# CoeFontの標準制作手順

- CoeFont音声制作では、この手順をInfo2・I1・Instagram V6・M1等と併用する。ユーザーに毎回説明や確認を求めない。
- 最初にCoeFontのログイン状態を確認する。ログイン済みなら現在のセッションを使う。ログインが必要ならGoogleを選び、認証情報は利用可能な安全な認証機能で扱う。パスワードや認証コードをチャットで求めない。別のGoogleアカウントへ勝手に切り替えない。
- 新しい制作案件の開始時は、必ず案件専用の新規プロジェクトを作成する。既存の別案件・別会話のプロジェクトを流用、上書き、削除しない。新しいタブを開くだけでは新規プロジェクト作成にならない。
- 名前は「テーマ_形式_専用_日付」など、他案件と区別できるものにする。新しい編集URLとプロジェクト名を確認して記録する。
- 同じ案件の継続作業は、直前に作成した専用プロジェクトを再利用する。毎ターン無意味に作り直さない。ただしユーザーが新規作成を求めたら、新規に作成する。
- 複数の会話で利用している場合でも、競合が不具合の原因だとは証拠なく断定しない。案件専用プロジェクトで作成・生成・取得を順番に確認する。
- 新規プロジェクトの音声選択では、まず「お気に入り」を押して、登録済みの声から指定の声を選ぶ。ユーザーのお気に入りには「後藤邑子」と「汎用式概念χ-soft-v2[最高精度] ¦CV:ろさちゃん Losa-chan -soft」がある（2026-10-04確認）。候補の存在だけで両方を使用するとは判断しない。指定の声がない場合だけ検索を使う。
- 指定の声をサービス上の正式名称で確認する。勝手に別の声へ置き換えない。
- 台本を空の編集欄へ入力し、入力後の全文を確認する。既存文への追記になっていないか、重複・旧文・別案件の文章が残っていないか確認する。
- 生成完了と音声の実ファイル取得を区別する。ダウンロードできるところまで進め、取得音声を確認してから動画と同期する。生成済みだけで音声付き動画完成と報告しない。
- ダウンロードに失敗した場合は、新規プロジェクトが本当に作られていることと生成完了を確認してから合理的な再試行を行う。アクセス制御を回避しない。解消できない場合は具体的な制約と、保存済みの専用プロジェクトへの検証済みリンクを伝える。
- Google認証の画面で本人操作が必要な場合以外は、通常のログイン確認や新規作成の許可を繰り返し求めない。安全な認証機能やブラウザの承認要件には従う。
