# 国試対応 病原体擬人化図鑑

制作前に `assets/yellow-staph-reference.jpeg` を確認する。これはユーザー提供の承認済み「黄色ブドウ球菌くん」の**構成と空気感**の見本。顔・衣装・王冠・固有の背景小物を別の病原体に流用しない。ユーザーが新しい見本を付けた場合はその指定を優先する。資料の読み方は `references/exam-evidence.md`、レイアウト票は `references/page-brief.md` を参照する。

## 仕上がり

- 原則、縦長の全画面イラスト一枚。Instagramフィードなら1080×1350の4:5、Reel素材も兼ねるなら1080×1920の9:16か、後で上下左右が安全に拡張できる構図にする。用途を先に決める。
- 人型の病原体キャラクターを主役にする。病原体の形態、生息場所、感染経路や看護上の要点を衣装・小道具・背景に変換する。菌体だけに顔を描いた絵を主役にしない。
- 上部に病原体名。小さく正式名・必要なら読みを添え、「看護師国家試験対応」を読める位置に置く。顔に見出しを重ねない。
- 細い手描き線の自然な吹き出し4〜6個を、人物の顔と手を避けて左右へ置く。読み上げられる短文を各1メッセージとし、視線に沿う順番で並べる。
- 下部に大きな「国試POINT」。最も覚えてほしい2〜3語をまとめ、長い説明表にしない。背景の装飾用ミニカードは、スマホで読めない小文字を増やす理由にしない。
- 文字は自然な日本語で、本文をスマホ縮小時に読める大きさに保つ。生成画像内の文字が崩れる場合は背景・人物を生成し、正確な文字を別レイヤーで組む。

## 制作の順序

1. **対象と試験根拠。** 病原体を細菌／真菌／ウイルスに分類し、厚生労働省の現行出題基準と公開された問題・正答を確認する。過去問に直接登場した事項と、臨床的に重要だが出題を確認できない事項を区別する。「頻出」「過去問に出た」は回・設問番号を特定できた時だけ使用する。最新の感染対策・臨床事項は公的機関または専門学会の一次資料で再確認する。
2. **制作票。** `references/page-brief.md` の欄へ、核となる覚え方、吹き出し文、対応する衣装・小道具、国試POINT、資料URL・確認日を記す。一枚で教える中心は一つに絞る。根拠のない衣装の「医学的意味」を後付けしない。
3. **作画。** 画像生成ツールで一枚ずつ制作する。キャラクターと吹き出しのための余白を先に設計し、作品内の日本語は逐語指定する。既存画像を修正するときはその画像を参照して編集し、指示のない顔・文章・世界観を書き換えない。
4. **文字組み。** 英字・略語は初出で読みと日本語を併記する。例：MRSA（エムアールエスエー／メチシリン耐性黄色ブドウ球菌）。細菌にのみ該当する性質を真菌・ウイルスへ機械的に当てはめない。発病・保菌、感染経路、毒素、薬剤耐性を混同しない。
5. **検品。** 全文を制作票と突き合わせて誤字・重複・根拠のない断定を消す。元サイズとスマホ想定約270px幅の両方で確認する。切れている文字、顔を覆う吹き出し、未説明の専門語があれば修正する。

## 表現の境界

- 病原体が「いつも病気を起こす」と誤読される表現を避け、常在・保菌と感染成立を描き分ける。
- 「これだけで診断できる」「どの患者にも同じ処置」の断定を避ける。国試の暗記と現場の判断の違いはキャプションへ補足する。
- 情報過密なら文字を縮めず、4つの最重要バルーンと最終POINTへ減らす。細かな疾患一覧はキャプションか別教材へ送る。
- 引用した過去問の全文をそのまま画像へ複製せず、設問の問う概念を自分の短文で表す。

## 納品

完成画像、必要に応じて根拠一覧・投稿キャプションを保存する。Reelも依頼されたら `animate-pathogen-layer-reel` の手順で**完成画像を素材として**別レイヤーに分解し、指定音声で動画にする。
