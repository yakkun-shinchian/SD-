# 国試の根拠の取り方

1. 厚生労働省の看護師国家試験出題基準を確認する。現行版かどうかを公開年と試験回で確かめる。参照入口：https://www.mhlw.go.jp/stf/shingi2/0000159020_00001.html
2. 厚生労働省公開の問題と正答を、回・午前／午後・問番号を控えて照合する。例（閲覧時は最新版も探す）：第115回 https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/tp260424-03_04_05.html
3. 一回の出題を見つけただけなら「第○回で扱われた」と書く。「毎年出る」「頻出15種」など頻度の主張には、対象回数、検索した回、採録条件、集計結果を残す。選択肢に名前があるだけか正答の根拠なのかも区別する。
4. 問題の記載と最新の感染対策に差があり得る場合は、現在の公的機関・学会・査読原著で別に検証する。臨床指示を単一の暗記語で代用しない。
5. 制作票に「主張／問題の回と番号／臨床一次資料／確認日／画像に残す短文」を一対一で記録する。根拠が見つからなければ「国試対策の基本事項」として扱い、出題実績を示唆しない。
