# 動画CTスキル（CT・MRI 断面図 → 縦型教育動画）

CT・MRIの断面図は、どの部位でもこの型で作る。基準は伸作さんが渡した3つの参考です。
- **胸部CT動画**：白黒CTと色分けを上下に並べ、引き出し線で同じ構造をつなぐ。冒頭は「まずはCTを『スクロール』」。
- **骨盤MRI動画**：「この白黒MRI どこを切ったか言える？」で始める。各高さに「POINT」「先輩に聞かれたら？」「病気のとき＋国試」のカード。最後は一覧と「保存して、実習前・国試前にもう一回！」。
- **輪切りの頭（漫画の3コマ）**：頭が水平に切れて、上の部分がスーッとずれ、切り口に断面が見える。「横断像＝体をこう輪切りにした面」を一目で伝える演出として使う。描くのは自前の素材だけ。漫画の絵や擬音はそのまま使わない。

## 絶対に守ること（伸作さんの指摘から）
1. **白黒と色分けは必ず上下に隣接**。並べないと分かりづらい。
2. **ラベルは大きく（1080幅で34px以上）、黒い余白に置き、線で引き出す**。構造の上に直接文字を書かない。
3. **動きはなめらかに**。高さが変わるときは上下2枚が同時にスクロールし、次の断面へ**ぴったり着地**する。崩れたAIフレームは使わない。
4. **退屈にしない**：冒頭のスクロール、立体（輪切りの頭・3D回転）、TIPS・クイズ・効果音を入れる。
5. 臨床の中身は正確に。書いた要点は最後に伸作さんへ確認をお願いする。

## 素材
- **各高さの断面図（色分け）**：同じ構図・同じ円の位置でそろえたもの。6〜10枚。小さなラベルが焼き込まれていれば消す（下記）。
- **白黒**：本物の白黒CT/MRIがあればそれを使う。なければ色分けから作る（下記 `ct_gray`）。
- **スカウト用の全身/頭部画像**：半透明の人体1枚。断面ラインが焼き込まれていれば消す。
- 断面どうしのつなぎ：AI動画（Seedance 2.0 Mini 720p 4秒 ≒ 63クレジット/本）か、クレジット0の**オプティカルフロー変形**。迷ったらフロー変形。AI動画は崩れる前で切る。

## 構成（縦 1080×1920・30fps・70〜90秒）
| 区間 | 長さ | 中身 |
|---|---|---|
| フック＋スクロール | 約5.5秒 | 「看護学生・新人さんへ／この白黒CT／どこを切ったか／言える？」。PACS風の白黒パネルで上→下へ一気にスクロールし、さっと戻る（カチカチ音）。下に輪切りの頭。切り口＝いま見ている断面 |
| 3D＋予告 | 約3秒 | 断面ライン入りの体が回る。断面サムネが①〜⑩と並ぶ。✔チェックリスト3行（病気はどう写る？／国試に出るポイント／先輩の質問にそのまま答える） |
| 各高さ | 5秒（先輩Qありは7.4秒） | 下のレイアウト |
| 高さのつなぎ | 1.0〜1.5秒 | 上下同時スクロール、ふたが戻る→切る高さが下がる→またずれる |
| まとめ | 6秒 | スカウトに全部の輪、「Nの高さ＝Nの病気・国試ポイント」一覧、グラデーションのCTA |

## 本編レイアウト（1080×1920の座標）
- ヘッダ y16〜120：「頭部CT **横断像** の見かた」（56px、横断像はシアン）＋サブ「白黒とカラーを上下に並べて『ここは何？』→ 病気・国試・先輩の質問へ」（26px）
- 左上スカウト (28,136)-(318,436)：**輪切りの頭**。切り口に今の色分け断面
- 右上情報 (334,136)-(1052,436)：金の丸数字＋レベル名（46px）、構造名（シアン26px）、POINT（金の札）＋2行（34px）。先輩Qのときは「先輩に聞かれたら？」→「シン先輩」の質問→1.2秒後に金の「答え」
- 白黒パネル (28,452)-(1052,1000)、札「白黒＝実際のCT」（MRIなら「白黒＝実際のMRI」）。右上に `Im: 045/100`・`Z: +54.4 mm`、左下 `W:80 L:40`（MRIは `T2 AXIAL`）、R/L
- 色分けパネル (28,1024)-(1052,1572)、札「カラー＝色分け」。断面の円は直径540、中心x=540
- 病気カード (28,1592)-(1052,1904)：ピンク枠。「病気のとき」札＋病名（44px）、▶3行（32px）、金の「国試」箱1行
- 色は：シアン(110,210,255)、金(255,205,90)、ピンク(255,80,160)、背景は紺のグラデーション

## 引き出し線のルール（上下をつなぐ）
- ラベルは左右の黒い余白の列に置く（左列の右端x≈268、右列の左端x≈812）。札は角丸・濃紺の塗り・構造色の枠・左に色の丸・白文字34px。
- 線は**直角**に引く。札から構造のxまで水平線、そこから縦線を白黒パネルの同じ点まで伸ばす。色分け側と白黒側の両方の点に「黒縁＋色＋白芯」のドットを打つ。
- 同じ側の札は縦に74px以上あける。縦線どうしが重ならないよう、アンカーのxを15px以上ずらす（構造の中で）。
- 出し方：札がポンッと出て（ease-back 0.32秒）、水平線→縦線の順に伸びる。消すときは0.22秒でフェード。

## つなぎ（なめらかさの要）
- 各つなぎは `gap_frame(i, u)`（u=0〜1）で、**u=0で前の静止画、u=1で次の静止画に完全一致**させる。
- AI動画を使うときは、崩れる手前までの割合だけ使う（例：0.62）。最初0.08は前の静止画から、最後0.22〜0.32は次の静止画へブレンド。傾き・横向き・リング状のノイズが出たら、その区間はフロー変形に替える。
- 速すぎず遅すぎず：1.0〜1.5秒。長いクリップは速めて収める。
- 同時に動かすもの：上下パネル、`Im:`の数字、スカウトの切る高さ、情報パネルのクロスフェード、病気カードの退場。

## コードの要点（Python + PIL + OpenCV、フレームごとに描いて ffmpeg へパイプ）
```python
# 色分け → CTらしい白黒（骨は白、髄液は暗く、ノイズ少し）
def ct_gray(rgb, seed=0, noise=6):
    a = np.asarray(rgb).astype(np.float32)
    g = 0.30*a[...,0] + 0.59*a[...,1] + 0.11*a[...,2]
    g = np.clip((g-40)*1.25, 0, 255); g = 255*(g/255)**1.15
    g += np.random.default_rng(seed).normal(0, noise, g.shape)
    return Image.fromarray(np.clip(g,0,255).astype(np.uint8)).convert("RGB")

# クレジット0のなめらか変形（両端の静止画に必ず着地）
dis = cv2.DISOpticalFlow_create(cv2.DISOPTICAL_FLOW_PRESET_MEDIUM)
fab, fba = dis.calc(gA, gB, None), dis.calc(gB, gA, None)
def flow_morph(u):
    wa = cv2.remap(A, gx-u*fab[...,0], gy-u*fab[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    wb = cv2.remap(B, gx-(1-u)*fba[...,0], gy-(1-u)*fba[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    return wa*(1-u) + wb*u
```
- **輪切りの頭**：人体画像を切る高さ `cy` で上下に分ける。下半分を描き、切り口に断面画像を「顔の向きへ90°回転→幅＝その高さの体の幅、高さ＝幅×0.34の楕円」で貼り、金の縁を描く。上半分（シルエットのマスクで背景を抜く）は、下側に暗い半楕円の縁をつけて右上へずらし、-7°傾ける。ずれ量 `lift` 0→1、動いている間は後ろに白い流線。上に90pxの余白を足して、ふたが切れないようにする。高さ→画像のyは、頭頂〜眼窩の割合表（例：[0.08,0.2,0.32,0.42,0.5,0.58,0.7,0.8,0.9,1.0]）で非線形に対応させる。
- 焼き込みラベルの消し方：①まず Nano Banana 2 の編集で「小さなラベル・線・点だけ消す」を作る（2K・24クレジット/枚）。②元画像とその差分のうち、手で測ったラベル箱と線の周り**だけ**を元画像に合成して戻す（それ以外の解剖は元のまま）。③円の縁に残ったピンクの線は、色相マスク＋inpaintで消す。
- PACS風HUD：等幅フォント（DejaVu Sans Mono）、四隅に `HEAD CT AXIAL`・`Se: 2 Im: 045/100`・`Z: ±mm`・`W:80 / L:40`・`Thk 1.0 mm`・`教育用イメージ`、A/P/R/L、右端にスクロールバー。
- 音：BGM（明るいシンセ＋マリンバ、110BPM、約30%の音量。長さが足りなければ acrossfade でつなぐ）、ラベルが出るときにポン、つなぎに小さなシュッ、先輩Qでクイズ音、スクロール中はノイズで作ったカチカチ音（クレジット0）。
- 確認：静止画を数枚書き出して（`STILLS=t1,t2,...`）レイアウト・ラベル位置・つなぎを目で見てから全編を書き出す。全編は1080pで約5分。

## 各高さの中身（骨盤動画の型）
- **POINT**：その高さで何が見えるか（2行、1行17字前後）
- **病気のとき**：病名＋▶3行（CTでどう写る／症状／看護で気をつけること）
- **国試**：1行で言い切る（例「pinpoint pupil ＝ 橋出血」「三日月形＝硬膜下血腫／凸レンズ形＝硬膜外血腫」）
- **先輩に聞かれたら？（シン先輩）**：全体の3〜4か所。臨床でそのまま聞かれる質問と、1行の答え
- まとめ一覧：「① レベル名 — 病気・キーワード」

頭部CT10枚での内容例：頭頂部・中心溝（ACA梗塞・錐体交叉）／半卵円中心（慢性硬膜下血腫）／側脳室体部・放線冠（ラクナ梗塞・DWI）／側脳室前角（水頭症・iNPHの3徴）／基底核・内包（被殻出血・共同偏視）／第三脳室・四丘体槽（視床出血・脳槽の消失）／中脳・鞍上槽（SAH・攣縮4〜14日目）／橋上部・トルコ鞍（橋出血・両耳側半盲）／橋・蝶形骨洞（小脳出血・急性水頭症）／眼窩・副鼻腔・延髄（ワレンベルグ・大孔ヘルニア）。

## 他の部位・MRIへの置きかえ
- 胸部・腹部・骨盤：スカウトを半透明の体幹（または骨盤）に替え、**輪切りの胴体**で同じ演出。ヘッダは「胸部CT 横断像の見かた」など。
- MRI：白黒パネルの札を「白黒＝実際のMRI」、HUDを `T2 AXIAL`。T1/T2で水が黒/白になる点をPOINTかTIPSに入れる。
- 断面の枚数が6枚なら、各高さを6〜7秒に延ばしてよい。
