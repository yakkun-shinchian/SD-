# CTスキル1（白黒×カラー対比の断面動画）

CT・MRIの横断像を、**上＝白黒（実際のCT/MRI）・下＝カラー（色分け）** に並べ、同じ構造を引き出し線でつなぐ縦型教育動画（1080×1920・30fps）を作る型。新しく作るときにも、既存のCT動画（例：白黒→カラーが同じ枠で切り替わるだけの動画）を作り直すときにも使う。

## 絶対に守ること（伸作さんの指示）
1. **白黒とカラーは必ず上下に隣接**。同じ構図・同じ位置にそろえる（位相相関でずれが1px未満か確認）。
2. **各高さの要素は順番に出さない。切り替わったら約1秒で全部パッと出す**：ラベル・引き出し線・点・病気カード・国試を同時にスタートし、1秒以内に完成させる（ラベル間のずらしは0.03秒だけ）。視聴者が最初から全体を見比べられるようにする。
3. **ラベルは大きく（1080幅で34px）**、左右の黒い余白に置く。構造の上に文字を書かない。線は直角で、色分け側と白黒側の同じ点にドットを打つ。
4. **動きはなめらか**：高さが変わるときは上下2枚が同時に変形し、次の断面にぴったり着地する（u=0で前の静止画、u=1で次の静止画に完全一致）。
5. 臨床の中身は正確に。病気・国試・先輩Qは最後に伸作さんに確認してもらう。

## 引き出し線
- ラベル札：角丸・濃紺の塗り・構造色の枠・左に色の丸・白文字34px（Noto Sans CJK Black）。名前は4文字以内。
- 線：札→構造のxまで水平線（札のy）、そこから縦線を色分けの点を通って白黒パネルの同じ点まで。黒縁＋色の二重線。
- ドット：黒r10＋色r7＋白芯r3を、色分け側と白黒側の両方に。
- 同じ側の札は縦74px以上あける（下へ押し出し、パネルからはみ出たら全体を上へ戻す）。縦線どうしはx を15px以上ずらす。
- 構造の座標は、色分け画像に50pxグリッドを重ねた画像を作って目で拾う（例：心臓・肝臓・食道・大動脈・椎体・肺／胃・脾臓／膵臓・腎臓・下大静脈）。

## 既存の動画から素材を取り出す手順
1. `ffmpeg -vf fps=10` で全コマを書き出し、パネル領域の彩度（max-min の平均）と白い横線の有無を1コマずつ計算する。
2. 各高さで、**彩度≈1の白黒コマ**と、**彩度が上がった直後で次のコマとの差が最小（≈0.05）のカラーコマ**（ラベルや線が入る前）を選ぶ。
3. 白黒とカラーを位相相関で比べ、ずれがないことを確かめる。
4. 焼き込みの札（「実際のCT（白黒）」「色分けすると…」）を消す：札の箱を色で検出し、皮膚ラインを左右の列から2次式で当てはめ、**皮膚ラインに沿って左右の端から補間**（cv2.remap でサブピクセル）＋ノイズ σ7。四隅の「右/左」は上200px・左右38px以内を黒で塗る。
5. 1.17倍に Lanczos で拡大し、軽くアンシャープ（1.35×元−0.35×ぼかし σ1.2）。
6. フックのスクロール用に、元動画の連続断面（IMG 01〜10 など）を切り出し、高さを①の断面に合わせて拡大・センタリング。
7. スカウト人体：最後の一覧コマなどから人体の黒い四角を切り出し、焼き込まれた細い横線は上下の行の補間で消す。黒背景は輝度から透明度を作って（max(RGB)/45）合成する。

## 輪切りの胴体（スカウト）
- 人体画像を切る高さ `cut` で上下に分ける。下半分を描き、切り口にカラー断面を**上下反転**（前＝手前）して楕円（幅＝胴の幅、高さ＝幅×0.34）で貼り、金の縁。
- 上半分（ふた）は下側に暗い半楕円の縁をつけ、`lift`（0→1）で右へ46px・上へ62px・−7°。動いている間は白い流線。キャンバス上に余白96pxを足してふたが切れないようにする。
- 各高さの `cut` は、元動画の一覧コマに焼き込まれた横線の位置から取ると正確。

## つなぎ（クレジット0のフロー変形）
```python
dis = cv2.DISOpticalFlow_create(cv2.DISOPTICAL_FLOW_PRESET_MEDIUM)
fab, fba = dis.calc(gA, gB, None), dis.calc(gB, gA, None)   # 白黒どうしで計算
def morph(A, B, u):
    wa = cv2.remap(A, gx-u*fab[...,0], gy-u*fab[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    wb = cv2.remap(B, gx-(1-u)*fba[...,0], gy-(1-u)*fba[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    return wa*(1-u) + wb*u
```
- 白黒で求めたフローをカラーにもそのまま使う（上下が同じ動きになる）。u は smoothstep。
- 断面の中身が大きく違う2枚（例：脾臓の高さ→膵臓の高さ）は途中で少し二重に見えるので、気になるときは中間の断面をはさむ。

## 色分けがなく白黒だけのとき
```python
def ct_gray(rgb, seed=0, noise=6):  # 色分け→白黒が必要なとき
    a = np.asarray(rgb).astype(np.float32)
    g = 0.30*a[...,0] + 0.59*a[...,1] + 0.11*a[...,2]
    g = np.clip((g-40)*1.25, 0, 255); g = 255*(g/255)**1.15
    g += np.random.default_rng(seed).normal(0, noise, g.shape)
    return Image.fromarray(np.clip(g,0,255).astype(np.uint8)).convert("RGB")
```

## 各高さの中身の書き方
- **POINT**：その高さで何が見えるか2行（1行17字前後）。例「画面の左＝患者さんの右／肝臓が左に見えたら正解！」
- **病気のとき**：病名＋▶3行（CTでどう写る／症状／看護で気をつけること）
- **国試**：1行で言い切る（例「ベック3徴＝血圧低下・頸静脈怒張・心音減弱」「後腹膜臓器＝膵臓・腎臓・十二指腸・大動脈」）
- **先輩に聞かれたら？（シン先輩）**：臨床でそのまま聞かれる質問と1行の答え
- 胸腹部Part1の例：①心臓の高さ（心タンポナーデ）②肝臓のてっぺん（胸水・背側に三日月形）③肝臓と胃（消化管穿孔・遊離ガス／胃管の先）④肝臓・胃・脾臓（脾損傷・左肋骨骨折）⑤膵臓の高さ（急性膵炎・アミラーゼ/リパーゼ）
- 字形に注意：「SpO₂」の下付き₂や「✔」はNoto CJKで豆腐になるので「SpO2」・線で描いたチェックにする。

## 音（すべてnumpyで合成、クレジット0）
- BGM：110BPM、C–G–Am–Fのマリンバ8分アルペジオ＋パッド＋ベース＋柔らかいキック＋ハット。ピーク0.30、最後1.8秒でフェード。
- 効果音：ポン（600→1500Hzの短いスイープ）、シュッ（ローパスノイズ）、カチカチ（2.2kHzクリック）、チーン/クイズ音/ディン（ベル系和音）。
- 効果音は0.55倍でBGMに足し、tanhで軽く抑える。

## 書き出し
- Python＋PIL＋OpenCVで1コマずつ描き、ffmpegへrawvideoでパイプ（libx264・veryfast・crf18・yuv420p）。
- CPUが2つなら、フレーム範囲を2つに分けて並列に書き出し、concatで結合してから音声をmux（aac 192k）。約60秒で7〜8分。
- 先に `STILLS=t1,t2,...` で静止画を数枚出し、レイアウト・ラベル位置・**1秒以内に全部そろうこと**・つなぎを目で確かめてから全編を書き出す。
- 書き出し後、1fpsのコンタクトシートで全体を確認する。
