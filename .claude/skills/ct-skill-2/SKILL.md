# CTスキル2（スクロール×考える1.5秒×ナレーション）

CT・MRIの横断像を「本物のCTをスクロールしている感じ」で見せ、各高さで1.5秒だけ考えさせてから、色分けとラベルを一気に出す縦型ショート（1080×1920・30fps・30〜40秒）。伸作さんの参考動画（胸部CT 9レベル・24.5秒）を型にしたもの。CTスキル1（病気カード・国試・先輩Qまで入れる長め版）より短く、テンポ重視。

## 絶対に守ること（伸作さんの指示）
1. **最初の3秒で決まる**：0秒目からCTがなめらかに動いている。タイトルだけの静止や、ロゴ・説明から始めない。
2. **カチカチ（クリック）音は使わない**。スクロールは無音で、BGMとナレーションだけ。
3. **考える時間は1.5秒**：各高さの頭で、上下とも白黒のまま「どこの高さ？／どこが何かわかる？」＋1.5秒で減る金のバー。1.5秒たったら色分け。
4. **ナレーションを入れる**：声は**高くて明るい、ポップでかわいい女の子の声**（低め・落ち着いた声や男性の声は使わない）。1.3倍速まで上げてよい。短く言い切る。
5. **白黒（上）とカラー（下）は同じ構図で上下に隣接**。同じ構造を直角の引き出し線でつなぎ、両側にドット。
6. **色分けしたら約0.6秒以内に全ラベルがそろう**（ずらしは0.03秒だけ）。順番に出さない。
7. 臨床の中身（各高さのひとこと）は最後に伸作さんに確認してもらう。

## なめらかなスクロールの作り方（本物のCTに見せるコツ）
- 断面が10枚程度しかなくても、**隣どうしの断面をオプティカルフローで補間**して連続スクロールにする。途中のコマも本物のCTに見える。
```python
dis = cv2.DISOpticalFlow_create(cv2.DISOPTICAL_FLOW_PRESET_MEDIUM)
flows = [(dis.calc(g[i], g[i+1], None), dis.calc(g[i+1], g[i], None)) for i in range(n-1)]  # 表示サイズで先に計算
pos = 9 * (0.5 - 0.5*cos(pi * t/2.6))        # 0..9 を cos で加減速
i = min(n-2, int(pos)); img = morph(S[i], S[i+1], flows[i], pos - i)

def morph(A, B, fl, u):
    fab, fba = fl
    wa = cv2.remap(A, gx-u*fab[...,0], gy-u*fab[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    wb = cv2.remap(B, gx-(1-u)*fba[...,0], gy-(1-u)*fba[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
    return wa*(1-u) + wb*u
```
- `Im` の番号と `Z` の値は pos から補間して毎フレーム更新する（数字が流れるだけで本物感が出る）。
- 人体の円盤の高さも pos から補間して、CTと同時に動かす。
- フックのCTは元動画の連続断面を**フル解像度のまま**使う（縮小しすぎない）。HUDの焼き込みは、文字は inpaint、スクロールバーの列は左右の列から補間で消す。

## ナレーション
- 声：**高くて明るい、ポップでかわいい女の子の声**（伸作さんの指定。低め・落ち着いた声は使わない）。Creative Claw の Character「YAKUBONかわいいナレーター」（character_id `edad7e7d-e309-4b79-b931-4704990eff31`）を `speech/elevenlabs-v4` で使う。`language_code: ja`、stability 0.5、行頭に `[excited]`、語尾は「〜だよ！」「〜！」で弾ませる。全文を1回で生成してクレジットを節約し、無音検出（-40dB）で行ごとに切る。
- この声がない環境では、design_voice で「20代前半の日本人女性、とても高く甘く弾むポップアイドル風の声、明るくキラキラ、東京標準語」と説明して3案作り、pyin で地声の高さ（中央値）を測って一番高く、文字起こしで発音が正しいものを選ぶ（目安：中央値450Hz前後）。実在の歌手・タレントの声そのものは真似しない。
- **医療用語はひらがなで渡す**（しんぞう・かんぞう・ひぞう・すいぞう・おうかくまく・ろっこつ・だいどうみゃく、CT→シーティー）。読み間違い防止。
- 切り出し後、行内の0.3秒以上の間は0.22秒に詰め、`atempo=1.3` で1.3倍速。
- 台本の型：
  - フック「胸からお腹のシーティーを、上から下へ、一気にスクロール！」「どこを切ったか、言えるかな？」「では、いちまいずつ見ていこう！」
  - ①の考える間「ここは、どこの高さ？」
  - 各高さ「〇〇の高さ！（ひとこと1文）」例「しんぞうの高さ！画面の左が、患者さんの右だよ。」
  - まとめ「保存して、実習前に、もう一回！」「パート2は、お腹から骨盤へ！」
- ミックス：ナレーション0.92、BGMはやわらかいパッド＋マリンバでピーク0.14、ナレーション中は55%ダッキング。効果音は色分けのポン（0.35倍）とまとめのチーン（0.25倍）だけ。**クリック音・シュッ音は入れない**。

## 素材の取り出し（既存の動画から）
CTスキル1の「既存の動画から素材を取り出す手順」と同じ（彩度で白黒/カラーのコマを選ぶ→位相相関でずれ確認→札・HUDを消す）。加えて：
- 元動画のスクロール区間から連続断面（IMG 01〜N）を白黒・カラーとも切り出す。焼き込みの札がない断面が手に入るので、本編の白黒/カラーもこちらを優先して使い、左右の端だけ本編コマから補う。
- 構造の座標は色分け画像に50pxグリッドを重ねて目で拾う。縦線どうしは15px以上離す。

## 書き出し
- Python＋PIL＋OpenCVで1コマずつ描き、ffmpegへrawvideoでパイプ（libx264・veryfast・crf18・yuv420p）。CPU2つなら半分ずつ並列→concat→音声をmux（aac 192k、`-movflags +faststart`）。
- 先に静止画（0秒・スクロール中・考える間・色分け後・つなぎ・まとめ）を数枚出して確認してから全編。
- 書き出し後、1fpsのコンタクトシートで全体を確認。
