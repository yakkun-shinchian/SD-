# 何のため？看護教材

## Instagram用インフォグラフィックの固定仕様

- Instagram投稿用のインフォグラフィックは **縦16：横9＝幅：高さ9：16** の縦長を標準にする。基準は **幅1080×高さ1920px**。高解像度版は2160×3840pxなど同じ比率とする。「縦16横9」を横長16：9と取り違えず、指定がなければ4：5や正方形に変えない。
- 書き出し後に実際の画素寸法で比率を確認する。生成プロンプトに比率を指定しただけで、正確な比率を検証済みと報告しない。調整時は図や文字を変形せず、切り落とさず、画像編集の指定手段に従う。
- 既定は **プロフェッショナルな医療インフォグラフィック**。見出し・短い説明・解剖図・血流図・因果矢印を主役にし、看護師の話者アバター、吹き出し、先輩後輩の会話、Q/A欄を自動で追加しない。看護師を描くなら介助・観察などの説明に必要な実施場面だけにする。
- 今回の明示的な画角・形式指定を最優先する。この固定仕様を漫画カルーセルや既存画像保持の動画に無条件適用しない。I1動画ではI1の原図保持ルールを尊重する。

## 「なぜ？」に理由で答える

- 病態は **原因 → 体の変化 → 症状**、対応は **操作 → 何が変わる → 患者への目的** として、短い理由と因果図で示す。「なぜ」を重視する依頼だけで会話形式を推定しない。
- 理由を見出しの隣に置き、注釈に追いやらない。病名の言い換えだけで答えず、短い文章で不足する仕組みは血流・神経・臓器の変化を矢印や比較で描く。
- ユーザーが会話形式を明示した場合のみ、質問1回・答え1回の1往復を使う。併用するV6などの会話量制限を尊重する。
- 文章を小さく詰め込まず、必要なら「起こる理由」と「対応する理由」の2枚に分ける。複数枚の依頼では全枚を制作して納品し、プロンプトだけで完成としない。
- 注意点は本文に埋めず、余白と大きな文字の専用帯で目立たせる。赤は危険、黄は最重要、青は仕組み、緑は対応の目的を基本とし、色だけで区別せずラベルも添える。
- 注意点にも短い理由を添える。全面禁止と条件付き注意、全員に行うことと必要時に行うことを区別し、根拠のない因果関係や禁止事項を作らない。
- 完成時に、原因から症状と対応から目的につながりがあり、注意点が一目でわかるかを確認する。

## 必須の教育方針

手順や物品名を並べるだけで終わらせない。各主要操作に、初学者が一読して理解できる「何のため？」を添える。基本は **何をする → 何が変わる・何がわかる → 患者にどう役立つ**。目的の説明は本文・図・音声の中心に置き、注釈だけに追いやらない。

「安全のため」「状態を見るため」だけでは不十分。何を防ぐのか、何を確認するのか、なぜその器具・経路を選ぶのかを具体的にする。説明できない理由は作らず、資料で確認する。

## 制作手順

1. 対象と場面を明確にし、主要な操作・観察・検査・治療を抽出する。
2. 内部で「操作／目的と仕組み／確かめる所見／限界・条件」を整理する。
3. 臨床上の順番で並べる。並行して行う準備や状態に応じた優先順位を、絶対的な一本道に変えない。医師が行うことと看護師の介助・観察を区別する。
4. 各項目に短い「なぜ？ ○○するため」を置く。因果関係が長ければ、図解・矢印・比較で補う。無理な比喩は使わない。
5. 観察・検査には「この結果で何がわかるか」と重要な限界を示す。単一の色・数値・所見で安全が確定すると書かない。
6. 医学的な理由、数値、使用方法は制作時点のガイドライン・添付文書などで確認する。元動画や文字起こしの誤りをそのまま継承しない。
7. 各操作の隣に目的があり、読者が「だからこれをするのか」と説明できるかを確認して納品する。

## 表現と形式

- インフォグラフィック：見出し「何をする」、目立つ短文「なぜ？」、必要最小限の確認ポイント。目的を色や囲みで強調し、写真と対応させる。
- 台本・動画：操作名だけを読み上げない。主要操作の理由をナレーションにも含める。短尺では説明対象を絞り、目的を消して手順だけ詰め込まない。
- 情報量が多ければページを分ける。Instagram用インフォグラフィックは上記の固定仕様を使い、別形式の会話量・寸法・音声・CTAは指定されたV6・M1等に従う。固定の枚数や尺は押し付けない。
- 実物写真を求められたら、提供写真や出典を確認した製品写真を使う。生成した器具を実物写真と偽らない。形・接続部・位置と説明が一致しているか確認する。
- この会話での緑のシリンジ、トーマス等の個別指定を、すべての看護教材の必須器具に一般化しない。

## 説明の具体例

以下は表現の例であり、固定の実施プロトコルではない。適応・方法・条件は制作時に確認する。

| 操作 | 初学者に伝える「何のため？」 | 誤解を防ぐ点 |
| --- | --- | --- |
| 必要時の口腔・咽頭吸引 | 痰・血液・吐物を除き、声門を見やすくし、気道閉塞を減らすため | 必ず吸引を最優先とはしない。酸素化と状態を考慮する。 |
| 前酸素化 | 酸素の蓄えを増やし、挿管中に酸素が下がるまでの時間を延ばすため | SpO₂ 100％だけで完了としない。BVM換気補助は呼吸状態に応じる。 |
| スタイレット | 柔らかいチューブに形と適度な硬さを与え、声門へ導きやすくするため | 先端をチューブから突出させない。固定具と混同しない。 |
| カフへの空気注入 | 気管との隙間をふさぎ、換気時の空気漏れを減らすため | カフは固定具ではなく、圧を確認する。 |
| 呼気CO₂検出 | 肺からの呼気を確認し、食道挿管を見逃さないため | 色調式の限界と製品手順を確認。片肺挿管は否定できない。 |
| 左右の胸郭・呼吸音確認 | 左右が換気されているかを確認し、片肺挿管に気づくため | 聴診だけで気管内と確定しない。 |
| チューブ固定 | 抜け・ずれを防ぎ、換気を安定して続けるため | 位置確認中も保持。固定後も位置や皮膚を確認する。 |
| 胸部X線 | 先端と気管分岐部の位置関係を確認し、深すぎ・浅すぎを評価するため | X線を待って初期の換気・食道挿管確認を遅らせない。 |

## 完成判定

- 主要な操作すべてに具体的な目的がある。
- 操作・目的・器具・写真の対応が正しい。
- 因果関係の説明と実施順序に飛躍がない。
- 必要な条件・限界が、本文の理解を妨げない短さで入っている。
- 目的を説明するために根拠のない断定や過剰な保証を加えていない。
