# インフォV3の重要文と下線の検品

[既存のインフォV3](../info-v3/SKILL.md)と併用する。台本を決める時点と、完成音声で書き出した後の2回使う。

## 1．各部の最初の一文を決める

1. 4枚を実際の順で開き、「この1分を見た新人看護師に、何を説明できるようになってほしいか」を一文で書く。前半・後半があるときは、それぞれで決める。後半から見ても対象が分かるようにする。
2. 原図から、**結論、結論を説明する発生機序、判断や行動につながる重要な観察ポイント**を文単位で拾う。「何が起こるか → なぜか → 何を見るか」と声に出してみる。テーマに該当する役割を採用する。単なる網羅のために原図外の機序を足さない。
3. ないと結論が変わる文、患者の観察や判断が変わる文を必読にする。前提がいる文には、その用語や対象を初めて説明する文を結び付ける。残りは、理解に必要な背景、重複、例、細目の順に見直す。採用しなかった文は原図に残せる。
4. 冒頭は主語と要点が自立する文を選ぶ。「そのため、ここも確認します」から始まるときは、何が起きたのかを先に読む。その文が原図の中央にあっても、一文の頭から意味が通っていれば使える。改行で分かれた一文は最後の行まで選ぶ。
5. 読み上げ順を記録し、各ページを切り替えた直後も、今の観察対象と前の説明との関係が伝わるか通読する。医学用語を初出で説明する。原図にない短いつなぎが必要なら、台本に明記し、関連する原図を映して下線を消す。

例：原図に「歩き始めの変化を観察します」「そのため、最初の一歩までの時間を比べます」の2文があるとき、2文目だけを抜き出すと「何のためか」が消える。1文目を先に選ぶか、観察対象と要点が一文に収まった、別の原文を選ぶ。

## 2．4枚で60秒に収める

- 前半4枚と後半4枚は**それぞれ60秒以内**。1枚15秒は初稿の配分の目安。機序に時間が必要なページには長く配分してよい。短くまとまった部に余白の無音を足さない。
- 最初は**1.3倍速**で仮読みまたは仮音声を通し、4枚分の実際の長さを測る。例えば68秒なら、少なくとも8秒ぶんを減らす。まず重複した結論、二つ目以降の例、細かな列挙から削る。各ページの中心文と、結論を理解するのに必要な前提を残す。
- 削った原稿を同じ速度で再度読み、秒数と聞きやすさを確認する。速度を上げる場合も**最大1.5倍速**。略語、薬剤名、否定、数値の区別が聞き取りにくければ、速度を戻して文章を短くする。必読文を落とす必要がある場合は、残す結論を再検討する。速度を上限へ自動調整しない。
- ひらがな原稿の依頼では、原図の表記を保存し、読みだけを別欄に持つ。速さ・連結・無音カットを確定した後、最終音声を測り直す。仮読みの値、文字数比、均等配分から下線の時刻を作らない。

## 3．原図、完成音声、下線を別々に採取する

[共通データ形式と実行方法](references/manifest.md)に従い、1部につきJSONを1つ作る。原図側では文と行に出現位置ごとのIDを振る。音声側では聞こえた文と発話区間を取り、映像側では実際に強調した行、線の座標と表示区間を採る。予定台本のIDや時刻を複写して3者が一致したことにしない。

- 制作指定の下線色を最優先にする。「すべて水色」なら見出し・本文とも水色。「本文だけ水色」なら見出しにV3の既定を使う。囲み・矢印・カメラは既存V3と当該制作の指定に従う。
- 記録を検品し、ずれた発話IDと行IDを見て該当区間を直す。語句の途中、同じ文の別出現、次の文の先取りにも注意する。下線は文字の直下に置き、ズーム時も原図と同じ変換を使う。
- 書き出し動画を音声付きで全編再生する。特に各部の冒頭と4枚目、改行、否定や数値、パン直後で「聞こえた文・線の位置・画角」を照合する。自動検品が調べるのは記録間の一致と素材の同一性。実物の聞きやすさ・意味・画面上の描画は試聴と目視で確認し、その範囲を記す。

実行を試すときは [4枚の仮想例](examples/synthetic.json) を使う。この例に音声・原図・動画は付属しない。仮想試験、実素材の記録照合、完成動画の全編視聴は、結果をそれぞれ明記する。
