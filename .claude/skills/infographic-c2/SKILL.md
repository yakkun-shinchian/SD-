# インフォグラフィックC2

## 目的
看護学生・新人看護師が「なるほど、だからそうなるのか」と理解できる、美しい・かっこいい・可愛い医学教育図解を制作する。抽象語だけで説明せず、物の移動、場所、因果関係を大きな図で見せる。2026年10月の腎生理教材1〜5枚の視覚表現を基準にする。
独立したC2として扱い、C1、M3、医療動画1・2の既存スキルを変更しない。静止画を基本にし、動画・音声は依頼がある場合に制作する。C1の架空症例カルテは必須にしない。

## 固定デザイン
- 縦9:16、最終PNGは1080×1920を基本とする。実寸を確認してからサイズを報告する。端を切らない。
- 背景は黒に近く、低彩度で暗い色を使用する。約7色をシリーズ内で回し、同じ色の再使用も認める。鮮やかな全面背景にしない。
- 半透明の医療3D、ガラス状のパネル、繊細な発光フチ、陰影と奥行きで高級感を出す。発光で文字や構造をぼかさない。
- 太いゴシック体、白の本文、控えめなゴールドの重要語を使う。筆文字を使わない。短い見出しと短文でスマートフォンでも読める文字量にする。
- 上部に女性看護師2人を配置する。左はボブ＋ヘアピンの新人、右はまとめ髪の先輩。双方ネイビーのVネックスクラブ、親しみやすく可愛いセミリアルなアニメ調。
- 新人の吹き出しは青、先輩はピンク。1枚につき質問1回・回答1回のみ。男性人物を追加しない。
- 人物より医学図を大きくし、中央〜下段の約60〜65％を図解に使う。説明の主役は構造と現象。
- 下部に学習の要点、YAKUBON STUDIO、Clinical Infographic C2、ページ番号、生成図なら「AI生成模式図」を置く。
- 配色・構図・プロンプトは references/design-system.md を参照する。

## 制作手順
1. ユーザーの台本・順序・枚数・対象・納品形式を読み、確定した内容を保持する。1枚1学習目標にする。
2. 医学的根拠を信頼できる公的・学会・原著資料で確認する。各ページの主張と出典を記録する。参考デザインを医学的根拠にしない。
3. 各ページのタイトル、対話1往復、短い図中ラベル、矢印、要点を決める。長い説明はナレーション台本へ分離する。
4. 同じ臓器・ネフロンは形状、向き、位置、視点、色をできる限り維持する。連続機序の説明では同じ基礎図を使い、必要部分だけを変化させる。
5. 画像生成ツールを使い、1枚ずつ独立した画像を制作する。5枚を1枚のコンタクトシートに置き換えない。既存画像を参照できる場合はツールの参照手順に従う。
6. 既定は5枚単位。ユーザーがバッチ確認を指定した場合は5枚を提示し、確認後に次の5枚へ進む。全枚数を一度に作る明示指示があれば従う。
7. 全画像を目視し、誤字、見切れ、矢印方向、膜の内外、物質の色・凡例、輸送体、解剖と数値を原稿と照合する。誤りは対象箇所を修正して再確認する。
8. 完成PNGを提供する。PDF・ZIP・台本・シーン構成表・動画は依頼された範囲で作成する。ファイル保存は環境の保存ルールに従い、生成画像の自動保存例外も守る。未確認の保存・解像度・医学的検証を完了と報告しない。

## 医学表現の品質基準
- 比喩を使い、その直後に正確な機序を添える。水の磁石を本当の磁力として描かない。
- 原尿と最終尿、管腔と細胞内と間質と血管を区別する。再吸収は管腔から体側、分泌は体側から管腔。
- 数値には必要に応じ「成人の一例」「抗利尿時の模式例」などの条件を添える。
- Na⁺はナトリウム、NaClは塩化ナトリウム。凡例で混同しない。色だけに頼らず文字・形状も使う。
- 腎教材では下行脚を左、上行脚を右、集合管をさらに右に固定する。太い上行脚の水不透過性、NKCC2の1Na⁺:1K⁺:2Cl⁻、ADHによる管腔側AQP2増加などを正確に描く。
- 髄質高浸透圧をNaClだけで説明せず尿素の寄与を示す。模式図を実画像と称さない。
- 低K血症や薬剤の作用などは因果を省略しすぎず、対象者に必要な観察とつなげる。
