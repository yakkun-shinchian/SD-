# C2デザインシステム

## 背景と透明な医学図

最背面に不透明な純黒 `#000000` を敷く。図の周囲、切り抜きの隙間、対話とラベルの余白にも同じ黒を通す。生成時から背景のグラデーション、ビネット、霧、光粒は使わない。

透明に近い人体は臓器の**位置**を示し、臓器の薄い外壁は**内部**を見せる。血管壁の奥に内腔が透け、どこを血液が通るのか指でたどれる程度にする。隣り合う膜の前後が消える場合は、手前の縁と断面の陰影だけを少し濃くする。光彩で境界を太らせない。

## 構造ごとの7色

下表は落ち着いた7色の作例。ページ設計時に「構造・物質／色／形またはラベル」の対応を決め、同じ意味には全ページで同じ色を使う。各行の2色は、その対象の陰から光へ移るための両端。1枚では説明に必要な色だけを選ぶ。人体全体を横切る虹や、ページごとの色替えは使わない。

| 色系統 | 陰 → 光（sRGB作例） | 腎教材での使い分け |
|---|---|---|
| 青 | `#365477` → `#86A8C4` | 尿細管を透ける管壁で示す |
| 水色 | `#547F94` → `#A7CFD9` | 水をしずく形で示す |
| 緑 | `#466C5C` → `#93BAA2` | Cl⁻の粒子 |
| 砂色に近い黄 | `#87774E` → `#C3B37F` | Na⁺の粒子。文字は銀白 |
| 杏色 | `#8B634D` → `#CCA083` | ブドウ糖の粒子 |
| 藤紫 | `#61547F` → `#B0A0C6` | K⁺の粒子 |
| くすみピンク | `#815769` → `#BF97AA` | マンニトールの粒子 |

腎髄質の**濃度**を示す場合は、その領域内に限って淡い青から濃い紫への連続勾配を使い、向きと意味を凡例に添える。尿素とブドウ糖が並ぶ場合は形と名称も区別する。他の題材では、血流や病変など原稿で定めた医学的な色の意味を保ち、同じ要領で構造に割り当てる。

## 構図と組版

- **上段**に短い見出しと女性看護師2人の対話を1往復。左の新人が疑問を一つ尋ね、右の先輩が中央の図でたどれる答えを返す。青とピンクは吹き出しの縁に控えめに置く。
- **中央〜下段の約60〜65％**を主図に割く。局所の説明では、小さな全体像に対象部位を示し、すぐそばに同じ向きの拡大図を置く。比較なら二つの図の向き・倍率・基準位置をそろえ、異なる箇所が同じ高さで目に入るようにする。段階図は読順を一方向にそろえる。枠や矢印は関係を示す分だけ使う。
- **下段**に短い要点、ブランド、シリーズ名、ページ番号、生成図の表記を置く。左右48px程度（幅1080px時）の安全域を確保し、投稿先の操作ボタンが重なる場所から重要情報を離す。
- 見出しの作例は淡い青白 `#DCEBF5`、本文・対話・ラベルは銀白 `#CED8E1`。強調はウェイト・行分け・余白でつける。黄色・金色の文字は見出しから単位・凡例まで禁止。短いラベルは黒い余白に置き、必要なら細い引き出し線で示す。文字色自体の冷たい色味で透明感を出せるため、文字の不透明度を下げる必要はない。
- 新規制作は図と文字を別レイヤーにし、[Adobe Fontsの規定](../../infographic-adobe/SKILL.md)に従う。構造とラベルが重なる場合はラベルを移す。過度な発光、装飾パネルの重ね置きは使わない。

ページごとの視点・色の割り当て・図の余白は[生成プロンプト](generation-prompt.md)に渡す。納品前は[スマートフォン向け可読性チェック](mobile-readability.md)を使う。

## 基準となる題材
- 150L→1.5L：腎断面と原尿・水の回収・最終尿の関係。
- キュウリと浸透圧：身近な物のリアルな立体表現と細胞拡大図。
- 半透膜の水槽：薄い側から濃い側への水の正味移動を大きな矢印で示す。
- 髄質勾配：腎断面と同方向のネフロン拡大、条件付き数値。
- 近位尿細管：管腔→細胞→間質→血管を美しく明確に示す。
この題材に限定せず、他の解剖生理・病態・薬理にも同じ視覚原則を適用する。
