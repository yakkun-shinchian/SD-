# スマートフォン向け可読性チェック

対象は**文字と医学図を合成した最終PNG**。全ページを縦向き・画面幅に合わせて確認する。実機が手元にないときは、1080×1920の画像を幅360px・高さ640px相当で表示し、拡大せずに読む。確認記録には実機か縮小プレビューかを記す。縮小は確認用に限る。

| 見るもの | 合格の目安と確認方法 | 読みにくいときの修正 |
|---|---|---|
| 文字の大きさ | 幅360pxの組版開始値は見出し24px、本文・対話16px、短い図中ラベル14px相当。幅1080pxの原稿ならそれぞれ72・48・42px。最終表示で濁点、数字、小数点、単位、Na⁺とCl⁻の符号も拡大せず読み分けられる。 | 冗長な語を削り、意味の切れ目で改行する。数値と単位を同じまとまりにし、ラベルに幅を戻す。 |
| 文字の色とコントラスト | 淡い青白・銀白の字の芯と直下の背景を、透明度反映後の色で比較する。C2の制作基準は見出し・本文・対話・小ラベルを含む情報文字すべてで **4.5:1以上**。場所によって下地が違うときは最も読みづらい部分で測る。 | 黒い余白へ移すか、文字の不透明度・太さを上げる。黄色・金色、発光や縁取りによる補強は禁止。 |
| 純黒の余白 | 原寸PNGの前景のない四隅、上下、中央付近の空き領域でRGBがすべて0。アルファがある場合は255。輪郭のアンチエイリアスは測定点から外す。 | 最背面の塗りと前景マスクを確認し、余白にかかった霧や色補正を外す。 |
| 主図と読み順 | 見出し → 質問と回答 → 中央の医学図 → 下部の要点を迷わず読める。比較図なら同じ場所を見比べられ、拡大図なら元のどこかを指せる。投稿画面のプレビューでも文字・結論・対象部位が操作ボタンに隠れない。 | 衝突するラベルを黒い余白へ移し、引き出し線を短くする。図に使える面積を戻し、飾り枠を減らす。 |
| 透明な解剖と色の意味 | 外壁越しに内腔や病変の位置が分かる。矢印がある場合は起点・終点を指でたどれる。グレースケール表示でも形・位置・短いラベルから対象を識別できる。 | 隣接する膜の縁だけ濃くする。形や凡例を補い、色のにじみや画面全体の光彩を除く。 |

**測定の例**　コントラストチェッカーに、完成画像の字画内部と、その文字の下地のsRGB値を入力する。下地が隠れている場所は、同じ位置で文字レイヤーだけを一時非表示にして採色する。細い縁の中間色を字の代表値にしない。基準値を満たしても「⁺」や「⁻」がつぶれるときは、スマホ幅の目視を優先して修正する。比率の算定は [W3Cのコントラスト解説](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) による。

各ページで原稿・単位・矢印・凡例を照合し、読めない箇所を直して同じ表示条件で再確認する。記録例は「3枚目／幅360pxプレビュー／ラベルを右余白へ移動／最小比率〔実測値〕／再確認結果」。数値と合否は実測後に記入する。
