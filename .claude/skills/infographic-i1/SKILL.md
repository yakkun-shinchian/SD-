# インフォスキル I1

## 目的とM1との区別

完成した一枚の資料を先生が指しながら説明する自然な講義動画にする。看護学生・新人看護師が「何なのか→どこを見るのか→なぜ大事なのか」を理解できる順番にする。M1の会話イラスト・吹き出し全文読み上げ・人物モーションを自動適用しない。この方式はI1として扱う。

## 原図を保持する

- 元画像を実際に確認し、文章、図、写真、イラスト、レイアウトを100％保持する。AIでの再生成・文章修正・差し替え・描き直しは禁止する。
- 原図とは別の一時的な解説レイヤーだけを追加する。医学的な誤りを見つけた場合も勝手に原図を直さず、根拠を確認してユーザーへ伝える。
- 初めと終わりは原図全体を見せる。途中は説明対象が読める位置へ穏やかに寄り、縦横比を変形しない。原図の画素を編集することとカメラの切り取りを区別する。
- 画角・尺は今回の指定を優先する。指定がなければ元画像の縦横比を保持し、不要な字幕帯を足さない。30秒へ固定しない。

## 4色の蛍光ペンと丸囲み


- 下線は赤・黄・緑・青の透明感のある蛍光ペンを標準とする。4色を説明対象に合わせて積極的に使い分け、同時に多箇所を強調しない。元図の色の意味を優先し、色だけで意味を伝えない。
- きれいで均一な半透明の帯を、左から右へ「スッ」と伸ばす。ガタガタしたマジック線、乱雑な手描きノイズ、不透明な塗りつぶし、重ね塗りによる濁りを避ける。文字と数値が透けて読める太さ・透明度にする。
- 実装の初期目安は1080px幅で線幅10〜16px、不透明度35〜55％、描画時間0.3〜0.6秒。赤 #FF507E、黄 #FFED00、緑 #42ED77、青 #39BFFFを候補とし、背景との視認性に合わせて調整する。均一な線・滑らかな端・アンチエイリアスで整える。
- 重要語や図は、きれいな円・楕円が「クルッ」と描かれる丸囲みで示す。対象に余裕を持たせ、隣の項目を巻き込まず、文字を横切らない。丸囲みを廃止して全て下線に置き換えない。
- 完成音声の該当語を話し始める瞬間に描画を開始する。説明より先に強調を完成させない。強調は原則1対象ずつとし、次の説明へ移る際に前の線や丸を自然に薄くするか消す。色数を増やしても強調を画面へ蓄積しない。
- 必要な指差し・矢印・カメラ寄りも同じ対象と発話に同期させる。目的は「先生が資料を指しながら教える」視線誘導とする。
- 既存インフォグラフィックをそのまま解説する依頼では、原図を不変の背景として使用し、文章・図・写真・レイアウトを再生成や描き直しで変更しない。効果は一時的な別レイヤーとして重ねる。局所の描き直しや病態アニメーションを無理に追加せず、同期した線・丸の描画を説明モーションとして扱う。
- この解説型では全項目の棒読みや図中の番号の読み上げを既定にしない。重要点を台本化する。下部字幕は指定がなければ追加しない。会話イラストの吹き出し全文音声ルールとは適用対象を区別する。尺・画角は今回の指定を優先する。
- 書き出した動画で線の伸長、丸の描画、4色の見え方、文字の可読性、発話との同期、前の強調の退場を確認する。原図を改変していないことも確認する。


## 台本と音声

- 全項目を読み上げず、臨床で重要な因果関係を優先する。元画像にない医学情報を無断で追加しない。必要な補足や正確性の確認は一次資料で検証する。
- 図中の番号は原則読み上げない。下部の字幕や新しい説明文は指定がない限り追加しない。専門用語の羅列を避ける。
- 既定の解説音声はCoeFont「後藤邑子」。ユーザーの「後藤さん」を別の似た名前に置き換えない。新規プロジェクトから開始してよい。サービス上の選択名を確認してから生成する。別サービスや別音声を無断で代用しない。
- 落ち着いた先輩看護師の自然な速さを優先する。尺の指定がある場合は台本と間を調整し、発話を途中切断しない。
- 冒頭は今回の教材の疑問や要点を短く提示する。本編は1ポイントずつ説明し、終盤で要点を復習して全体へ戻す。
- 保存・フォローを促すナレーションは標準では入れない。「インフォグラフィックを保存して、あとで見てね」「フォローよろしくお願いします」や同趣旨の言い換えも自動追加しない。今回の依頼で明示された場合だけ入れる。従来の必須CTAルールよりこの既定を優先し、指定尺は本編の要点説明に使う。締めは内容の要点で自然に終え、最後は原図全体を見せる。保存・フォローの字幕や終了カードも代わりに自動追加しない。
- 配布リンクやダウンロード可能な原図を実際に用意していない場合は配布済みと報告しない。

## 制作と検収

1. 原図・解説範囲・対象者・声・尺・画角を確認する。今回の指示から明確な部分は再確認しない。
2. 台本を作り、完成音声に合わせて「該当語、開始時刻、終了時刻、原図上の対象領域、色、線または丸、退場時刻」を対応付ける。推定時刻だけで同期済みとしない。
3. 原図を不変の背景として、滑らかな蛍光ペン・丸囲み・必要なカメラ移動を合成する。カメラが動いても強調位置を対象に追従させる。
4. 完成MP4の冒頭、本編の各強調、切替、復習、終端を確認する。発話より先行しないこと、字を隠さないこと、1対象ずつ示すこと、丸と4色が自然に使われることを検品する。
5. 出力の解像度、ピクセル比、フレームレート、音声、尺、再生可能性を確認する。実施していない聴取・再生確認を完了と報告しない。動画と編集データを保存し、完成ファイルを提示する。
