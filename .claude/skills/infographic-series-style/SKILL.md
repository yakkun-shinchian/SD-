# C1・C2・C3の背景と投稿文

## 背景は全面を純黒にする

- 新規制作でも修正でも、生成プロンプト、編集用テンプレート、書き出しの背景を **不透明な単色の純黒 `#000000`（sRGB 0, 0, 0）** にそろえる。余白・画面端・上下左右の帯も同色。旧テンプレートにあるネイビー、青黒、背景の7色グラデーション、色付きの霧やビネットは外す。
- グラデーション、透け感、発光は人体・臓器・血管・図形などの対象に局所的に使う。画面全体に光やカラー補正をかけて背景を染めない。
- 制作中は黒の背景レイヤーを最背面に置く。納品前に原寸のPNGを開き、前景のない四隅・上下の余白・中央付近の空き領域をスポイトで確認する。背景のRGBは3値とも0、アルファがある場合は255。文字・臓器の輪郭は背景の測定点から外す。
- 不透明な原図に青みが焼き込まれている場合は、組版前の素材に戻って背景を純黒にするか、前景をマスクして合成し直す。暗い血管や陰影まで色域で一括置換しない。動画は純黒の下地で合成し、書き出し映像でも余白の色かぶりを確認する。

## キャプションの末尾に2行を付ける

本文、空行、キーワード行、空行、ハッシュタグ行の順にまとめる。本文には題材に合う絵文字を使う。キャプション・キーワード・ハッシュタグの見出しは付けない。

- キーワードは5つ。1行に半角スペースで並べ、**5つ全体の直前と直後に半角アスタリスクを3つずつ**置く。
- ハッシュタグも5つ。各タグは半角 `#` で始め、半角スペースで並べる。**5つ全体の直前と直後に半角アスタリスクを3つずつ**置く。
- アスタリスクと最初・最後の語の間に空白を入れない。各語を個別に囲まない。投稿本文・改行・絵文字・記号を合わせて500文字以内。前後編は各投稿で数える。チャットでは1投稿を1つのプレーンテキストのコードブロックで渡し、コピー後にも12個のアスタリスクが残るようにする。

```text
🧠 脳梗塞のしくみを、血管の図でたどってみましょう。

***脳梗塞 血栓 塞栓 脳血流 看護観察***

***#脳梗塞 #脳卒中 #脳神経看護 #新人看護師 #看護学生***
```
