# Instagram V5

## 最上位原則

毎回きれいな別作品を作るのではなく、同じシリーズを再現する。

次の優先順位を固定する。

1. 今回ユーザーが添付し、視覚基準に指定した画像
2. `assets/visual-reference-lock/` の固定10枚
3. 今回の医学内容に必要な構図調整
4. AI独自の美的判断

「より洗練する」「より現代的にする」などの理由で別テイストへ進化させない。参考画像と矛盾する一般的な文章指示があれば、参考画像に実際に見えている特徴を採用する。

## 制作前に必ず行うこと

1. `references/visual-reference-lock.md` を最後まで読む。
2. `references/generation-contract.md` を最後まで読む。
3. 10枚カルーセルでは固定10枚をすべて `view_image` で確認する。単ページでは少なくとも `01-cover-hook.jpeg`、`03-flora-definition.jpeg`、`10-summary.jpeg` と、そのページの役割に近い1枚を確認する。
4. ユーザー添付の参考画像があれば必ず確認する。未読のまま生成を始めない。
5. 台本を「見出し／発言者／吹き出し／医学図解／矢印／下部まとめ」に分け、画像内へ入れる正確な文字列を確定する。

この手順を Visual Reference Lock とする。参考画像を単なる雰囲気資料として扱わない。

## 制作ワークフロー

### 1. 内容を整える

- 1枚1メッセージにする。
- **結論を冒頭へ置く。** 教育カルーセルでは最初の1〜2枚で「結局何を覚え、現場でまず何をするか」を明示する。最終ページにしか出ない臨床的な結論や行動を作らない。最終ページは初出の答えではなく短い再確認と締めに使う。
- 台本が「問い→長い仕組みの説明→最終ページで初めて実践的な答え」という順序なら、生成前に冒頭へ要点を移し、その後に理由・例・注意点を配置し直す。元の台本の重要な意味を落とさず、ページ数の範囲で組み替える。ユーザーが明示的に順序固定を求めた場合はその指定を優先する。
- 緊急対応では、発見直後の安全確保・応援要請・観察と、特定の時間基準による治療判断を区別する。薬剤名は適応と医師の指示・院内手順の条件を添えて早期に示し、誰にでも直ちに投与するような表現にしない。
- 見出しは原則1〜3行、吹き出しは1人1個・2〜3行を目安にする。
- 文字が多い場合は文章を短くするかページを分ける。文字を小さくして押し込まない。
- 医学内容を絵の都合で変更しない。臨床上重要な修正が必要なら生成前に明示する。
- 英語・略語はユーザーのルールに従い、初出時に読みと日本語を添える。
- 10枚構成の最後の1枚では、医学的な結論の後に後輩の吹き出しで「フォローしていただくと励みになります。よろしくお願いします。」と一字一句そのまま添える。別の11枚目は増やさない。ユーザーがその回に別の締めを指定した場合は、その指定を優先する。

### 2. 参照画像を固定する

- 全ページ共通アンカーとして `01-cover-hook.jpeg`、`03-flora-definition.jpeg`、`10-summary.jpeg` を使う。
- ページの役割に応じて固定10枚から追加で1枚を選ぶ。
- 画像生成ではローカル参照を `referenced_image_paths` で渡す。
- シリーズ全体で参照アンカーとスタイル文を変えない。ページごとに新しい美的形容詞を足さない。
- 参考画像の腸・花・菌・カプセルなどテーマ固有物は、今回のテーマと無関係ならコピーしない。

### 3. 1枚ずつ生成する

- 新規生成と画像修正には `image_gen` を使う。
- `references/generation-contract.md` のプロンプトを使い、内容欄だけを差し替える。
- 新作は縦16:横9（幅:高さ=9:16）、1080×1920px、フルブリードで最初から構成する。既存の4:5絵を中央へ配置して上下にぼかし帯や空白を残さない。
- 参考10枚が4:5でも参照するのは絵柄・人物・文字の筆致。上下を自然な病棟背景、会話、図解で描き足して9:16に再構成し、左右を切って文字・顔・図解を欠けさせない。
- リールやYouTubeショートの表示を考え、下端約250pxと右端約120pxに重要な文字を置かない。背景の絵は端まで描く。
- タイトル、人物、吹き出し、医学図解、矢印、結論の視線順を保つ。
- 最初の承認済みページをシリーズ内アンカーとして扱い、後続ページで人物の顔立ち・髪型・スクラブ色・画材感を変えない。

### 4. 毎ページを原寸検品する

生成後は必ず `view_image` で確認し、次を順に判定する。

1. 画像内の日本語が台本と一字一句一致するか。
2. 見出しが固定10枚と同じ太い手描きマーカー調か。
3. 見出しが濃紫とピンク〜赤を主役にし、橙・黄を補助にしているか。
4. 吹き出しが白地・横長・少し不均一な自然形で、硬い箱や完全な楕円ではないか。
5. 吹き出し本文が濃紺の読みやすい手書きマーカー調か。
6. 先輩・後輩の顔立ち、髪型、年齢感、左右、スクラブ色が固定されているか。
7. 顔・髪・手・重要な医学図解を文字や吹き出しが隠していないか。
8. 医学図解と矢印が台本どおりで、誤解を招かないか。
9. スマホ縮小表示でも主要文が読めるか。
10. 固定10枚の間へ差し込んでも違和感がないか。

最終ページは、後輩の締めの一言が正確に入り、人物の顔・医学的結論・下端の表示安全域に重なっていないかも確認する。

10番を SERIES MATCH 判定とする。1項目でも不合格なら完成扱いにしない。

### 5. 局所修正する

- 修正箇所だけを明示し、構図・人物・背景・医学図解・配色を保持する。
- 誤字修正のためにページ全体を再設計しない。
- 見出しの筆致、吹き出し形状、人物の顔立ちがずれた場合は、その要素を最優先で戻す。
- 修正後も10項目を再確認する。

### 6. 納品を検証する

- 10枚ならファイル名を `01_...` から `10_...` まで連番にする。
- JPEGまたはPNGで書き出す。ZIPはユーザーが一括納品を求めた場合だけ作る。
- 書き出した画像を次で検証する。

```bash
python3 scripts/validate_carousel.py OUTPUT_DIR --expect-count 10 --require-sequence
```

## STYLE DRIFT禁止

- タイトルを通常のゴシック体、均一なベクターフォント、滑らかな虹色グラデーションへ変えない。
- 吹き出しを四角いカード、硬い角丸長方形、完全な円・楕円、ギザギザ爆発形へ変えない。
- 会話文を極太ゴシック、明朝体、細すぎるペン字、極小文字へ変えない。
- 先輩と後輩を別人化、左右反転、年齢変更、スクラブ色変更しない。
- 平坦な企業インフォグラフィック、Canvaテンプレート風、写実写真、テカテカした3Dプラスチック、アメリカンコミックへ寄せない。
- ページ全体や見出しを枠で囲まない。情報を何でもカード化しない。
- 黄色い蛍光マーカー下線を定番化しない。黄は短い筆跡・放射線・光のアクセントに限定する。
- 「もっときれいに」という内部判断で参考画像よりCG感や装飾密度を上げない。

## 完了条件

次の全条件を満たして初めて完成とする。

- Visual Reference Lock、Style Drift禁止、Series Match判定を通過する。
- 原稿と画像内文字が完全一致する。
- 9:16縦長の1080×1920pxで、上下にぼかし帯・空白がなく、主要要素が表示安全域内にある。
- 医学的因果関係と看護上の要点が正しい。
- 10枚を一覧表示しても、同じ人物・同じ画材・同じ文字・同じシリーズに見える。

## 固定の締め（必須）

- 作品の最終ページ・最終場面の医学的なまとめの後に、後輩の発話として「フォローしていただくと励みになります。よろしくお願いします。」を一字一句そのまま入れる。各ページには繰り返さない。
- 尺だけを理由に省略・短縮・言い換えをしない。動画では後輩の指定音声で全文を読み、末尾まで時間を確保する。納品前に表示と音声（動画の場合）の全文・話者・末尾を確認する。今回ユーザーが別の締めや省略を明示した場合はその指示を優先する。
