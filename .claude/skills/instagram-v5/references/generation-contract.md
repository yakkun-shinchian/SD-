# V5 generation contract

## 1. 参照画像の渡し方

新規ページでは次の3枚を共通アンカーにする。

- `assets/visual-reference-lock/01-cover-hook.jpeg`
- `assets/visual-reference-lock/03-flora-definition.jpeg`
- `assets/visual-reference-lock/10-summary.jpeg`

ページの役割に最も近い固定画像をもう1枚加える。ユーザーが今回の視覚基準を添付した場合は、その添付を最優先にし、固定アンカーは補助にする。

参照画像を「内容のコピー」ではなく、「文字、人物、吹き出し、線、色、余白、密度のロック」に使う。

## 2. 新規生成プロンプト

角括弧の内容をページごとに置き換える。V5固定文は削らない。

```text

--- V5固定デザイン ---

大見出しは画面最上部へ直接置き、太いカラーマーカーまたは平筆で丁寧に手書きした日本語にしてください。線幅を完全均一にせず、わずかな筆圧、かすれ、インクだまり、丸みある筆端を持たせてください。通常のゴシック、均一なベクターフォント、毛筆、子どもの落書きにはしないでください。

見出し色は参照画像どおり、濃い紫と鮮やかなピンク〜赤を主役にして語句または行ごとに切り替えてください。青紫は補助、オレンジと黄色は短い放射線や小さなアクセントだけに使ってください。全体を虹色、単色、滑らかな一直線グラデーションにしないでください。

吹き出しは温かい白地、横長の自然な楕円〜丸みある不定形、少しだけ手描きの揺れを持たせてください。後輩は青紫、先輩はコーラルピンクの細い色鉛筆／マーカー風輪郭と短い尻尾にしてください。完全な楕円、硬い台形、角丸長方形、四角いカード、ギザギザ形は禁止です。

吹き出し本文は参照画像どおり、濃紺の読みやすい中太手書きマーカー調にしてください。タイトルより細く、細いペン字より太くしてください。極太ゴシック、明朝体、教科書体、小さい文字は禁止です。重要語だけピンク〜赤にしてよいですが、黄色い蛍光下線は使わないでください。

後輩は必ず左。20代前半〜半ばの日本人女性、顎付近の短いダークブラウンのボブ、軽い前髪、淡い青紫〜ペリウィンクルのVネックスクラブ。先輩は必ず右。20代後半〜30代前半の日本人女性、ダークブラウンの低いポニーテールと柔らかな後れ毛、濃紺のVネックスクラブ。参照画像と同じ顔立ち、年齢感、髪型、スクラブ色に固定し、自然に見つめ合って会話させてください。

背景は参照画像と同じ、明るい日光の入る病棟またはナースステーション。白〜アイボリーの光、緑、ぼけたモニターやスタッフで奥行きを出し、人物と文字より一段弱くしてください。

医学図解は画面の30〜50%で大きく、一目で分かる形、明るい発色、柔らかな発光、参照画像と同程度の親しみやすい立体感にしてください。内容に必要な矢印だけを太く単純に描き、交差させないでください。参照よりCG感、光沢、装飾を強めないでください。

見出し、吹き出し、人物の顔、手、重要図解を重ねないでください。外周枠、見出しの箱、情報カードの乱立、企業プレゼン風、Canvaテンプレート風、平坦なベクター、写実写真、アメリカンコミック、プラスチック3D、読めない名札、余分な人物、重複した手足、透かし、ロゴを入れないでください。

画像内の日本語は上記の指定文字列と一字一句同じにしてください。勝手な言い換え、補足、英訳、意味不明文字を追加しないでください。
```

## 3. 局所修正プロンプト

```text
YAKUBON STUDIO Visual Reference Lock V5を維持してください。構図、人物の顔と髪、スクラブ、背景、医学図解、矢印、配色、余白は変更せず、次の箇所だけを局所修正してください。

【修正対象】
[例：上部見出しの2行目]

【正しい内容】
「[正確な文字列]」

【維持条件】
- 大見出し：濃紫とピンクを主役にした太い手描きマーカー調
- 吹き出し：白地、横長の自然な不定形、細い青紫／ピンク輪郭
- 会話文：濃紺の読みやすい中太手書きマーカー調
- 先輩・後輩：顔立ち、髪型、左右、スクラブ色を完全保持

修正対象以外を再設計しないでください。新しい文章、装飾、人物、ロゴを追加しないでください。
```

## 4. 生成後の判定文

各ページを次の一文で判定する。

> この1枚を固定10枚の任意の位置へ差し込んだとき、文字だけを見ても、吹き出しだけを見ても、人物だけを見ても同じシリーズに見えるか。

どれか一つでも「いいえ」なら修正する。医学内容が正しくても、シリーズ不一致の画像を納品しない。
