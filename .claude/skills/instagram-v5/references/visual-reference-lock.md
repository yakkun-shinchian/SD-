# Visual Reference Lock V5

## 1. 参照の扱い

`assets/visual-reference-lock/` の10枚を、V5のデザイン上の正解として扱う。内容を模写するのではなく、次の視覚DNAを固定する。

- 見出しの筆致、太さ、改行、色分け
- 吹き出しの白地、輪郭、縦横比、尻尾
- 吹き出し本文の文字量、太さ、色
- 先輩・後輩の顔立ち、髪型、服、左右関係
- 明るい病棟背景と奥行き
- 人物、会話、医学図解の占有率
- 下部まとめの置き方
- 全体の華やかさ、余白、情報密度

参考画像より「きれい」「モダン」「高級」「3D」に作り替えない。V5の成功は独創性ではなく再現性で測る。

## 2. キャンバスと画面文法

- 縦16:横9（幅:高さ=9:16）。標準納品は1080×1920px。固定参考10枚が4:5でも絵柄と人物だけを参照し、構図は9:16用に上下へ自然に広げる。
- フルブリード。外周フレーム、ページ枠、白い外周カードを置かない。
- 既存の4:5絵を中央に置いて上下をぼかし・無地の帯で埋めない。文字や顔を切るような横方向の拡大もしない。
- 左端約5%、上端約8%、下端約250px、右端約120pxを重要要素の安全域とする。周辺には自然な背景を描く。
- 基本の視線順を「大見出し → 会話 → 人物の表情・手 → 医学図解 → 下部結論」とする。
- 目安の占有率を次とする。
  - 大見出し：上部18〜25%
  - 吹き出しと人物：中央25〜40%
  - 医学図解：下部または中央下30〜50%
  - 下部まとめ：必要なページのみ下端8〜14%
- ページの役割により重ねてよいが、文字同士・顔・重要図解を衝突させない。

## 3. 大見出しの文字を最優先で固定する

### 形

- 太いカラーマーカーまたは平筆で、人が紙へ丁寧に一気書きしたような日本語にする。
- 通常のゴシックフォントに見せない。
- 線幅を完全均一にせず、筆圧、わずかなかすれ、インクだまり、丸みのある筆端を残す。
- 子どもの落書き、荒い筆文字、筆ペンの毛筆、可愛い丸文字にはしない。
- 参照10枚のように、力強く、親しみやすく、遠目で即読できる字形にする。
- 文字へ縁取り、立体影、ネオン発光、金属質感を加えない。背景との分離は淡い白い光または余白で行う。

### 大きさと改行

- 1080px幅換算で文字高95〜155pxを目安にする。
- 原則1〜3行。1行あたりを詰め込みすぎない。
- 行間を狭めすぎず、上端や左右端で文字を切らない。
- 疑問符、感嘆符、引用符も同じマーカー質感にする。

### 色

実物の主役は「濃い紫」と「鮮やかなピンク〜赤」である。青、オレンジ、黄色を均等に並べた虹色へ変えない。

- 主色A：deep violet `#3A00A8`〜`#4A08C7`
- 主色B：hot magenta `#F00062`〜`#FF236F`
- 補助色：indigo `#2836B8`〜`#354FE0`
- アクセント：orange `#FF7A00`〜`#FF8A22`
- アクセント：yellow `#FFD229`〜`#FFE24A`
- 会話・結論の濃色：navy `#07185E`〜`#11206D`

色は滑らかな一方向グラデーションで塗らず、語句・行・意味のまとまり単位で切り替える。見出しは通常2色を主役にし、橙・黄は短い放射線、感嘆符、短い筆跡に少量使う。オレンジや黄色を長文の本文色にしない。

### 見出しの判定

固定10枚のタイトルだけを切り出して並べたとき、新作のタイトルが11枚目として自然に混ざることを要求する。筆致が違えば、人物や図解が美しくても不合格とする。

## 4. 吹き出し

### 形

- 温かい白 `#FFFDF9` の不透明な塗りにする。
- 横長の自然な楕円〜丸みのある不定形を基本にする。
- 上下辺をわずかに揺らし、左右の膨らみを完全対称にしない。
- ページ内容により少し台形寄りになってよいが、「台形」を機械的な固定形にしない。
- 完全な円、CADの完全楕円、角丸長方形、硬い四角、ギザギザ爆発形を禁止する。
- 尻尾は短く、白地と連続させ、発言者へ自然に向ける。顔へ突き刺すような長い尻尾にしない。

### 輪郭

- 1080px幅換算で4〜7px程度にする。
- 細い色鉛筆またはマーカーで一周したような、わずかな揺れとかすれを持たせる。
- 後輩側は青紫 `#5C5EEA`、先輩側はコーラルピンク `#F04F70` を基本にする。
- 役割色はシリーズ全体で入れ替えない。

### 配置

- 発言者が瞬時に分かる位置と尻尾にする。
- 顔、目、髪、手、重要な医学図解へ重ねない。
- 人物との間に不自然な空白を作らず、会話している距離に置く。
- 吹き出しをページ端へ密着させない。

## 5. 吹き出し本文

- 濃紺の手書きマーカー調にする。
- タイトルより明確に細くするが、実物は「細いペン字」ではなく、スマホで読める中太の丸みある筆致である。
- 一般的な極太ゴシック、明朝、教科書体、均一なデジタル丸ゴシックにしない。
- 1080px幅換算で原則50〜72px、最低48pxとする。
- 1吹き出し2〜3行、全角30〜38字程度を目安にする。
- 重要語だけをピンク〜赤にしてよい。多色化、下線乱用、黄色マーカー帯を避ける。
- 行末・句読点・疑問符を含め、ユーザー原稿と完全一致させる。

## 6. 固定キャラクター

### 後輩・左

- 20代前半〜半ばの日本人女性看護師。
- 顎付近の短いダークブラウンのボブ、軽い前髪。
- 淡い青紫〜ペリウィンクルのVネックスクラブ。
- 大きめだが自然な茶色の瞳。驚き、疑問、発見、納得を表情と手で示す。
- 質問・確認・気づきを担当する。

### 先輩・右

- 20代後半〜30代前半の日本人女性看護師。
- ダークブラウンの長髪を低いポニーテールにし、顔周りに柔らかな後れ毛を残す。
- 濃紺のVネックスクラブ。
- 穏やかな笑顔、自信、安心感を持ち、指差しや開いた手で説明する。
- 解説・整理・結論を担当する。

### 共通固定

- 顔立ち、髪型、左右関係、スクラブ色をページ間で変えない。
- 明るく上品な日本アニメ寄りの半写実デジタルペイントにする。
- 肌と髪へ参照と同程度の柔らかな立体感を付けるが、プラスチックのような光沢を増やさない。
- 名札に読める個人名を生成しない。
- 手指の本数、関節、腕の接続、視線を検品する。
- 同じ人物を1枚の中で重複生成しない。

## 7. 背景

- 明るい病棟、ナースステーション、処置室を基本にする。
- 大きな窓、白〜アイボリーの日光、緑、ぼけたモニターやスタッフで奥行きを出す。
- 背景は人物と文字より一段弱くぼかす。
- 暗い病室、冷たい青灰色、黒背景、無機質な企業プレゼン背景へ変えない。
- ページごとに病院の建築様式や時間帯を大きく変えない。

## 8. 医学図解

- 主概念を画面の30〜50%で大きく見せる。
- 臓器や器具は一目で認識できる形を保ち、参照と同程度の明るい発色、柔らかな発光、親しみやすい立体感を使う。
- 原因→変化→結果は太く単純な矢印で示し、交差させない。
- 擬人化した菌や細胞は内容に必要な場合だけ使う。善悪の単純化が誤解を生む場合は表情や色だけで断定しない。
- 見本の腸、花、菌、カプセルを別テーマへ飾りとして流用しない。
- 過剰なCG、金属反射、透明プラスチック、ゲーム画面風へ強めない。

## 9. 下部まとめ

- 必要なページだけ置く。
- 背景の白いぼかしまたは自然な明部へ直接載せ、カードで囲まない。
- 濃紺を基本にし、結論語だけピンク〜赤にする。
- タイトルより一段小さい太めマーカー調にする。
- 左右端や下端で文字を切らない。

## 11. 最終比較順序

新作を固定10枚と並べ、違和感がある場合は次の順で直す。

1. タイトル文字の筆致
2. タイトルの濃紫・ピンク中心の色分け
3. 吹き出しの形と輪郭
4. 吹き出し本文の書体感と大きさ
5. 先輩・後輩の顔・髪・服・左右
6. 医学図解の大きさと発色
7. 余白と画面密度
8. 背景の明るさと奥行き

この順序を変えない。特に1〜4を最優先とする。
