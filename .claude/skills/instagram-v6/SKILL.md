# Instagram V6｜会話イラスト制作

## 役割と優先順位

このスキルは静止イラスト制作を担当する。V5のシリーズ、先輩・後輩の人物、色、画材、見出し、自然な白い吹き出しを保持し、動画効果のために絵柄や構図を大きく変えない。

1. 今回ユーザーが指定した参照・内容・サイズ
2. `instagram-v5` の固定参照と制作・検品契約
3. 本スキルの工程分離

## 必須の基準読み込み

## Visual First｜説明するな、見せる（標準仕様）

- 医学的内容は削らず、文字を削る。制作の優先順位を「イラスト → 図解・矢印 → 人物の表情・リアクション → キーワード → 必要最小限のセリフ」とする。人物と絵柄の参照固定は保持する。
- 1枚＝1メッセージ。後輩のセリフは原則2行、先輩は2〜3行、多くても各2〜3行程度。追加説明が必要なら、文字を増やす前に医学図、血流、色分け、アイコン、模式図、Before/After、↑↓、渋滞・水の比喩で示せないか検討する。字を縮小して詰め込まない。
- 確定済みの台詞、伸ばし文字、ユーモア、感情は無断短縮しない。文字量の制限と衝突する場合は図解へ移せる説明を整理し、必要な医学的修正を明示する。図中の長文で実質的な文字量を増やさない。
- 後輩女性1人＋先輩女性1人を維持し、リアクション用の同一人物の小像も追加しない。「？？？」「あっ！」「違うーーー！！」、焦り、驚き、苦笑い、納得を顔・姿勢で演じ、感情のために説明文を増やさない。
- 比喩と生理現象を区別する。血流・圧の伝播・カテーテル進行の矢印は意味を区別し、解剖学的位置関係と方向を確認する。条件付きの因果を無条件の矢印にせず、必要な条件・安全上の注意を短い図中ラベルで保持する。
- 完成前に各ページを①セリフ量、②図だけで主旨が伝わるか、③医学的位置関係・血流方向、④台本順、⑤同一人物の重複なしの5項目で検品する。台本順を勝手に並べ替えない。

## 言葉遊び・比喩・例え話を豊富に使う（標準仕様・必須）

- 台本作成・内容整理の段階から、言葉遊び、語呂合わせ、比喩、身近な例え話を積極的かつ豊富に組み込む。追加依頼を待たず、シリーズ全体で繰り返し活用する。確定台本では既存のユーモアを保持し、無断で発話を追加・改変しない。
- 渋滞、蛇口、排水、ポンプ、配送、鍵と扉など、説明する仕組みに対応する例えを選び、会話だけでなく大きな補助イラスト・図解でも見せる。単に面白いだけのダジャレを足さず、「なぜそうなるか」が覚えやすくなる表現にする。
- 比喩の各要素と医学的な対象を短く対応付ける。比喩だけで説明を終えず、正しい用語と結論へ戻す。生理現象と異なる部分や比喩の限界は必要に応じて短く示し、誤った因果・断定・語呂のための医学情報改変を避ける。
- 1枚＝1メッセージ・会話1往復を守る。各説明場面で比喩や言葉遊びの候補を検討し、理解を助けるものを採用する。無理な挿入でセリフを長くしたり、複数の比喩を混ぜて理解を妨げたりしない。患者の苦痛を笑いの対象にしない。

## 正確な表・グラフ・イラストを多用する（標準仕様・必須）

- 表・グラフ・イラストを説明の中心として積極的に多用する。台本の各場面に、主となる視覚資料、伝える関係、図中ラベル、根拠を指定する。比較は表、量や時間による変化はグラフ、機序・位置・作用点はイラストや模式図を選び、1枚にすべてを詰め込まずシリーズ全体で活用する。
- 教科書で扱われる標準的な図表や関係を、意味・条件・例外を保ってわかりやすく再構成する。実際の教科書を参照した場合は書名・版・該当箇所を記録し、未確認の資料を「教科書掲載」と称さない。原図をそのまま写すことを既定にせず、学習目的に合わせて独自に整理する。
- 医学的内容は教科書、公式ガイドライン、添付文書、原著などで確認し、出典・確認日を台本や制作メモに残す。数値・基準値・単位・対象集団・測定条件・比較条件・重要な例外を省略や創作で変えない。最新性を要する情報は制作時に確認する。
- グラフは軸名・単位・目盛・凡例・曲線や点の対応を確認する。軸の切り詰め、面積、傾き、曲線の形で関係や効果量を誇張しない。実測データ、計算例、概念的な模式図を区別し、模式図には「模式図」、仮の数値には「説明用の仮例」と明示する。架空の数値を実測値として見せない。
- 表は比較項目と条件を揃え、違い・共通点・例外を読み取れるようにする。長文をセルへ詰めず、読み切れない表は分割する。図と会話で用語、色、方向、数値を一致させる。
- 手書き風は理解と可読性が上がる場合に選ぶ。軸・目盛・文字・罫線が曖昧になり見づらくなる場合は、整った線・明瞭な文字の図表を使う。親しみやすさのために正確さを犠牲にしない。
- 正確な数値グラフや精密な表は、検証済みデータと決定的な描画・組版手段で作成し、画像生成だけに数値、目盛、軸、表の文字の正確さを委ねない。人物や補助イラストの新規生成・編集には従来どおりimage_genを使用する。
- 納品前に①理解を助ける言葉遊び・比喩・例え話、②表・グラフ・イラストの活用、③出典と数値・軸・単位・条件、④比喩と実際の病態の区別、⑤スマホでの可読性を検品する。装飾の量でなく、図を見ることで理解できるかを判定する。

## 基準参照の読み込み手順

- 個人スキルから正式名 `instagram-v5` のSKILL.mdを解決して読む。表示一覧にない場合も個人スキル内のnameで検索する。
- そのスキルの `references/visual-reference-lock.md` と `references/generation-contract.md` を読み、対象ページに必要な固定画像を実際に確認する。これらを雰囲気だけの資料として扱わない。
- V5の内容整理、結論の早期提示、参照アンカー、1枚ずつの画像生成、原寸検品、局所修正、Series Match判定、出力検証を実行する。検証スクリプトや素材は解決したV5のディレクトリから使う。未確認の別テイストへ変更しない。

## イラスト制作と検品

- 台本の見出し、先輩・後輩の発話、医学図、図中ラベル、静止矢印、結論を整理し、正確な日本語を確定する。
- 人物の会話と表情を主役にして画像生成・編集する。新規生成・画像修正はimage_genを使用する。
- 吹き出し全文と話者を正確に保つ。顔、手、図を文字で覆わず、文字を小さくして押し込まない。
- 文脈、感情、医学的意味に一致するイラストを使う。焦りの汗と症状としての発汗、震えとけいれん、比喩と実際の病態を区別する。医学的因果や矢印の向きを誤らない。
- 元の絵に必要な表情・症状・医学図・静止矢印は描いてよい。動画編集用のApple絵文字や炎・風・水等の動く効果を、この段階で焼き込まない。
- 毎ページの文字、話者、顔、配色、吹き出し、医学内容、スマホ可読性を確認し、V5の参照と同じシリーズになっているか判定する。
- 原則はV5に従う9:16、1080×1920。カルーセル等で今回別サイズの指定があればそちらを優先する。リール用途の「縦16：横9」も幅1080×高さ1920の縦9:16と解釈する。動画予定なら右120px・下250pxへ重要文字を置かない。
- 静止画像の依頼は画像の完成・検品で完了する。動画制作や音声生成を勝手に開始しない。

## 1枚に後輩1人・先輩1人を基本とする（必須）

- 各ページは後輩1人・先輩1人、合計2人を既定にする。同じ人物を複数のコマ、顔の挿入、リアクションの小像として繰り返し描かない。人物の反復が明示的に依頼された場合のみ例外にする。患者や医学図は必要に応じて追加できる。
- 会話は一往復を基本に、少ない吹き出しで伝える。会話が長い場合は制作前に内容を整理し、人物を増殖させたり文字を縮小したりして押し込まない。確定済みの台詞の無断短縮は禁止するが、ユーザーが短縮・削除を指示したらその最新指示を優先する。
- 会話を減らした余白には、テーマを理解するための大きな補助イラストを配置する。医学の用語だけを羅列せず、臓器・血管・薬剤・状態の変化などを絵で示す。原因・関連要因・治療を区別し、根拠のない因果矢印や断言を加えない。
- ユーザーが削除した「まだあるんですか」「今日はそこまで覚えなくていい」「よかった」などの会話を慣例として再追加しない。台本にない掛け合いで文字量を増やさない。
- 納品前に各人物が1回だけ描かれていること、吹き出し数、補助イラストの面積と可読性を検品する。

## 台本への忠実さと人間らしい演技（必須）

- 最優先原則を「医学的には正確。でも登場人物はちゃんと人間」とする。台本を単なる情報源として要約・再構成せず、セリフ・語尾・間・ユーモア・感情・リアクションまで含む演技台本として扱う。V5の内容整理を適用する際も、確定した発話を無断で短縮しない。

- 台本を、言葉・ユーモア・間・感情・演技指示を含む設計図として扱う。先輩のツッコミ、後輩の天然さ、焦り、照れ、困惑、苦笑い、安堵を無表情な説明へ置き換えない。
- 発話の伸ばし文字、言いよどみ、繰り返し、笑い、句読点、語尾を勝手に省略・平坦化しない。「違うーーー！！」を「違う！」に短縮しない。医学的な修正が必要な場合は修正箇所を明示し、ユーモアや感情のニュアンスを残す。
- 各発話について、原文・話者・感情・表情・視線・姿勢／手ぶり・吹き出し演出を制作前に対応付け、画像生成指示へ含める。文字だけでなく人物自身の顔と身体で演技させる。

| 台本の表現 | イラストで必ず反映する演技 |
| --- | --- |
| 「違うーーー！！」 | 原文の伸ばし文字を保ち、先輩が身を乗り出してツッコむ。強弱は文字や吹き出しでも表す。 |
| 「ダメ！！」 | 制止する手、切迫した表情、必要に応じた焦りの汗を描く。 |
| 「えっ!?」「うそ!?」 | 目を見開く、のけぞるなど、驚きが一目で伝わる姿勢にする。 |
| 「す、すみません……わからないです💦」 | 肩をすぼめ、視線が泳ぎ、手が落ち着かずワタワタする後輩を描く。 |
| 「ははは……😅」 | 満面の笑顔ではなく、眉・口元・視線で苦笑いを表す。 |
| 「なるほど！」 | 納得して表情が明るくなる様子を描く。 |

- 感情表現を豊かに使いながら、場面に存在しない感情や症状は足さない。絵文字・柄・背景効果も場面、セリフ、感情、医学的意味に一致するものだけを選ぶ。「かわいい」「目立つ」だけで追加せず、合うものがなければ入れない。
- 焦る医療者の汗を患者の冷汗と混同させず、ワタワタする身ぶりをけいれんとして描かない。患者の苦痛を笑いの対象にしない。
- 納品前に、台本と全ページを照合し、原文の短縮、ユーモアの欠落、苦笑いと笑顔の取り違え、感情と身ぶりの不一致を修正する。文字の可読性とV5の人物・絵柄も維持する。

### 医学的な誤認を避ける表現契約

| 表現 | 区別する対象と扱い |
| --- | --- |
| 後輩の焦りの冷や汗 | 患者の発汗とは区別し、誰の反応かを配置・表情で明確にする。 |
| 驚きによる震え | けいれんとは区別し、病的な運動として描かない。 |
| 炎の比喩 | 発熱とは区別し、比喩を患者の症状や体温として示さない。 |
| ❤️による感情表現 | 解剖学的心臓とは区別し、医学図の代用にしない。 |

- 文脈に合った絵文字・Apple絵文字系表現・炎・風・水・冷や汗・震え・太い矢印・スライドイン・ポップ・音声同期モーションの既存仕様を保持する。静止画の表情・身体演技はV6で描き、動く効果の合成は従来どおりM1へ引き渡す。
- 「ダメ！！」には制止する身体動作と必要に応じた✋・😱・💦、「えっ!?」「うそ!?」には驚きの演技と❗️・⁉️、「なるほど！」には明るくなる表情と必要に応じた💡・✨を対応付ける。全部を機械的に追加せず、台本の意味に合うものだけを選ぶ。
- 動画用の対応表には、効果の対象人物・意味・対応する発話・表示開始の音声キュー・終了キューを記載し、M1で音声タイミングと照合する。音声生成前に未確認の秒数を確定値として扱わない。

## M1への引き渡し

- 動画も依頼された場合は、まず静止イラストを完成・検品し、その後に正式名 `instagram-video-m1`（表示名「Instagram動画スキル M1」）を解決して読む。
- M1へ完成画像、ページ順、台本全文、吹き出しID・話者・原文、感情・演技の対応表、音声指定、指定尺を渡す。伸ばし言葉・間・笑い・ツッコミを音声と動きでも保持し、感情の出るタイミングに合わせる。既存画像を活用し、動画効果だけを理由に画像全体を再生成しない。
- 炎・風・水・冷や汗・Apple絵文字・背景効果・太い動く矢印・人物や医学図の控えめな微動・発光・電気・拍動・円や囲みの出現・重要語句の拡縮・ズーム・パン・フェード・スライド・バウンス・点滅・全文音声同期・動画書き出しはM1の工程とする。
- 「V6でイラストを作り、M1で動画にする」という依頼は、この順番で実行する。V6だけの完了を動画完成と報告しない。

## V6 固定CTA（標準仕様）

- 最終ページ／動画末尾には原則として、医学的なまとめの後に次の2文をそのまま入れる。
  - 「フォローしていただけると励みになります。よろしくお願いします」
  - 「わからないことはコメント・DMへどうぞ📩」
- 後輩の締めの発話として扱い、各ページには繰り返さない。省略・短縮・言い換えをせず、今回ユーザーが別の締めや省略を明示した場合はその指示を優先する。
- 動画化では、この2文を含む最終ページと台本をM1へ引き渡し、動画末尾にも両方を表示する。📩は表示用の絵文字として保持する。
- 納品前に、最終ページ／動画末尾の両文の全文、話者、スマホ可読性を確認する。

## このスキルを更新する際の保存・確認契約

- 正式名 `instagram-v6` の既存本体を特定し、既存仕様を保持して更新する。同名の別スキルを安易に作らない。
- スキル更新用の正式な保存手順と形式検証を実行し、保存先の本体を再読して追記内容が実在することを確認する。保存・再読が済むまで「追加済み」と報告しない。
- 別Workからの認識確認を求められた場合は、利用可能な独立した環境で名前による発見・読み込みを確認する。同じ作業環境の別エージェントによる確認はその範囲を明示し、別Workセッションの実測と混同しない。実際の別Workを起動・確認できない場合は未確認と報告する。
- 完了報告は、①更新した正式名称、②今回追加した項目、③保存・再読の確認結果、④別Workからの認識可否と確認範囲を区別して伝える。

## 女性キャラクターとシリーズの一貫性

- 先輩・後輩は、V5固定参照に沿ったいつもの女性看護師2人を既定にする。顔・髪型・制服・線・配色を参照と照合する。過去の引き継ぎ台本の「先輩男性」より2026-10-01の女性へ戻す訂正を優先する。音声名から人物の性別を推測しない。今後の明示的な別人物指定は優先する。患者の性別まで限定しない。
- 男性化・別人化した素材は画像修正工程で固定参照へ戻し、検品してからM1へ渡す。
- M1へは完成イラストの構図・人物・絵柄を維持して渡し、元絵の中の対象を動かす。指定のない独立した別動画、実写、別テイストの3Dへの全面切替を認めない。必要な補助図は元絵の線・色・画材に合わせる。
- 各ページで女性2人の同一性とシリーズの一致を検品する。スキルの更新と既存画像・動画の修正完了を区別して報告する。


## 1枚目のフックと保存用インフォグラフィック（標準仕様）

- 台本の1枚目には、対象者が「続きを見たい」と感じる短いフックを必ず置く。臨床の疑問、意外な事実、よくある誤解を使い、テーマ名だけの表紙にしない。恐怖・誇張・医学的な断言で釣らない。
- 1枚＝1メッセージと一往復の会話を保持し、フックに対する答えを2枚目から早期に示す。
- 保存用インフォグラフィックを台本に組み込み、全文の長文要約ではなく、その回の判断・比較・観察項目を一目で整理する。基準値、単位、重要な例外を正確に保つ。
- 2枚目で全体図や保存用資料を予告し、中盤に保存用の完成図を置く構成を既定案とする。読み切れない場合は分割し、今回のユーザー指定を優先する。
- 動画では「ここで一時停止。スクショして使ってね」と案内し、図を読める静止時間を確保する。スマートフォンで見て確認し、装飾や動く矢印で重要文字を隠さない。
- 「ダウンロードできます」「プロフィールから受け取れます」は実際に受け取れる導線を確認できた場合だけ使う。SNS動画から直接画像をダウンロードできるかのような表現をしない。
- 必要に応じて同じ図を使う約15秒の保存用動画を別案にする。音楽は利用可能な音源を選び、説明動画を置き換えず、別投稿の尺・読める文字量・目的を指定する。
- インフォグラフィックが再生増加の原因とは断定せず、保存率・共有率・視聴維持・フォロー獲得で検証する仮説として扱う。
- M1へフック、保存図のページ順、停止案内、静止表示時間の目安、実際の配布導線を引き渡す。
