# 線→丸→線→丸の段階構築

## イベント表の例

| 発話の要点 | 時刻（完成音声で確定） | 画面の変化 |
| --- | --- | --- |
| 心臓から送り出す | 9.80–10.45 | 心臓から第1の線が伸びる。丸1はまだ見せない |
| 血液の流れ | 10.45–10.80 | 線の先端に丸1が自然に現れる |
| その先の臓器へ | 11.20–11.85 | 丸1から第2の線が伸びる。丸2はまだ見せない |
| 臓器への血流 | 11.85–12.20 | 第2の線の先端に丸2が現れる |
| 観察点へつながる | 12.70–13.35 | 丸2から第3の線が伸びる |
| 観察すること | 13.35–13.70 | 丸3が現れ、全体図を短く保持する |

時刻は例に過ぎない。実際の台本と完成音声を基準に置き換える。「丸」は内容のあるV5式の円・小さな医学図・ラベルであって、意味のない飾りの点ではない。臓器と所見の因果が医学的に間違っていないか確かめる。

## 実装

- 各線は始点から終点へ向けてパス長の0→100%を表示する。RemotionならSVGの `strokeDasharray` と `strokeDashoffset`、または距離で補間したパスのマスクを使う。先端が移動して見えることが必要。
- 丸1の登場は線1が少なくとも90%まで到達した後。丸2は線2の後、丸3は線3の後。丸の入場には短い拡大・フェードを加え、直後は落ち着かせる。
- 前段の線と丸は次段の構築中も表示を維持。端と端を正しく結ぶ。どの線も人物の顔や吹き出しの文字を横切らない。
- 発話が短いなら線0.25〜0.6秒、丸0.15〜0.35秒を目安にし、単調な待ち時間を作らない。発話が長いときだけ距離と移動に時間を与える。

## 必ず確認する止め画

`line1 halfway`、`line1 complete / node1 absent`、`node1 present / line2 absent`、`line2 halfway`、`node2 present` を抽出する。続く段も同様。連続再生して声の内容とその瞬間の絵が一致するか検査し、図全体を最初から見せる動画を不合格にする。
