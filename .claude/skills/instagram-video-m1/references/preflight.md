# 投稿前検査：完成動画から証拠を取る

ユーザー提示の2026-09-30 VEEDメール10項目との照合に基づく補足。メール原文を別途検証したとは扱わない。以下の数値はM1の制作・検査用初期値であり、VEEDやInstagramの公式規格とは呼ばない。既存の構図・全文音声・医学的意味の契約を優先する。

## 10項目の対応（同じ条件を二重管理しない）

|項目|既存条件／追加する検査|
|---|---|
|冒頭1〜2秒のフック|冒頭黒画面禁止を継承。0〜2秒に問い・驚き・学習価値のいずれかが実際に読める／聞けるか追加確認|
|焼き込み字幕|吹き出し全文と対応表を継承。映像自体に発話内容が見えるか検査。全文吹き出しで満たせれば字幕を二重追加しない|
|無音を削ったテンポ|既存の無音短縮を継承し、無音区間を数値で抽出|
|画角|画面・構図の必須契約を唯一の基準として実ファイルと全フレームの変換を検査|
|音声ノイズ除去|ノイズ・クリッピング・処理による語尾欠損の検査を追加。不要な除去処理はしない|
|音楽・効果音|使用時だけ音声マスキングと使用権を確認。未使用は理由付きN/Aでよい|
|ズーム|意味のあるモーションと保護領域条件を継承し、予定した動きが出力に存在するか検査|
|読みやすい文字|既存のスマホ可読性を継承し、寸法・安全領域・コントラスト・表示時間を計測|
|B-roll|使用時だけ場面・台本との一致、権利、字幕遮蔽を検査。完成イラストで十分ならN/A|
|Brand Kit|指定済みのロゴ・色・字体・表記と照合。未指定の新しい規則やロゴを作らない|

## 入力と結果

既存の発話対応表・ショット表を再利用し、検査に必要な列だけ補う。動画のSHA-256、ツール名／版、検査日時、区間の開始終了秒、ページ／吹き出しID、測定値、閾値、判定、証拠ファイル、修正または確認理由を `preflight.json` に残す。再書き出し後はハッシュを更新して再検査する。

判定は PASS / FAIL / REVIEW / N/A。ツールなし・OCR失敗・音声認識未実施・測定不能をPASSにしない。FAILは修正、REVIEWは実際の再生・目視聴取で解決して理由を記録する。字幕可読性、動きの医学的意味、音声内容は数値だけで最終合格にしない。

## 画角・余白

```bash
ffprobe -v error -show_streams -show_format -of json final.mp4 > probe.json
ffmpeg -hide_banner -i final.mp4 -vf 'blackdetect=d=0.1:pix_th=0.10,cropdetect=limit=24:round=2:reset=1' -an -f null - 2> picture.log
```

- `probe.json` の主映像を既存契約と比較する。sample_aspect_ratio=1:1、回転メタデータ／display matrixの回転=0、r_frame_rateとavg_frame_rateも確認する。規定外はFAIL（ユーザー指定の別用途は指定値で判定）。全編デコードエラーもFAIL。
- 余白はcropdetectだけで合否を決めない（白帯を検出できず、暗い背景を誤検出する）。合成時の画像寸法・変換行列から全フレームの四隅が覆われることを検算し、保護領域が画面外や既存UI除外領域へ出たフレームを抽出する。覆えないフレームはFAIL。
- フラット動画しかない場合は辺ごとの低分散帯を連続フレームで抽出しREVIEWとする。検出器なしなら未検査と記録する。既存の開始・中間・終端・最大変位フレーム検品で白帯、カード化、文字切れを確認する。

## 字幕・焼き込み文字

- 各発話の表示区間・文字列・行数・最終出力上の文字サイズ・bboxを対応表に追加する。新規字幕は2行以内、文字サイズ50px以上を初期値とする。既存吹き出しを2行へ強制改稿しない。拡縮後サイズを検算する。
- 全フレームのbboxで画面内・既存UI安全領域・保護対象との非衝突を判定し、違反はFAIL。発話開始から終了まで内容の表示を保ち、文字の消失や別ページへの切替はFAIL。
- 各字幕の初期安定フレーム・中間・最小サイズ／最大変位時にOCRをかけ、表示原文と正規化後に照合する。不一致・欠字・低信頼度はREVIEW。画像のOCR文字高はフォントサイズとは異なるため同一視しない。
- 動く背景では字幕領域の背景を各フレームで計測する。文字と直下背景（帯または縁取りを含む）の相対輝度比4.5:1未満をREVIEWとする。帯のない複雑背景は最悪箇所を確認する。
- 表示文字数÷表示秒が日本語8文字/秒を超える区間はREVIEW。全文を削らず表示時間・尺を見直す。句読点込みで計算し、読みやすさの保証値とはしない。最終的に360×640相当表示でも目視する。
- 字幕トラックの存在だけで焼き込み済みと判定しない。抽出した映像フレーム上で文字が見えることを確認する。

## ズーム・モーション

- ショット表の各効果に対象ROI、予定区間、動作種別、予定変位または倍率・透明度、期待方向を記録する。静止シーン／全体ズーム省略は既存契約に従い理由を残す。
- 変換ログから移動量・倍率が予定値へ達したか検算し、完成動画の同区間ROIでフレーム差分またはoptical flowを測る。ページ切替、字幕変化、カメラ移動を分離／補正する。全体のピクセル変化だけで合格にしない。
- 明確な動きを予定したROIの移動量が出力上8px未満、ズーム予定の倍率差が0.03未満ならREVIEW（微動を目的とする効果には適用しない）。予定した効果がない場合はFAIL。発光・出現は移動量ではなく対象ROIの輝度・透明度変化で照合する。
- 重要語時刻と効果開始の差が0.20秒を超えればREVIEW。動きの方向・医学的妥当性・文字固定は既存検収で確認し、動きの数を増やすための演出は追加しない。

## 音声の抜け・テンポ・ノイズ

```bash
ffmpeg -hide_banner -i final.mp4 -vn -af 'silencedetect=noise=-40dB:d=0.35,astats=metadata=1:reset=0,ebur128=peak=true' -f null - 2> audio.log
```

- 音声ストリームなし、デコード失敗はFAIL。発話ID集合と配置音源ID集合を比較し、未配置・重複・話者不一致・区間逸脱はFAIL。ファイル有りだけで発話有りとしない。
- BGMで無音を隠さないよう、ミックス前の発話トラックにも同じ無音検査を行う。発話予定内の0.35秒以上、発話間の0.50秒以上、冒頭の0.20秒以上の無音をREVIEWにする。呼吸、読解の間、演出は理由を残して許容し、自動一括切除しない。
- 最終ミックスを発話区間ごとにASRし、対応表の「読み」と照合する。句読点・空白を正規化し、略語や同音語は読み辞書で吸収する。差分は全件REVIEW、医療用語・用量・否定語・最後の語の欠落は優先確認する。全文の有無は実聴で確定し、ASR未実施を全文一致と報告しない。
- 語尾まで音が収まり、次ページ・書き出し終端で切れないことを波形と実聴で確認する。話者の声名は既存のサービス選択記録で確認し、ASRや音の印象で本人性を判定しない。
- true peakが−1dBTPを超える場合、0dBFS付近のサンプルが連続する場合はREVIEW。ピーク値単独から歪みを断定しない。
- 発話トラックの非発話区間（合計0.5秒以上）と発話区間からRMSを測る。ノイズ床が−45dBFSより大きい、または発話RMSとの差が25dB未満ならREVIEW。無音をデジタルゼロ化した素材や非発話区間のない素材ではS/Nを測定不能と記録する。BGM混合後からノイズ床を推定しない。
- ハム・ヒス・クリック・歪みはヘッドホンで確認する。除去処理した場合は処理前後を比較し、子音や語尾が欠けたらFAIL。BGM／効果音使用時は発話区間の音量差を測り、発話より15dB以上低いことを初期目安とし、満たさない場合はREVIEW。最終判断は言葉を明瞭に聞き取れるかで行う。

## フック・任意素材・最終判定

0、0.5、1、2秒のフレームと音声を確認する。フック開始時刻を記録し、2秒以内に問い／驚き／学習価値が提示されなければREVIEW。煽りや医学的誤認を招く表現を避ける。

BGM・効果音・B-rollは使う場合だけ台本との対応、権利情報、音声・文字の遮蔽を記録する。Brand Kitは既存の指定値を参照し、ロゴ・色・フォント・名称の逸脱をREVIEWとする。指定がない項目はN/A。10項目を満たすために新しい素材や契約を追加しない。

すべての必須項目のPASSと、理由付きN/A、解決記録付きREVIEWを確認して納品する。未解決の項目が残れば「検収済み」と報告しない。この文書の更新自体は過去動画の再検査完了を意味しない。
