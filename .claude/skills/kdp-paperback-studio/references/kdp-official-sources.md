# Official KDP sources

Verify these pages immediately before final calculations or delivery because KDP requirements can change:

- Paperback submission guidelines: https://kdp.amazon.com/help/topic/G201857950
- Trim, bleed, and margins: https://kdp.amazon.com/help/topic/GVBQ3CMEQW3W2VL6
- Create a paperback cover: https://kdp.amazon.com/help/topic/G201953020
- Print options and page-count ranges: https://kdp.amazon.com/help/topic/G201834180
- Cover calculator and template generator: https://kdp.amazon.com/cover-calculator

As checked in August 2026, official guidance requires single-page interior files, 0.125 inch outer cover bleed, and a continuous back-spine-front cover. Current spine coefficients used by `cover_geometry.py` are recorded in that script but must be rechecked against the official calculator before final export.
