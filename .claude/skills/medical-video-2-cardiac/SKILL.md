# 医療動画2 ｜ 心臓シリーズ

## 適用と使い方

心臓シリーズでは医療動画2の柔らかな生体膜、透過光、奥行きを継承する。背景・粒子・矢印・連続構図は本書を優先する。腎臓等で心血管が背景に写るだけなら親スキルのみを使う。親の腎臓用プロンプトや凡例を心臓用プロンプトに連結しない。

ChatGPT・Codex・Claude Codeで同じ2文書を使う。リポジトリでは本フォルダの SKILL.md を入口にし、チャットに渡す場合は本書と [英語プロンプト集](references/prompts.md) を一緒に指定する。依頼が設計・検品だけならその範囲で完結する。

## 1カットを設計する

1. カットID、伝えたいこと1つ、病型・術式の変法、術前／術中のどの時点／術後、血流再開の有無を画面外の制作メモに書く。症例資料がある場合はその接続を優先する。
2. 同一構図の区間ごとに参照画像を1枚決める。ユーザー指定画像を優先し、初回なら基準カットの解剖を検品してから固定する。患者の左右、視点、回転・傾き、倍率、切断面、心尖・心基部・肺動脈分岐の位置、画面内の心臓の外形を記録する。術前と術後で実際に変わる接続を先に列記する。
3. 縦9:16、基本1080×1920。高解像度原本は原寸を保つ。背景の空白は全面 #000000。臓器の光は表面に留め、背景の色かぶり・グラデーションを避ける。中央約60%を主役にし、上下各15〜20%を後編集用に空ける。
4. 心筋はくすんだ藤色、血管壁は淡い青緑、弁尖は乳白、人工導管は淡い灰白など、構造ごとに半透明の材質を割り当てる。壁・弁輪・弁尖・内腔の境界を残す。色はシリーズ単位で固定する。
5. 血液の酸素化は壁色とは独立に、内腔の淡い暖色（高い）・寒色（低い）で示す。混合部は実在する交通部とその下流で中間調にする。彩度から酸素飽和度の数値を推定させない。静脈血の赤血球も暗赤色。流れのある内腔に少数の両凹円盤を置き、弁の縁や吻合口を隠さない。心筋内・壁外・空の器具に散らさない。遮断・排血中の術野や閉鎖した交通を通る流れを描かない。
6. 全画面で文字・擬似文字・数字・化学式・記号・矢印・ラベル・引出線・目盛り・ロゴ・透かしを禁止する。器具の刻印やモニターの筐体内の画面、波形、UIも描かない。必要な装置は無地の筐体・管・接続部だけを見せる。方向は経路と前後カットの血球位置で伝える。人物は指定された患者カットのみ、柔らかな日本アニメ調。手元の明示指定があるときだけ器具を持つ手を加える。
7. 次カットには区間の基準画像と直前の採用画像を照合し、指定した手術操作・血流だけを変える。参照入力が1枚なら区間の基準画像を使い、直前カットまでに成立した変更を文章で引き継ぐ。別視点・拡大を指定されたカットは別区間とし、戻りのカットは元の基準に合わせる。

## 1枚ずつ行う医学・画面検品

| 見る箇所 | 合格条件 |
|---|---|
| 向きと構図 | 基準画像と交互表示または半透明重ね合わせで、心尖・心基部・未操作の分岐が一致する。左右反転、回転、意図しない拡大、心房・心室の入替がない。 |
| 弁と血管 | 血液の出発腔から弁輪、開口、吻合先、末梢まで指でたどれる。弁尖は弁輪につき、同じ心周期の流れと開閉が合う。重なっただけの血管を交通と判定しない。冠動脈の起始口は正しい根部の内腔へ開く。 |
| 酸素化と赤血球 | 血管名ではなく、この病型・手術段階の流入元から色を決める。どこで混じり、どこで肺を通るかを説明できる。欠損のない中隔・血管壁を血球が越えない。 |
| 器具・デバイス | 指定された器具だけを、アクセス部から軸・先端・標的まで追う。カテーテルは指定内腔内、開放術野の器具は指定切開口から標的へ。壁の突き抜け、弁尖や冠動脈口への意図しない干渉、術後の一時器具残存は不合格。留置物は固定部と両端の位置を確認する。 |
| 画面 | 原寸で四隅・器具・粒子まで目視し、禁止要素が一つもない。縦横の実寸比を確認し、被写体から離れた背景の四隅と余白をスポイトで検査する（RGBすべて0）。 |

各カットに「ID／病型・段階／参照／確認した経路／合格・要修正・判定保留／理由」を記録する。接続を目で追えなければ判定保留。透過度や遮蔽物を調整して同じ構図で再確認する。誤接続・禁止要素は当該カットを修正して再検品する。採用画像だけを次の基準にする。実画像を見ていない段階では合格を付けない。

術式別の判定と医学資料は [英語プロンプト集](references/prompts.md) の各例を参照する。
