# 制作時の合格条件

各項目を合格／要修正／未検証で記録する。重大な解剖誤りを美観で相殺しない。

| 項目 | 合格条件 |
|---|---|
| 透明感 | 壁の存在と内部構造を同時に判別できる |
| 造形 | 丸み、厚み、前後関係があり、接続・内腔が連続する |
| 材質 | 壁・血球・器具を区別でき、不透明なプラスチック化がない |
| 色 | 組織そのものが青のグラデーション、原則赤は血球のみ |
| 光学 | 白飛び、過剰ブルーム、構造を誤認する屈折がない |
| 解剖 | 対象の左右・接続・血流・機器位置を出典と照合済み |
| 赤血球 | 両凹円盤の立体感があり、全体が内腔に収まる |
| 構図 | 指定縦横比、中央60%、上下20%余白（別指定は優先） |
| 解像度 | 元と最終の実測寸法・拡大有無を記録済み |
| 一貫性 | 全画像を並べ、形状・色・照明・カメラの意図しない変化がない |
| 動画 | 開始・中間・終了と全編再生で壁貫通、融合、変形、カメラ飛びがない |

画像依頼では動画を対象外とする。制作手順の存在、参照の目視、実生成の検証を分けて報告する。
