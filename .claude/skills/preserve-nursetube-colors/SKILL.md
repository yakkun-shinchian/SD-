# ナースチューブ背景色の維持

ユーザーが2026年10月1日に確定した「今後も背景色を変更しない」を、すべてのNurseTube更新で守る。

## 固定ルール

- ページ、ヘッダー、カテゴリナビゲーション、教材カード、動画サムネイルなどの既存背景色・グラデーション・カテゴリごとの色分けを維持する。
- 教材のイラスト化、動画化、V5/V6/M1への更新、カードの共通化、レイアウト改善は、背景色変更の許可と解釈しない。
- 基礎看護学の教材カードは従来の青グラデーションと白文字を維持する。バイタルサインも同じ青とする。左に文字・右にイラストの配置でも、共通のイラスト動画クラスによってピンクに変えない。
- 解剖生理学など他カテゴリも、各表示箇所の既存配色を維持する。基礎看護学に合わせて全カテゴリを青にしない。
- ライト／ダークの既存テーマ切替は維持し、各テーマ内の配色を勝手に変更しない。
- イラスト内部の色と、イラストを載せるウェブページ／カードの背景色を区別する。新しいイラストの色からサイトの背景色を自動決定しない。
- ユーザーが対象と色を明示して変更を依頼した場合だけ、その範囲を変更する。明示済みの依頼には重ねて許可を求めない。

## 更新手順

1. 対象の現在のコードと表示を読み、背景色、カテゴリの色定義、適用クラス、テーマ別上書きを確認する。
2. 表示箇所ごとの配色を基準として記録する。カテゴリの代表色を全要素に一律適用しない。
3. 依頼された文章・画像・動画・配置だけを更新する。共通スタイルの変更では既存の背景色を維持する条件を残す。
4. 差分で background、background-color、background-image、CSS変数、カテゴリ色、インラインstyleを確認し、依頼されていない色の変更を除く。
5. ホーム一覧とカテゴリ一覧の対象カードを表示確認する。基礎看護学は青背景・白文字と右側イラストが共存していることを確認する。共通CSSを触った場合は他カテゴリと既存テーマも確認する。
6. 公開が依頼に含まれる場合は公開後の表示まで確認する。古い配色がキャッシュに残る場合は通常の読み込みバージョン更新を使う。コード保存だけで表示確認済みと言わない。

## 対象の手掛かり

- 公開ページ: https://yakkun-shinchian.github.io/SD-/nurse.html
- リポジトリ: yakkun-shinchian/SD-
- 主な対象: nurse.html、app.js、styles.css、data.js。ブランチは毎回現在の設定を確認する。
- 2026年10月1日の基礎看護学カード: CATEGORIES の基色 #2563eb、135度グラデーションの終点は同色を35%暗くした rgb(24,64,153)、文字 #fff。既存の生成処理を再利用する。
- 解剖生理学のイラストカードには淡いピンク背景がある。data.jsのカテゴリ代表色と、実際のカード背景色は必ずしも同じではないため混同しない。

このスキルは配色維持のための指示とする。教材制作、認証、公開権限などの別作業の許可は与えない。
