# 明日の準備

指定日の行動に必要な情報を、読み取り専用で一枚の実用的なブリーフにする。

## 手順

1. 対象日、タイムゾーン、勤務時間、取得してよい予定・タスクの範囲を確認する。
2. 許可されたカレンダー、タスク、会議資料から時刻、場所、参加者、期限、準備事項を集める。
3. 重複予定、移動時間不足、連続会議、期限衝突、事前提出物を検出する。
4. 当日の最重要事項を三つ以内に絞り、理由を添える。
5. 会議ごとの目的、読む資料、持ち物、質問、開始前に必要な時間を示す。
6. 空き時間とバッファを示し、確定予定と提案を明確に分ける。
7. 情報の取得時刻と、アクセスできなかった情報源を記す。

## 安全境界

- 予定の作成・変更・削除、出欠回答、メッセージ送信、タスク完了を自動で行わない。
- 予定タイトルなどの機微情報は必要最小限に要約する。
- 固有の働き方を仮定せず、ユーザーのタイムゾーンと優先基準を使う。
- 情報が古い可能性があれば断定せず、確認時刻を示す。
