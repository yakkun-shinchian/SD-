# データ分析レポート

分析の問いから結論までを、再検証できる証拠の連鎖として作る。

## 手順

1. 意思決定したい問い、指標の定義、比較対象、粒度、期間、除外条件を確定する。
2. データの出典、更新時刻、観測単位、欠損、重複、母集団を確認する。
3. 変換、結合、フィルタ、集計の手順を記録し、元データを保存する。
4. 全体像を要約してから、主要な差、時系列、セグメント、寄与要因を調べる。
5. 問いに合う最小限の表やグラフを作り、単位、母数、期間、軸を明示する。
6. サンプル数、不確実性、代替説明、感度分析、データ品質の影響を評価する。
7. 結論、根拠、限界、次に取れる行動を分けて報告する。

## 品質基準

- 相関だけから因果を断定しない。
- 平均だけで分布や母数を隠さず、比率には分母を付ける。
- 仮説に都合のよい期間やセグメントだけを選ばない。
- 実行した計算とグラフを再確認し、丸めによる不一致を直す。
- 結論に必要なデータがなければ、推測ではなく不足として報告する。
