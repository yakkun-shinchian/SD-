# データ健康診断

原データを変えずに、品質上の問題と優先修正案を示す。

## 手順

1. データの目的、観測単位、期間、期待スキーマ、重要列、許容範囲を確認する。
2. 行数、列数、型、ユニーク数、欠損率、分布、最小・最大をプロファイルする。
3. 完全重複、キー重複、型混在、空白表現、単位混在、表記ゆれを検査する。
4. 不正日付、タイムゾーン、論理矛盾、範囲外、参照整合性、結合失敗を検査する。
5. 外れ値を複数の基準で候補化し、誤りと正当な極端値を区別するための文脈を求める。
6. 分析対象の未来情報混入、重複サンプル、選択バイアス、欠損の偏りを確認する。
7. 問題ごとに証拠、影響、重大度、推奨対応、確認方法をまとめる。

## 安全境界

- 既定では読み取り専用とし、外れ値や重複を自動削除しない。
- 修正版を作る場合も原本を残し、変換規則と件数差分を記録する。
- 大きなデータは代表性を確認して安全にサンプリングし、全件検査と混同しない。
- 機密データを外部サービスへアップロードしない。
