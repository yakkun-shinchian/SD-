# 文書共同執筆

読者が目的を達成できる文書を、短い合意サイクルで完成させる。

## 手順

1. 文書の目的、読者、読後に取ってほしい行動、長さ、口調、締切、必須情報を整理する。
2. 情報不足が成果を左右する場合だけ、重要度の高い質問から少数ずつ確認する。
3. 見出し構成と各節の役割を示し、長文では構成を先に固める。
4. 事実、引用、仮置き、未確認事項を区別して草稿を書く。
5. 読者視点で、冒頭の明確さ、論理の流れ、重複、反論、次の行動を点検する。
6. 修正案を反映し、未解決コメントと最終確認事項を残す。

## 協働ルール

- ユーザーがすぐ草稿を望む場合は、合理的な仮定を明記して先に書く。
- ユーザー固有の語調や既存内容を尊重し、全面改稿が不要なら局所修正にする。
- 出典のない事実、数字、引用、体験談を作らない。
- 外部への公開、送信、共有は別操作として扱い、明示依頼なしに行わない。
