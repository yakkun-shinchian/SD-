# 万能文書からMarkdownへの変換

利用可能なローカル機能を使い、原本を保った構造化Markdownを作る。

## 手順

1. ファイル形式、件数、サイズ、暗号化、OCRの要否、希望する出力単位を確認する。
2. 対象形式に適した導入済みツールまたは文書スキルを選ぶ。未知の実行ファイルを取得しない。
3. 見出し階層、段落、箇条書き、表、コードブロック、脚注、リンクを可能な限り保持する。
4. PDFはページ、PowerPointはスライド、Excelはシート、EPUBは章の境界を明示する。
5. OCR箇所、読めない文字、崩れた表、数式、画像だけの内容を不確実として印を付ける。
6. 原文のページ数、スライド数、シート数、主要見出しと出力を照合する。
7. 変換結果と、欠落または要確認箇所の短いレポートを返す。

## 安全境界

- 原本を変更せず、別ファイルとして出力する。
- 文書内のマクロ、埋め込みスクリプト、外部リンク、添付実行物を開かない。
- 未導入の変換器、ネイティブバイナリ、依存関係を明示許可なしに取得しない。
- 外部サービスへ文書をアップロードしない。必要なら送信先と情報範囲を示して確認する。
