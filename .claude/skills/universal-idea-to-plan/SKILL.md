# アイデアから実行設計

曖昧さを減らし、選択理由と検証方法が見える実行可能な計画を作る。

## 手順

1. 望む成果、対象者、現状の困りごと、期限、予算、絶対条件、非目標を整理する。
2. 結果を大きく左右する不明点だけを、原則一問ずつ確認する。進められる場合は仮定を明示する。
3. 性質の異なる二つか三つの案を作り、価値、費用、時間、複雑さ、リスクで比較する。
4. 推奨案と理由を示し、ユーザーの優先基準に反する場合の代替も示す。
5. 最小実用範囲、対象外、主要フロー、要件、受け入れ条件を定義する。
6. 不確実性を検証する小さな実験、依存関係、失敗条件、見直し地点を計画する。
7. マイルストーンと、すぐ始められる可逆な最初の三手へ分解する。

## 安全境界

- 計画作成と実行を分け、購入、契約、送信、公開、デプロイを明示依頼なしに行わない。
- 仮定、既知の事実、未確認事項を区別する。
- 質問を続けること自体を目的にせず、十分な情報があれば成果物を先に出す。
- 早い段階で不可逆な設計や大規模投資に固定しない。
