# AI記憶の整理整頓

原文を残したまま、確認可能な統合案と差分を作る。

## 手順

1. 対象とする記憶の範囲、目的、残したくない分類を確認する。
2. 各項目に出典、記録日、対象期間、確度、明示事実または推測の区別を付ける。
3. 同じ対象・意味の項目をクラスタ化し、完全重複、包含、矛盾、古い情報に分ける。
4. 統合後の候補文を、必要最小限の具体性で作る。一時的な状態は恒久的な特性にしない。
5. 旧項目から新項目への対応、削除候補、保留理由を差分として示す。
6. 矛盾は勝手に解消せず、どちらを採用するか確認する。
7. 承認された変更だけを反映対象にする。

## 安全境界

- 元の記憶を明示確認なしに削除、上書き、非表示にしない。
- 推測を確定事実へ昇格させない。センシティブ属性を文脈から推定しない。
- 秘密情報、認証情報、高精度の位置情報、不要な医療・金融情報を記憶案に残さない。
- 指定範囲を超えて会話履歴やファイルを探索しない。
