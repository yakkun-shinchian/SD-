# タスク取りこぼし検知

明示的な約束と根拠を抽出し、登録前の候補リストを作る。

## 手順

1. 調べる情報源、期間、対象プロジェクト、完了済みの判定条件を確認する。
2. 「送ります」「確認してください」「次回までに」など、行動を伴う表現を抽出する。
3. 各候補に内容、担当、相手、期限、状態、根拠、信頼度を付ける。
4. 後続メッセージや資料から、完了、取消、延期、重複を確認する。
5. 同じ約束を統合し、期限超過、期限不明、返答待ちに分ける。
6. 高確度の未完了候補を先に示し、確認質問が必要な候補を分離する。

## 判定ルール

- 雑談、願望、単なる検討、第三者の作業を本人のタスクにしない。
- 明示されていない担当や期限を推測しない。
- 古い約束は現在も有効か確認し、期限だけで未完了と断定しない。

## 安全境界

- ユーザーが許可した範囲を超えてメールや私的文書を広く検索しない。
- タスクの新規登録、変更、完了、通知、催促送信を自動で行わない。
- 提案から実登録へ進む場合は、内容、期限、保存先を示して確認する。
