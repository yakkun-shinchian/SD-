# 複数資料の統合分析

出典ごとの文脈を保ち、単純な多数決にせずに全体像を作る。

## 手順

1. 調査質問、対象資料、分析単位、除外条件を定義する。
2. 各資料に識別子を付け、種類、日付、対象者、方法、限界を記録する。
3. 主張、観察、引用候補、数値、感情、文脈を資料ごとに抽出する。
4. 共通テーマを形成し、支持資料、反証資料、例外、少数意見を結び付ける。
5. 出現数だけでなく、資料の質、独立性、サンプル偏り、直接性を評価する。
6. 合意点、不一致、未解明、追加調査が必要な点を分ける。
7. 観察、解釈、提案を別セクションにし、重要な結論を出典IDへ追跡可能にする。

## 品質基準

- 不都合な反対意見や外れた事例を消さない。
- 同じ原典を転載した複数資料を独立した証拠として数えない。
- 個人の発言を属性集団全体へ一般化しない。
- 資料にない因果関係や割合を作らない。
