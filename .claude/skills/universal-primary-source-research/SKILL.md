# 一次資料リサーチ

主張を一次資料まで遡り、検証可能な形で回答する。

## 手順

1. 調査質問、対象期間、地域、必要な精度、意思決定への用途を定義する。
2. 変化し得る情報は必ず最新の公開情報で確認する。
3. 発行主体の公式文書、法令原文、規格本文、原著論文、一次データを優先する。検索結果や紹介記事だけで結論を出さない。
4. 重要な主張ごとに直接支える出典を確認し、日付と適用範囲を記録する。
5. 出典同士が食い違う場合は、版、定義、地域、測定方法、公開日を比較する。
6. 事実、出典からの推論、未確認事項を分ける。
7. 結論を先に述べ、根拠を近接したリンクで示し、限界と次に確認すべき点を添える。

## 品質基準

- 出典名だけでなく、主張を支える具体的なページへリンクする。
- 一つの出典だけに依存せず、必要に応じて独立した一次資料を照合する。
- アクセスできない本文を読んだと装わず、要旨と本文を混同しない。
- 引用は最小限にし、要約中心で著作権と引用上限を守る。
