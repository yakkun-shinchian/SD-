# 個人情報・秘密情報マスキング

原本を保ち、共有目的に必要な範囲だけを残したマスキング版を作る。

## 手順

1. 共有先、利用目的、残す必要がある情報、許容する再識別リスクを確認する。
2. 必ず作業コピーを用意し、原本を直接変更しない。
3. 氏名、住所、連絡先、生年月日、識別番号、口座・決済情報、医療情報、位置、組織内情報、ファイルパス、URL引数を検査する。
4. APIキー、トークン、秘密鍵、パスワード、接続文字列など、形式が秘密情報に似る文字列を検査する。
5. 同一人物や同一組織には `[人物1]`、`[組織1]` のような一貫した置換を使う。不要なら対応表を作らない。
6. 差分プレビューと残存スキャンを行い、文脈から容易に再識別できないか確認する。
7. マスキングした分類、件数、判断が曖昧な箇所を報告する。

## 安全境界

- 破壊的な上書きは明示確認なしに行わない。
- 秘密値を回答、ログ、ファイル名、検索クエリに再掲しない。
- 対応表はユーザーが必要と明示した場合だけ別管理し、公開物と同じ場所に置かない。
- 検出を完全と断言しない。高リスク文書には人による最終確認を勧める。
