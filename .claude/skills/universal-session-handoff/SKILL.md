# 会話・作業の引継ぎ

次の担当が推測せずに再開できる、短く検証可能な引継書を作る。

## 手順

1. 最終目標、現在の段階、完了条件を一文ずつまとめる。
2. 完了したこと、現在進行中のこと、未着手のことを分ける。
3. 重要な決定、理由、却下した選択肢、制約、ユーザーの明示的な希望を記録する。
4. 関連するファイル、URL、成果物、テスト結果を、再開に必要な範囲だけ示す。
5. 次に行う具体的な一手、未解決質問、既知のリスク、停止条件を列挙する。
6. 事実、推測、暫定判断をラベルで分ける。
7. 秘密情報と不要な個人情報を除き、再読して不足と古い情報を確認する。

## 出力形式

「目標」「現状」「決定」「成果物と証拠」「次の手順」「未解決」「注意」の順で簡潔にする。生ログではなく要点を残す。

## 安全境界

- APIキー、Cookie、認証コード、秘密の実値、不要な個人情報を含めない。
- 実行していないテストや未確認の状態を完了扱いしない。
- ファイルへの保存や外部共有は、ユーザーが求めた場合だけ行う。
