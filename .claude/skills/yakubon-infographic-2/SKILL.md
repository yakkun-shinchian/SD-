# YAKUBON STUDIO Clinical Infographic 2（擬人化キャスト版）指示文づくり

薬・ホルモン・神経伝達物質・細胞などを**キャラクターに擬人化**し、「誰がヒーローで、誰が門番で、誰がサポート役か」を色と役割で一目でわかるようにした、新人看護師・看護学生向けInstagramリール素材の指示文を作る。ChatGPT（ユーザーは「チャッピー」と呼ぶ）にそのまま貼れる形で出す。

基準にした成功例：アナフィラキシー回（全9ページ・約40秒）
- アドレナリン＝金色のヒロイン（主役・救命の第一選択）
- ポララミン（H1ブロッカー）＝青い髪の門番、H1の青い扉を盾で守る
- ガスター（H2ブロッカー）＝紫の髪の門番、H2の紫の扉を守る（補助・必要に応じて）
- ヒスタミン＝鍵の形をしたオレンジの小さなマスコット軍団（悪役ではなく、扉を開けてしまう“いたずらっ子”）
- 受容体＝扉、薬が結合する物質＝鍵

## 最重要ルール1：チャッピーはイラストで止める

- チャッピーに作らせるのは**静止画のイラストとテキストまで**。動画は絶対に作らせない。
- 動画化は、ユーザーがイラストを確認し、Claude側で調整してから行う。
- 「動画化プロンプト」は、あとで別のツールで使う**文章として書かせるだけ**。
- テンプレートの「■ 制作範囲」ブロックは省いたり弱めたりしない。前後編なら両方に入れる。

## 最重要ルール2：配役は臨床の優先度どおりにする

擬人化はわかりやすい反面、**配役そのものが医学的なメッセージになる**。見た目の目立ち方で誤解させない。

- **主役（ヒーロー）＝エビデンス上の第一選択・最優先の治療**だけに与える。画面の中央・一番大きく・一番明るく描く。
- 補助薬は「門番」「サポート役」として、主役より小さく・後ろに配置する。補助役を主役より強そうに描かない。
- 体内の物質や防御反応は悪役にしない（例：ヒスタミン＝いたずらっ子の鍵、ヘプシジン＝体を守る門番）。悪い顔は「困った顔」「やんちゃ顔」までにとどめる。
- 配役は、ガイドライン・添付文書をWebSearchで確認してから決める。記憶だけで「第一選択」と書かない。

## 手順

1. **医学的な正確さを先に整える**
   - ユーザーの説明に誤り・誤解されやすい点、聞き間違い（例：「プロラミン」→ポララミン）があれば、指示文の前に短く訂正する。
   - 数値・用量・投与経路・第一選択かどうかは、WebSearchで最新のガイドラインを確認してから使う。
   - 正常値（基準範囲）は施設差があるため、原則として画像に入れない。
   - 商品名で呼ぶ薬は、一般名を小さく併記させる（例：ガスター（ファモチジン）、ポララミン（d-クロルフェニラミン））。

2. **キャスト表をつくる**（下の「配役と色の決め方」に従う）
   - 登場するキャラを、役割・色・性別・見た目・決めポーズ・シンボルで表にする。
   - 女性だけにしない。キャストが3人以上なら男性も入れる。
   - 指示文の前に、キャスト表を短く見せる（ユーザーが配役を確認しやすいように）。

3. **ページに分解する**
   - 基本は**9ページ・1ページ約4〜5秒・合計約40〜45秒**。
   - 1ページで伝えることは1つだけ。
   - 合計が60秒を超えそうなら前編・後編に分ける。前編の最後に「次回予告」、後編の最初に「前編のおさらい」を入れ、書式・キャスト・制作範囲は両方に入れる。
   - 構成の基本（アナフィラキシー回の流れ）：
     1. フック：「〇〇なのに、なぜ△△？」（意外性・疑問形）
     2. 全体像・キャスト登場：「二つの扉と、ヒーローの到着」
     3. 原因の発生：原因物質の群れが出動する
     4〜5. 仕組みを1つずつ：扉（受容体）ごとに何が起こるか
     6. 主役の活躍：主役の「〇つの力」
     7. 補助役の位置づけ：「門番は、あくまで補助」
     8. 投与・観察の注意：速度・希釈・副作用など
     9. 決めの一枚：「救命の一手は〇〇！」＋観察で締める

4. **指示文を1つのコードブロックで出力する**（下のテンプレート）

5. **コードブロックの後に、ひとこと添える**
   - 最初に「キャスト設定画」を1枚作らせ、それを見てからページ画像に進むと、キャラの顔と色が揃いやすい。
   - 前後編・シリーズは同じChatGPTチャットで続けて生成すると、キャラが揃いやすい。
   - 文字の多いページは日本語が崩れやすい。崩れたら背景とキャラだけ作ってもらい、文字はCanvaで乗せる。

## 配役と色の決め方

### 役割（ロール）

| 役割 | 誰に与えるか | 見た目の方向性 |
|---|---|---|
| 主役・ヒーロー | 第一選択・最優先の治療、命を守る主な働き | 中央・大きく・光をまとう。マント、ティアラや紋章、前に手を伸ばす決めポーズ |
| 門番・防御役 | 受容体ブロッカー、拮抗薬、バリア機能 | 盾（受容体名入り）を持ち、扉の前に立つ。落ち着いた表情 |
| サポート役・補助 | 補助療法、対症療法、必要に応じて追加する薬 | 主役の後ろや横。道具（点滴・時計など）を持たせて役目を示す |
| 司令塔・指揮官 | 上位のホルモン（視床下部・下垂体など）、調節中枢 | 高い位置から指示を出す。軍師・指揮官風 |
| 回復・修復役 | 修復・再生・回復を促すもの | 癒やしの光、やわらかい表情 |
| ブレーキ係 | 抑制系（GABA、ネガティブフィードバックなど） | ハンドルやレバーを握る、落ち着いた職人風 |
| アクセル係 | 興奮・促進系 | 走る・押すなど前向きな動き |
| いたずらっ子の群れ | 症状を起こす体内物質（ヒスタミン、炎症性物質など） | 小さく丸いマスコットを複数。鍵などシンボルを持つ。悪役にしない |

### 色

- **1キャラ1色**を決め、髪・服・盾・名前タグ・関係する扉や臓器まで同じ色でつなぐ（例：H1＝青の扉と青い門番、H2＝紫の扉と紫の門番）。
- 主役は金・白など「光」の色。いたずらっ子の群れはオレンジなど暖色の小さな丸。
- 色が近いキャラ（青と水色など）を同じ画面に並べない。
- 背景はネイビー。キャラの色が背景に沈まないようにする。

### 性別と見た目

- 女性だけにしない。役割に合わせて男女を混ぜる（例：司令塔＝男性の軍師、門番の片方を男性の騎士にする、など）。性別で強さや賢さを決めつけない。
- 全員ちびキャラ調ではなく、**頭身はやや高めのアニメ調**（アナフィラキシー回の門番・ヒロインくらい）。
- 露出は控えめで品よく。清潔感を優先する。
- 既存のアニメ・ゲームのキャラクターに似せない（オリジナルのデザインにする）。
- 各キャラに**名前タグ**（薬・物質名＋短い役割）を必ず付ける。

### たとえの道具

- 受容体＝扉、結合する物質＝鍵、ブロッカー＝扉の前の門番と盾
- 酵素＝職人、輸送体＝バスの運転手、フィードバック＝見張り台、など、テーマに合わせて身近なものにする。

## ナレーションの口調

- やさしい先輩の話し言葉（「〜なの」「〜だよ」「〜してね」）。
- 1ページのナレは1〜2文まで（約4〜5秒に収まる長さ）。
- キャラ名で呼んで物語にする（例：「ここでヒーロー、アドレナリンの登場！」）。ただし、作用や優先度は正確に言う。
- 最後のページは必ず「保存してね」の呼びかけで終える。
