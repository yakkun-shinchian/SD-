# YAKUBON STUDIO Clinical Infographic C1 指示文づくり

新人看護師・看護学生向けのInstagramリール素材を、ChatGPT（ユーザーは「チャッピー」と呼ぶ）にそのまま貼れる指示文として作る。

## 手順

1. **医学的な正確さを先に整える**
   - ユーザーの説明に誤り・誤解されやすい点があれば、指示文の前に短く訂正する（例：βアミロイド→β2ミクログロブリン）。
   - ガイドラインの数値・薬剤名・最新改訂は、WebSearchで確認してから使う。記憶だけで数値を書かない。
   - 正常値（基準範囲）は施設差があるため、原則として画像に入れない。

2. **シーンに分解する**
   - 1枚の画像で伝えることは1つだけ。難しい内容ほど細かく分ける。
   - 1シーンは約6〜8秒。
   - 合計が70秒を超えそうなら、前編・後編に分けることを提案する。分けるときは、前編の最後に「次回予告」シーン、後編の最初に「前編のおさらい」シーンを入れる。前後編どちらも単独で貼れるよう、書式・キャラ設定は両方に入れる。
   - 構成の基本：フック（疑問形・意外性）→ 全体像 → 要素を1つずつ → 臨床の落とし穴 → まとめ・保存の呼びかけ。

3. **わかりやすい“たとえ”を決める**
   - 抽象的な仕組みは、身近なもの（倉庫・バス・工場・シーソーなど）にたとえ、マスコットとして全シーンで使い回す。
   - ホルモンや防御反応を悪役にしない（例：ヘプシジンは「体を守る門番」）。

4. **指示文を1つのコードブロックで出力する**（下のテンプレート）

5. **コードブロックの後に、ひとこと添える**
   - 文字の多いまとめ画像は日本語が崩れやすいので、崩れたら背景とキャラだけ作ってもらい、文字はCanvaで乗せる。
   - 前後編は同じChatGPTチャットで続けて生成すると、キャラが揃いやすい。

## テンプレート

```
あなたはYAKUBON STUDIOの医療教育コンテンツ制作アシスタントです。
新人看護師・看護学生向けのInstagramリール（約○秒）の素材を作ってください。
（前後編の場合：これは前後編の【前編／後編】です。）
テーマ：「○○」
キャッチコピー：「○○」

━━━━━━━━━━━━━━━━
■ ブランド書式：YAKUBON STUDIO Clinical Infographic C1
━━━━━━━━━━━━━━━━

・ネイビーの背景 × ネオンカラー（シアン・マゼンタ・ライムを差し色に）× グラスモーフィズムのパネル
・（テーマに合う差し色があれば追加）
・ちびキャラ調。「かっこよく、美しく、少し可愛く」
・医療的に正確で、臓器や細胞は清潔感のあるデフォルメに（グロテスクにしない）
・テロップは短く大きく、正確な日本語で。文字の崩れや誤字は不可
・1枚に伝えることは1つだけ。情報を詰め込みすぎない

■ キャラクター（全シーン共通・同一人物）
・後輩の新人看護師、ボブヘア、水色のスクラブ、明るく素直な表情
・画面に出るのは彼女1人だけ。先輩は声（吹き出し）だけで登場
　（2人を画面に出す回は：先輩＝ポニーテール、ネイビーのスクラブ）
・動画化を前提に、ポーズや動きはシンプルにする

■ マスコット（全シーンで同じデザインを使い回す）
・（たとえに使うキャラを列挙）

━━━━━━━━━━━━━━━━
■ 医学的に守ってほしいこと（変更禁止）
━━━━━━━━━━━━━━━━
・（式・数値・薬剤名・順番・誤解されやすい点を、一字一句変えない形で列挙）

━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━
1. シーン画像 ○枚
2. まとめ画像 ○枚（保存用）
3. 各シーンの動画化プロンプト（Seedance／Veo用、英語、1シーン約6〜8秒、カメラワークと動きは控えめ）
4. ナレーション原稿（CoeFont読み上げ用。読みにくい語にはカッコでふりがな。略語の読み方も併記）
5. Instagramキャプション＋ハッシュタグ

出力の順番：画像を1枚ずつ生成し、各画像の直後にその動画プロンプトを添えてください。最後にナレーション全文とキャプションをまとめて出してください。

━━━━━━━━━━━━━━━━
■ シーン別の内容
━━━━━━━━━━━━━━━━
① 0〜○秒｜見出し
テロップ：「○○」
絵：（キャラの表情・マスコットの動き・配置を具体的に）
ナレ：「○○」
（以下、シーン数ぶん）

━━━━━━━━━━━━━━━━
■ まとめ画像（保存用）
━━━━━━━━━━━━━━━━

（タイトル・表の中身・欄外の注意書き）

━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━

・「保存して、病棟や国試前に見返してね」で締める

```

## ナレーションの口調

- やさしい先輩の話し言葉（「〜なの」「〜だよ」「〜してね」）。
- 1シーンのナレは2〜3文まで。
- 最後のシーンは必ず「保存してね」の呼びかけで終える。
