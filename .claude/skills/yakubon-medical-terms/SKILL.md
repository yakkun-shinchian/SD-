# 専門用語・理解度チェック

看護学生が、初めて読む順番のまま「何が、どこで、どうなるか」を自分の言葉で説明できる教材にする。構成時と納品前にこの手順を使う。静止画の「ページ」は、動画なら場面、音声や台本ならひとまとまりの発話として扱う。

## 1　問いを一つ決め、残す言葉を選ぶ

- 教材を見終えた学生に尋ねたい問いを一文で書く。各ページにも、そこで初めてわかることを一つ割り当てる。
- 見出しからまとめまで、図中のラベル、吹き出し、凡例、字幕、音声、投稿文に現れる用語を読む順に拾う。正常な構造、病名、略語、薬や器具の名称、作用を表す動詞も対象にする。
- 各語について「この名前を消しても、学生は同じ問いに正確に答えられるか」と試す。答えられれば日常語で伝えるか、語ごと省く。図や読み上げにも削除を反映する。安全に関わる違い、対象者、条件、因果関係は保つ。

## 2　意味を教えてから、名前を使う

1. **前提を置く。** 場所と通常の働き → 何が変わるか → その結果、の順に組む。検査・処置なら、普段の体の流れ → どこから何をするか → 何がわかる・変わるか、とたどる。
2. **初出の位置で教える。** 学生がその語を初めて見る、または聞く位置で「どこで何をするものか」を既出語と日常語の一文で示す。題名に掲げるときは直下に、発話で初めて触れるときは同じ発話内に置く。名前だけが出たページは「説明済み」に数えない。定義に別の新語が必要なら、先にその意味を教えるか、既知の言葉で定義し直す。
3. **略語には対応をそろえる。** 学会用語集・ガイドライン等で実在する表記を確かめ、初出に「略語 → 元の正式名称（英語）→ 標準的な日本語名 → この場面での意味」をひとまとめにする。英語由来でない略語は原語を記す。難読語は読みを添える。読みやカタカナ訳だけで終えない。「バルーン」のように器具名だけでは処置を特定できない場合は、原資料で目的と使用部位を確かめる。確認できるまでは処置名を断定しない。用語カードはこの順で並べ、本文やナレーションは身近な説明から始めてよい。英語を読ませることが目標でなければ、画面で正式名を示し、音声では意味を優先する。
4. **既出語でつなぐ。** 次のページは、前のページで確認できた言葉から始める。学生に答えを求める前に、必要な手掛かりをすべて示す。独立して配信する後編・抜粋は冒頭から新しい教材として点検し、必要な前提と略語を初出扱いに戻す。

## 3　何を絵にするか決める

| 判断する場面 | 制作時の処理 |
|---|---|
| 学習目標に不要な細分類や別名 | 省く。新しい用語を説明するためだけに枝を増やさない。 |
| 必要な新語で、主図に対象と働きがはっきり見える | その用語を教えるために描いた部分と日常語の一文を対応させる。学生が対象を指し、働きを言えれば同じページで扱える。 |
| 位置・向き・前後の変化・似た処置の違いが主図から読み取れない | 必要な差だけを示す専用の挿絵を作る。同じ視点の拡大・前後比較などを選ぶ。別の問いが生まれる、文字が小さくなる、次の説明が先に必要になる場合は、その語を使う**前**に説明用の1枚を置く。 |
| 枚数・尺が固定されている | 重複や周辺知識を削り、必要な図に枠を譲る。追加枠が取れなければ専門名を省き、正確な日常語で同じ要点を伝える。必須の学習目標を落とさなければ収まらないときは、該当箇所を要修正として示す。 |

元の制作形式が専用の新しい絵を求める場合は、その語のために主図または挿絵を描く。文字禁止の画像には説明を焼き込まず、形式で許された字幕・ナレーション・併載文に同じ場面の説明を置く。台本のみなら、絵で示す場所と変化をその場面の制作指示に書く。たとえを使うときは「ブレーキ＝何を抑える働きか」のように実際の体の働きへ戻す。

## 4　ページごとに合否をつける

**合格条件は、看護学生が前のページまでの知識だけを土台に、次のページを初見で理解できること。** 新しい内容はそのページで教え、先のページや巻末の用語集を前提にしない。

[検品用チェックリスト](references/checklist.md)を使い、後続ページ、制作メモ、解答例を隠して順に読む。各ページで、開く前に「何を知っていれば読めるか」、読んだ後に「絵のどこを見て、自分の言葉でどう答えるか」を記録する。先のページの知識や専門家の補足を使った回答は差し戻す。修正後は該当ページから最後まで再点検する。実際の学習者に聞けた場合と、制作者による模擬読解は区別して記録する。

判断に迷ったら[修正前後の作例](references/worked-examples.md)を見る。アスピリン喘息では削る細分類と残す機序を、ERCPでは略語の正式名と体内での動作を比較できる。
