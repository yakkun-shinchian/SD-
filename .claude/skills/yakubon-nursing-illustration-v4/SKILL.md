# YAKUBON Nursing Illustration V4

## 必ず最初に行うこと

1. `references/visual-spec.md` を最後まで読む。
2. `assets/style-references/` から用途に合う見本を `view_image` で確認する。見本は画風・人物・画面構成だけに使い、腸や抗菌薬など見本固有の内容を別テーマへ持ち込まない。
3. ユーザーが添付した見本があれば、それも確認し、最新の明示指示を優先する。
4. 台本を1枚ごとの制作票へ分ける。各制作票に「大見出し／発言者／吹き出し本文／中心の医学図解／矢印／下部まとめ／強調色」を書く。原稿を勝手に言い換えない。

## 制作ワークフロー

### 1. 情報量を整える

- 1枚1メッセージにする。
- 大見出しは原則1〜3行、スマホで2秒以内に読める長さにする。
- 吹き出しは1人1個を基本とし、1個2〜3行、全角30字前後までにする。収まらなければ削るか次ページへ送る。文字を小さくして解決しない。
- 医学内容を変更する必要がある場合は、画像制作前にユーザーへ示す。絵の都合で臨床内容を創作しない。

### 2. 見本を選ぶ

- フック表紙：`01-cover-hook.jpeg` と `10-summary.jpeg`
- 先輩・後輩の対話：`02-dialogue-board.jpeg` と `03-dialogue-organ.jpeg`
- 大きな臓器・概念図：`05-concept-cutaway.jpeg` と `07-process-flow.jpeg`
- 比較・変化：`06-balance-comparison.jpeg` と `08-contrast-paired-organs.jpeg`
- 観察・アセスメント：`09-clinical-observation.jpeg`

一度に使うスタイル参照は原則2枚までにする。シリーズ中盤以降は、必要なら直前の承認済み画像も人物一貫性の参照に加える。

### 3. 画像を生成する

- `image_gen` を使い、1枚ずつ生成する。画像編集も `image_gen` を使う。
- ローカルにある見本は `referenced_image_paths` で渡す。ローカルパス参照と会話内の最近画像参照を同時に使わない。
- `references/prompt-template.md` を基礎にし、そのページの正確な文言と医学図解だけを差し替える。
- 4:5縦長、最終想定1080×1350px、フルブリードで作る。外周枠を置かない。
- タイトル、人物、医学図解、矢印、補足の優先順位を明示する。文章だけで画面を埋めない。

### 4. 目視検品する

生成後は必ず `view_image` で原寸確認し、次を1枚ずつ判定する。

- 日本語が一字一句正しく、文字化け・脱字・重複・意味不明文字がない。
- 見出しが太い手描きマーカー調で、紫・青・マゼンタ・オレンジ・黄が上品に調和している。
- 吹き出しが白地の自然な横長台形寄りで、硬い長方形や完全な楕円ではない。
- 吹き出し本文が細めの手描きマーカー調で、極太ゴシックや明朝体ではない。
- 吹き出し、尻尾、文字が顔・髪・手・重要図解にかかっていない。
- 先輩と後輩の髪型、スクラブ色、年齢感、左右関係がシリーズ内で一貫している。
- 医学図解が大きく、説明と矢印の対応が正しい。
- スマホ縮小表示でも主要文が読める。小さすぎる文字で無理に詰め込んでいない。

一項目でも落ちたら、その箇所を具体的に指定して再編集する。誤字のある画像を「ほぼ完成」として渡さない。

### 5. 書き出しを検証する

- 10枚カルーセルでは、ファイル名を `01_...` から `10_...` まで連番にする。
- JPEGまたはPNGで書き出す。ユーザーが一括納品を求めた場合だけZIPも作る。
- 寸法と枚数を次で確認する。

```bash
python3 scripts/validate_carousel.py OUTPUT_DIR --expect-count 10
```

## 固定ルール

- 上部見出しを箱で囲まない。
- ページ全体をカードや額縁で囲まない。
- 白地の情報カードを何枚も並べない。必要な比較表以外は一枚絵で見せる。
- 黄色い蛍光マーカー下線を定番化しない。黄は筆文字・光・短い放射線のアクセントとして使う。
- 医療者を冷たい無表情にしない。先輩は穏やかで自信があり、後輩は好奇心と発見が伝わる表情にする。
- 平坦なベクター、3Dプラスチック調、写実写真、モノクロ漫画へ寄せない。
- 不自然な指、増えた手足、重複人物、壊れた器官、読めない名札を残さない。
- 参考画像のテーマ固有物を転用しない。腸の教材でなければ腸や花畑を出さない。

## 完了条件

「V4らしい」だけでなく、次の全条件を満たして初めて完成とする。

1. 4:5縦長で、主要要素が安全域内にある。
2. 見出し・吹き出し・本文・人物・医学図解が `visual-spec.md` と一致する。
3. 原稿と画像内文字が完全一致する。
4. 医学的な因果関係と矢印が台本どおりである。
5. 10枚を一覧で見たとき、同じシリーズ・同じ人物・同じ画材に見える。
