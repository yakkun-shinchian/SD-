# Image generation prompt template

以下を1枚ごとに埋めて使う。角括弧の指示は削除してから送る。

```text
添付したYAKUBON STUDIO V4参考画像を、画風・固定キャラクター・レイアウト文法の参照として使ってください。参考画像の腸、花、抗菌薬、菌などのテーマ固有物はコピーせず、今回の医学テーマだけに完全に置き換えてください。

Instagram用の縦4:5、最終想定1080×1350px、フルブリードの看護教育イラストを1枚制作してください。

【ページの役割】[フック／対話／図解／比較／まとめ]
【医学テーマ】[テーマ]
【大見出し・完全一致】
[1〜3行。改行位置も指定]

【吹き出し・完全一致】
後輩：[本文。不要なら「なし」]
先輩：[本文。不要なら「なし」]

【下部まとめ・完全一致】
[本文。不要なら「なし」]

【中心の医学図解】
[何を、どの向きで、どれくらい大きく見せるか]

【因果関係と矢印】
[A → B → C。不要なら「なし」]

画面上部の大見出しは箱で囲まず、太い油性マーカー／平筆で手描きしたような文字にしてください。紫〜インディゴ青を軸に、マゼンタ、オレンジ、少量の黄色を語句単位で美しく配色し、短い放射線も加えてください。均一な虹色や機械的なフォントにはしないでください。

後輩は左、淡い青紫スクラブ、短いダークブラウンのボブ。先輩は右、濃紺スクラブ、低いダークブラウンのポニーテール。明るい病棟で自然に向き合い、表情と手ぶりで会話してください。顔と髪を文字や吹き出しで隠さないでください。

吹き出しは温かい白地で、四隅が大きく丸い、少し不均一な横長の台形寄り。硬い長方形や完全な楕円にしないでください。輪郭は細い手描きマーカー風。中の文字は濃紺の細め手描きマーカー風で、大きく読みやすくしてください。極太ゴシック、明朝体、小さい文字は禁止です。

全体は明るく上品な半写実日本アニメ調。柔らかな日光、アイボリーの光、細い輪郭、自然な肌、丁寧な髪、明るい瞳。医学図解を画面の30〜50%で大きく、直感的に見せてください。外周枠、見出しの箱、情報カードの乱立、平坦なベクター、3Dプラスチック調、顔への重なり、増えた指、読めない文字、重複人物を入れないでください。

画像内の日本語は上記の文言と一字一句同じにしてください。勝手な言い換え、補足、英語、透かし、ロゴを追加しないでください。
```

## 修正用の短い追指示

```text
構図、人物、医学図解、背景、配色はそのまま保持し、[修正箇所]だけを直してください。正しい文字は「[正確な文字列]」です。吹き出しは白地の自然な横長台形寄り、本文は濃紺の細め手描きマーカー、大見出しは多色の太いマーカー調を維持してください。他の要素を再設計しないでください。
```
