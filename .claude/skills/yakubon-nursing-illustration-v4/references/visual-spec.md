# V4 visual specification

## 1. キャンバスと安全域

- 縦4:5。標準納品は1080×1350px。
- 参考10枚は1122×1402pxで、同じ4:5比率である。
- 外周はフルブリード。額縁、ページ枠、白い外周カードを置かない。
- 重要文字・顔・吹き出し尻尾は左右54px、上40px、下48pxより内側へ置く。
- 画面の目安：上部見出し20〜24%、人物と会話28〜38%、医学図解35〜50%。各ページの役割に応じて重ねてよい。

## 2. 全体の絵柄

- 明るく上品な日本アニメ／漫画寄りの半写実デジタルペイント。
- 肌と髪は柔らかいグラデーション、細い輪郭、瞳に自然なハイライト。幼児化や過度なデフォルメは避ける。
- 病棟は大きな窓、白〜アイボリーの光、緑、ぼかしたモニターやスタッフで奥行きを出す。
- 高輝度で温かい。冷たい青灰色、暗い病室、無機質な企業プレゼン風にしない。
- 医学図解は「わかるための華やかさ」にする。柔らかな発光、小さな擬人化、花・葉・水滴・矢印は内容に合うときだけ使う。

## 3. 固定キャラクター

### 後輩・左

- 20代前半〜半ばの日本人女性看護師。
- 顎付近の短いダークブラウンのボブ、軽い前髪。
- 淡い青紫〜ペリウィンクルのVネックスクラブ。
- 好奇心、驚き、ひらめきが伝わる大きめの目と自然な口元。
- 質問、発見、確認を担当する。

### 先輩・右

- 20代後半〜30代前半の日本人女性看護師。
- ダークブラウンの長髪を低いポニーテール、顔周りに柔らかな後れ毛。
- 濃紺のVネックスクラブ。
- 穏やかな笑顔、自信、安心感。説明や指差しを担当する。

### 共通

- 名札は文字を読ませず、個人情報を作らない。
- 顔、髪、目、口、手を吹き出しで隠さない。
- 1枚の中で同一人物を重複させない。手指は自然な本数と向きにする。
- 同一シリーズでは左右関係とスクラブ色を変えない。

## 4. 大見出し

- 画面最上部に直接置く。見出しの後ろに長方形、帯、枠、カードを敷かない。
- 太い油性マーカーまたは平筆で一気に書いたような日本語。輪郭がわずかに揺れ、インクだまりと乾いた筆端が少し見える。
- 1080px幅換算で文字高100〜150px。1〜3行。端まで詰めず、左右余白を保つ。
- 文字色は単色一色に固定しない。語句単位で次を2〜4色使う。
  - deep violet `#3B0DB8`
  - indigo blue `#2648D8`
  - vivid magenta `#F20B68`
  - coral orange `#FF7A24`
  - sunshine yellow `#FFD83D`
- 基本は紫／青とマゼンタを主役にし、オレンジ／黄は短い語、感嘆符、放射線、筆跡の光として少量使う。全字を均等な虹色にはしない。
- 見出しの周囲に3〜7本の短い手描き放射線を置いてよい。色はオレンジ、黄、ピンク。

## 5. 吹き出し

- 白〜温かい白 `#FFFDF8` の塗り。半透明にせず、背景から明瞭に分ける。
- 形は「自然な横長台形寄り」。四隅を大きく丸め、上辺・下辺をわずかに傾け、左右の膨らみを少し不均一にする。
- 完全な楕円、角丸長方形、漫画のギザギザ爆発形、硬い幾何学台形は禁止。
- 1080px幅換算で輪郭4〜7px。クレヨンまたは細いマーカーの軽いかすれを持たせる。
- 発言者の側へ短く自然な尻尾を向ける。尻尾の根元を広く、先端を細くする。
- 後輩は青紫 `#5B5FE8`、先輩はコーラルピンク `#F25773` の輪郭を基本とする。単色統一でもよいが、ページ内で役割を混同させない。
- 内側余白は上下32〜42px、左右38〜50pxを目安にする。

## 6. 吹き出し本文と下部まとめ

- 吹き出し本文は細い油性マーカーで丁寧に書いたような、丸みのある自然な手書き日本語。
- 濃紺 `#0A1B63` を基本にする。機械的な極太ゴシック、明朝、細すぎるペン字、縦書きを使わない。
- 1080px幅換算で原則52〜70px。最低50px。行間1.12〜1.25。
- 強調語はマゼンタまたはコーラルに変える。下線だらけにしない。
- 下部まとめは白いぼかしの上へ直接置き、見出しより一段小さい太めマーカーにする。箱で囲まない。

## 7. 医学図解

- そのページの主概念を画面の30〜50%で大きく示す。
- 臓器は認識可能な形を保ちつつ、柔らかな発光と親しみやすい色で表現する。
- 原因→変化→結果は太い矢印で一方向に示す。矢印は3本以内を基本とし、交差させない。
- 擬人化する菌や細胞は小さく可愛くしてよいが、善悪だけで誤解させない。台本の医学的ニュアンスを優先する。
- 背景小物ではなく、図解そのものを視線の中心にする。

## 9. 禁止パターン

- 全面の太い外枠、画面を縮めるカード。
- 見出しを囲む白い箱や色帯。
- バルーンがカチカチの長方形、完全な楕円、均一なCAD形状。
- 吹き出し本文の極太角ゴシック、明朝、極小文字。
- 文章の詰め込み、長い箇条書き、5枚以上の小カード。
- 顔・髪・手・重要臓器への重なり。
- 同じポーズの反復、人物の増殖、左右反転による役割入れ替え。
- 参照画像の腸、花、菌、カプセルを無関係なテーマへコピーすること。
