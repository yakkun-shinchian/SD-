# YAKUBON STUDIO SNSキャプション

Instagram・TikTok・YouTube Shorts用に、動画1本ぶんのキャプション、キーワード、ハッシュタグを作る。

## 出力のルール

- キャプション、キーワード、ハッシュタグは分けずに、コードブロック1つにまとめる。そのままコピペできる形にする。
- 全体で500文字以内にする（絵文字・改行・ハッシュタグも数える）。仕上げる前にコードで文字数を数え、返事の中で何文字かを一言伝える。
- 「国家試験対策」「国試対策」という言葉は入れない（入れると見る人が減る）。
- 締めの一文は「保存して、病棟で見返してね」の系統にする。新人看護師が現場で使える、という方向で書く。

## 構成（この順番）

1. **つかみの1行**：絵文字で始め、動画の売り（例：回すと一発でわかる、3Dで見る）を一文で書く。最後にも絵文字を1つ付ける。
2. **空行**
3. **見出し①**（例：🧠輪のつくり、🫀しくみ）：動画で見せる順番どおりに、1行1項目で3〜5行。各行の頭に、内容を表す絵文字を付ける。
4. **空行**
5. **見出し②「💡ここが大事」**：病気の変化、注意する症状、CT所見、時期などのチップスを3〜4行。各行の頭に絵文字、矢印は「→」を使う。
6. **空行**
7. **締め**：「📌保存して、病棟で見返してね🩺」など。
8. **空行**
9. **キーワード行**：頭に🔍を付け、半角スペース区切りで並べる。日本語の用語と略語の両方を入れる。
10. **空行**
11. **ハッシュタグ行**：10〜12個。

## 書き方

- 医学用語のあとには、略語を（ ）で付ける。例：内頸動脈（ICA）、椎骨動脈（VA）、脳底動脈（BA）、前交通動脈（ACoA）、後交通動脈（PCoA）、中大脳動脈（MCA）。
- 1行は短くして、1行に1つのことだけ書く。スマホで縦に読みやすくするため。
- 「知ってた？」「〜じゃない！」のような、意外性のある一言を1つ入れる。
- 絵文字は意味が伝わるものを選ぶ。例：⬆️⬇️＝位置、🔗＝つなぐ、⚠️＝注意、👁️＝目の症状、💥＝破裂、⭐＝形、📅＝時期、🙅‍♀️＝違う・含まない、🧠🫀🫁＝臓器。
- 内容は動画の台本・テロップと一致させる。動画にないことは足さない。

## ハッシュタグ

- 必ず入れる：#看護師 #新人看護師 #看護学生 #看護 #医療動画 #YAKUBONSTUDIO
- 題材に合わせて足す：診療科（例：#脳神経外科 #脳外科看護 #循環器）、疾患名、構造名（例：#ウィリス動脈輪）、#解剖生理 など。
