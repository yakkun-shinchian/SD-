# NurseTube（ナースチューブ）🩺▶

**看護師・看護学生のための「勉強用YouTube」** — **ずんだもん**が看護をやさしく解説してくれる、動画で学ぶ学習ポータルアプリです（番組の解説文はすべて「〜なのだ」口調なのだ）。

解剖生理・薬理・看護技術・疾患・国家試験対策などを、カテゴリ別の「番組」として一覧・検索し、視聴ページで学べます。YouTube風のUIで、ブラウザで開くだけですぐに使えます（環境構築・ビルド不要）。

## 🫁 トップページ：VentSim（人工呼吸器モニター・シミュレーター）

**サイトを開くと（`index.html`）、まず人工呼吸器モニター画面が表示されます。** Dräger EVITA 2/4 タイプのモニターを再現した学習用シミュレーターです（単一HTML、依存なし）。

- **波形表示**：気道内圧 Paw（圧波形・黄）／流量 Flow（流量波形・緑）／換気量 Volume（ボリューム波形・水色）をリアルタイムにスクロール描画
- **肺の病態プリセット**：正常肺・**ARDS**・**COPD**・**気管支喘息（発作）**・肺線維症・健常肺。コンプライアンス／気道抵抗が切り替わり、波形の形が病態ごとに変化します（COPDの auto-PEEP、ARDSの高圧・低換気量など）
- **換気モード**（EVITA搭載モードを網羅）：IPPV / CMV、VC-AC、SIMV（量規定／圧規定）、MMV、PCV+ / PC-CMV、**BIPAP**／BIPAP Assist、**APRV**、**CPAP**、CPAP/ASB（PSV）、ASB、PPS、NIV+PS
- **設定パラメータ**：FiO₂、タイダルボリューム VT、強制換気回数 RR、PEEP、プレッシャーサポート（PS/ASB）、吸気圧 Pinsp、吸気時間 Ti、表示スピード（すべて画面上で常時操作可能）
- **実測値表示**：Ppeak／Pmean／Pplat／PEEP（auto-PEEP）／VTe／MV／総呼吸回数／Cdyn／気道抵抗／I:E／推定SpO₂ と、簡易アラーム
- **iPad / スマホ対応**：レスポンシブ。Safariの「ホーム画面に追加」で全画面アプリのように使えます

物理モデル（抵抗 R・コンプライアンス C の単一コンパートメント肺）で気道内圧・流量・換気量を計算しているため、モードと病態の組み合わせで教科書的な波形が得られます。

> ⚠️ **教育用デモです。** 実機の数値・挙動とは異なります。臨床判断には使用しないでください。

（旧 `ventilator.html` を開いても自動でトップの人工呼吸器画面へ移動します。）

## 🧾 検査値アセスメント支援アプリ（`labs.html` ほか）

**血液検査の結果から「今この患者に何が起きているのか」を構造的に読み解く**、臨床看護師向けの判断支援ツールです。単一ページの静的アプリで、依存もビルドもありません。

| ページ | 内容 |
|---|---|
| **`labs.html`** | **統括アセスメント**。4領域を横断して緊急度トリアージ・症候群判定・看護アクションを提示 |
| `labs-cbc.html` | 血算（CBC） |
| `labs-chem.html` | 生化学 |
| `labs-coag.html` | 凝固・線溶（急性期DIC診断基準の自動スコアリング付き） |
| `labs-autoab.html` | 自己抗体（膠原病＋臓器特異的＋神経免疫） |

### 設計の核：アンカリング・バイアスへの対抗

検査値を見るとき最大の敵は「異常値を1つ見つけると思考がそこで止まる」ことです。本アプリは**単独項目の判定**と**組み合わせ（症候群）の判定**を構造的に分離し、横断視点を強制的に提示します。

- 🚦 **緊急度トリアージ**：パニック値・qSOFA・症候群から 赤／黄／緑 を最上段に表示
- 🔗 **横断症候群**：DIC、血栓性微小血管症（TTP／HUS）、敗血症、肝不全、消化管出血、溶血、汎血球減少、腫瘍崩壊症候群、横紋筋融解、SIADH／中枢性塩類喪失症候群／尿崩症 など
- 🗺 **臓器別の所見マップ**：造血・凝固・肝胆道・腎電解質・心循環・感染炎症・代謝内分泌・免疫・神経の9系統に整理
- 🩺 **看護アクション**：緊急度順に並べた具体的な行動（観察項目・報告・準備）
- 🔎 **次の一手**：判断に足りない検査・観察を提案
- 👤 **患者背景が解釈を書き換える**：年齢・性別・妊娠で基準値を切替。内服薬（ワルファリン／ヘパリン＝HIT／ステロイド／化学療法／バルプロ酸／カルバマゼピン／マンニトール ほか）を解釈に反映
- 📚 **症例プリセット 38 件**：ワンタップで典型症例を流し込める（動作確認と学習を兼ねます）
- 🖨 **印刷／PDF保存**・ライト／ダークテーマ切替・iPad/iPhone 最適化

### 脳神経領域への対応

脳外科・神経内科病棟を想定し、以下を重点的に実装しています。

- **低Na血症の三分岐**：SIADH／中枢性塩類喪失症候群（CSWS）／尿崩症。検査所見がほぼ同じでありながら治療が正反対になるため、体液量評価を促す設計
- **抗てんかん薬の検査影響**：バルプロ酸→高アンモニア血症、カルバマゼピン→低Na血症
- **神経免疫抗体**：抗AChR・抗MuSK（重症筋無力症）、抗AQP4・抗MOG（NMOSD／MOGAD）、抗GM1・抗GQ1b（ギラン・バレー／Fisher）、抗NMDA受容体・抗LGI1・抗CASPR2（自己免疫性脳炎）、傍腫瘍性 抗Hu／Yo／Ri

### 基準値について

既定値は**日本臨床検査標準協議会（JCCLS）共用基準範囲**（成人）です。JCCLS に収載のない項目（凝固・自己抗体ほか）は一般的な施設値を既定とし、画面上に「**施設依存**」と表示しています。

> ⚠️ **本ツールは教育・判断補助が目的です。** 診断・治療の決定は医師が行います。パニック値の閾値を含め、**各施設の規定が優先されます**。患者氏名・IDを入力しない設計になっています。

## 🩺 内科診断支援アプリ（`dx.html`）

**内科医向け**の診断支援ツールです。看護師版（`labs.html` 系）とはエンジンを共有しつつ、表現と判定の深さを専門医水準に引き上げています。**すべての判定にガイドライン・原典の出典が付きます。**

### 🫁 血液ガス・酸塩基平衡の体系的読影

内科診断の中核です。6段階で機械的に読み切ります。

1. **pH の評価** — アシデミア／アルカレミア／正常域
2. **一次性障害の同定** — 代謝性／呼吸性 × アシドーシス／アルカローシス
3. **代償の妥当性** — Winter 式、呼吸性障害は急性／慢性で係数を切替（1.0 vs 3.5）。予測範囲を外れれば**混合性障害**として検出
4. **アニオンギャップ** — **アルブミン補正**（低Alb血症は AG を 2.5/g·dL⁻¹ 小さく見せます）
5. **Δ-Δ 解析** — AG開大性に隠れた高Cl性アシドーシスや代謝性アルカローシスを炙り出す
6. **酸素化** — A-aDO₂（年齢補正）、P/F 比と ARDS ベルリン定義の重症度

加えて**浸透圧ギャップ**（中毒性アルコール）と**尿アニオンギャップ**（腎性／腎外性の切り分け）も算出します。

### 🔬 鑑別診断エンジン

所見の組み合わせから鑑別候補を順位づけ、**支持する所見・否定に働く所見・次に行う検査・鑑別のコツ**を提示します。35疾患を収載（敗血症、ARDS、DIC、TTP/HUS、AKI、SIADH／CSWS／尿崩症、RTA、DKA/HHS、副腎クリーゼ、甲状腺クリーゼ、肝不全、急性胆管炎、消化管出血、HLH、HIT、SLE、ANCA関連血管炎、重症筋無力症、ギラン・バレー、自己免疫性脳炎、中毒性アルコール、横紋筋融解 ほか）。

> 出力は「**合致度**」であり疾患の確率ではありません。事前確率と、病歴・身体所見・画像は臨床医が与えます。

### 📐 臨床スコア 24種

入力済みの検査値とバイタルから**自動で下書き**されます。

qSOFA／SOFA／CURB-65／A-DROP／McIsaac／NEWS2／CHA₂DS₂-VASc／HAS-BLED／Wells（DVT・PE）／簡易PESI／ABCD²／KDIGO AKI／CKD重症度／Child-Pugh／MELD-Na／West-Haven／Glasgow-Blatchford／急性膵炎重症度／Light基準／ISTH overt DIC／4Ts（HIT）／HScore／Burch-Wartofsky

### 📖 出典

Sepsis-3、KDIGO、ACR/EULAR、ベルリン定義、Winter 式、GOLD MARK ほか**40件の原典**を収載し、各判定カードの末尾に表示します。

> ⚠️ 書誌情報は実装時点のものです。臨床判断に用いる前に、必ず原典および最新版のガイドラインで照合してください。本ツールは**教育・判断補助**が目的であり、診断・治療の決定は医師が行います。

## 🩺 NurseTube（看護学習アプリ）は `nurse.html`

看護の勉強用ポータル（ずんだもん解説）は **`nurse.html`** に移動しました。人工呼吸器画面のフッターのリンク、または直接 `nurse.html` を開いてください。

## 主な機能

- 🟢 **ずんだもん解説**：すべての番組の解説が「〜なのだ」口調。出演（チャンネル）はずんだもん
- 🎬 **番組一覧**：カテゴリ別のカード表示（サムネイル・タイトル・チャンネル・視聴回数）
- 🗂 **カテゴリ絞り込み**：基礎看護学／解剖生理学／薬理学／疾患・病態／看護技術／母性・小児／精神看護／国家試験対策
- 🔍 **キーワード検索**：タイトル・説明・タグから横断検索
- ▶ **自動再生で学ぶ**：視聴ページで再生を押すと、スライド＋ナレーション読み上げで“動画のように”自動再生（端末の音声合成を使用）
- 🖼 **図解を多用**：心臓・腎臓・肺・心電図などの模式図や、**CT/MRI風の断層イメージ**をスライドに表示（一部アニメーション）。本物のCT/MRI写真や動画クリップも差し込み可能
- 🧩 **視聴ページ**：プレーヤー＋説明＋関連番組＋字幕
- 🌙 **ダーク／ライトテーマ**切替（設定は保存されます）
- 📝 **国家試験カウントダウン**：試験日までの残り日数を表示
- 📱 **スマホ対応**（レスポンシブ）

## 使い方

### ローカルで開く

`index.html`（人工呼吸器モニター）をブラウザで開くと、そのままモニター画面が動きます。看護学習アプリ（NurseTube）は `nurse.html` を開いてください。

検索・テーマ保存などを確実に動かしたい場合は、簡易サーバー経由がおすすめです:

```bash
# Pythonがある場合（このフォルダ内で実行）
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 動画（番組）の追加・差し替え

番組データは **`data.js`** にまとまっています。`PROGRAMS` 配列に項目を足すだけで番組が増えます。

```js
{
  id: "myvideo01",                 // 重複しないID
  title: "心電図の読み方 入門",      // タイトル
  category: "国家試験対策",         // CATEGORIES のいずれかと一致させる
  channel: "こくし対策ゼミ",        // チャンネル名（講師など）
  durationSec: 690,                // 長さ（秒）
  views: 12000,                    // 視聴回数
  published: "2026-06-01",         // 公開日（YYYY-MM-DD）
  videoId: "",                     // ★ YouTube動画ID（後述）
  description: "解説テキスト…",
  tags: ["心電図", "循環器"],
}
```

### `videoId` について

- YouTube動画 `https://www.youtube.com/watch?v=XXXXXXXXXXX` の **`XXXXXXXXXXX`** 部分が動画IDです。
- `videoId` に設定すると、視聴ページで**そのまま埋め込み再生**されます。
- 空 `""` のままにすると、「**YouTubeでこのテーマを見る**」ボタン（YouTube検索へのリンク）に切り替わります。

> 初期データはサンプルの番組構成です。`videoId` はすべて空にしてあるので、お手元の動画IDに差し替えてご利用ください。

## 自動再生で学ぶ（番組の中身）

`videoId` が空の番組は、**`scenes.js`** に書かれた解説台本をもとに、視聴ページで**スライドが自動でめくられ、ナレーションが読み上げられます**（“動画のように”再生）。再生・一時停止・前後の移動・最初から・音声オン/オフ・字幕に対応しています。

- 音声は **ブラウザの音声合成（Web Speech API）** を使うため、**お使いの端末の日本語音声**で読み上げます（本物のずんだもんボイスではありません）。
- 日本語音声が無い環境では、音声なしで字幕とスライドが自動で進みます。
- 再生はブラウザの自動再生制限のため、**最初に再生ボタンを押す**ことで始まります。

### 台本（シーン）を編集・追加する

`scenes.js` の `SCENES` に、番組ID（`data.js` の `id`）をキーにしてシーンの配列を書きます。

```js
SCENES["myvideo01"] = [
  {
    heading: "スライドの見出し",
    points: ["箇条書き1", "箇条書き2", "箇条書き3"],
    narration: "ここに読み上げるナレーションを書くのだ。",
  },
  // …シーンを増やすほど“長い動画”になります
];
```

> 本物のずんだもん音声を付けたい場合は、各 `narration` を [VOICEVOX](https://voicevox.hr2.jp/) で音声化して差し込めます（手順は次のセクション）。

## 本物のずんだもん音声にする（VOICEVOX）

端末の読み上げではなく、**本物のずんだもん音声**で再生させることもできます。台本は VOICEVOX にそのまま流し込めるよう、テキストと対応表に書き出してあります。

```bash
# 1) 台本を VOICEVOX 用に書き出す（scenes.js を編集したら再実行）
node tools/build-voicevox.mjs
#   → voicevox/narration.txt（1行=1ナレーション・全118行）
#   → voicevox/manifest.json / manifest.csv（順番と番組ID・ファイル名の対応表）

# 2) VOICEVOX で narration.txt を読み込み、話者「ずんだもん（ノーマル）」で一括書き出し
#    → 書き出した wav を voicevox/export/ に入れる

# 3) 書き出した音声をアプリ用に整列＆対応表を生成
node tools/link-audio.mjs
#   → audio/<番組ID-シーン番号>.wav にコピーし、audio/manifest.js を自動生成
```

- アプリは各シーンで `audio/manifest.js`（`AUDIO_FILES`）にある音声を優先再生し、無ければ端末の読み上げにフォールバックします。**作った分だけ**本物の声に置き換わります。
- 詳しい手順・手動で用意する方法は **[`voicevox/README.md`](voicevox/README.md)** を参照してください。
- ⚠️ VOICEVOXのずんだもん音声を使う場合は「**VOICEVOX:ずんだもん**」のクレジット表記が必要です。

## 図解・CT/MRI写真・動画クリップ

スライドには図解（SVG）を表示できます。`figures.js` に **心臓・腎臓・肺・自律神経・内分泌・バイタル・心電図**、さらに **CT/MRI風の断層イメージ**（脳梗塞・胸部など）を用意しており、**`figures-preview.html`** をブラウザで開くと一覧で確認できます。各シーンへの割り当ては `figures.js` の `SCENE_FIGURES`（キーは「番組ID-シーン番号」）で管理します。

各シーンの「映像」は次の優先順位で表示されます：

1. **動画クリップ** … シーンに `videoId`（YouTube動画ID）を設定するとそのクリップを埋め込み
2. **本物の写真（CT/MRI・X線・臨床写真）** … `images/` に置いて `images/manifest.js` に登録（図解より優先）
3. **図解（SVG）** … `SCENE_FIGURES` の割り当て

```js
// images/manifest.js の例（本物の写真を使う場合）
const IMAGES = {
  "dis03-1": "images/dis03-1.jpg",
  "dis03-3": { src: "images/dis03-3.jpg", alt: "頭部MRI 急性期", credit: "出典/ライセンス" },
};
```

> ⚠️ CT/MRI風の図は **学習用の模式図** で、実際の患者画像ではありません。本物の断層写真を使う場合は、権利的に使える画像（自作・CC0・ライセンス明記のCC BY等）を `images/` に入れてください。手順と注意は [`images/README.md`](images/README.md) を参照。

## カテゴリの追加・変更

`data.js` の `CATEGORIES` 配列を編集します。`color` はサムネイルの配色、`icon` は絵文字アイコンに使われます。`key` は `PROGRAMS` の `category` と一致させてください。

## GitHub Pages で公開する

このリポジトリは静的サイトなので、GitHub Pages でそのまま公開できます。

1. GitHub のリポジトリ → **Settings** → **Pages**
2. **Build and deployment** の Source を **Deploy from a branch** に設定
3. Branch を公開したいブランチ（例：`main`）／フォルダ `/ (root)` に設定して保存
4. 数分後に発行される URL でアクセスできます

## 技術

- 依存ライブラリなしの **HTML + CSS + バニラJavaScript**
- URLハッシュによる簡易ルーティング（`#/watch/<id>`, `#/category/<名>`, `#/search/<語>`）
- 自動再生は **Web Speech API（`speechSynthesis`）** で読み上げ＋スライド送り
- `videoId` 設定時は YouTube の埋め込み（`youtube-nocookie.com`）を利用
