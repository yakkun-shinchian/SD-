# 00 共通設計方針（全パス共通規約）

全14パスに共通する記述規約・記号・分類を定める。各パスファイルはこの規約に従う。

---

## 1. 原典照合状況の記号

本資料は外部ネットワーク制限下で作成されており、学会公式PDF・PMDA電子添文の
本文に直接アクセスできていない（README §3）。そのため **すべてのエビデンス項目に
照合状況を明示** する。

| 記号 | 意味 | 院内での扱い |
|------|------|--------------|
| ◎ | 本作業で一次情報（学会公開PDF・電子添文本文）を直接確認した | そのまま採用可 |
| ○ | 一次情報に到達できず、学会プレスリリース・査読誌・医薬品情報データベース等の二次情報で内容を確認した | 原典で数値・推奨度を確認のうえ採用 |
| △ | 出典（文献名・版・年）は特定したが、本文の内容照合ができていない | **必ず原典を参照して記載を確定** |
| × | 出典が存在しない、または特定できなかった＝ `【エビデンス不足・院内検討事項】` | 院内で継続/削除/検証を決議 |

> 本資料作成時点で **◎ に到達できた項目はない**。全項目が院内照合対象である。

## 3. アウトカムの記述規約

アウトカムは **患者の状態** で記述する。「退院」「◯日目」などの
**日程・工程はアウトカムにしない**。

判定は次のいずれかの形式で、**判定者が迷わない粒度**まで書く。

| 形式 | 例 |
|------|-----|
| あり／なし | 新規神経脱落症状：なし |
| 達成／未達 | 自己血圧測定の手技実演：達成 |
| 自立／見守り／一部介助／全介助 | 病棟内歩行：自立 |
| 安定／不安定（定義付き） | 循環動態：安定（昇圧薬・降圧薬の持続投与なしで目標血圧域を維持） |
| 数値（出典のあるもののみ） | 収縮期血圧：目標値は各パス M・E**nn** 参照 |

**禁止表現**：「観察する」「状態を見る」「適宜対応」「問題なければ」
**代替**：「何を」「いつ」「どの値／所見をもって達成とするか」「逸脱時に誰へ報告するか」まで書く。

## 4. バリアンス分類

| 区分 | 名称 | 定義 | 標準対応 |
|------|------|------|----------|
| **V0** | 正のバリアンス | 予定より早期に中間アウトカムを達成 | パス継続。次段階へ前倒し可否を医師判断。記録は必須 |
| **V1** | 軽度負のバリアンス | パス内の標準対応で解決可能。アウトカム到達が遅延するが軌道に戻る見込み | 病棟内対応。記録し、次勤務帯へ申し送り |
| **V2** | 中等度バリアンス | 追加評価・検査・治療変更を要するが、パス継続の可能性が残る | **医師報告必須**。追加指示を受けパス継続可否を判断 |
| **V3** | 重大バリアンス | 標準パスの継続が不適切。個別診療へ移行 | **パス離脱**。離脱理由・時刻・判断医師を記録 |

**記録項目（全区分共通）**：発生日時／発生時期区分／該当中間アウトカム／
バリアンス内容／原因分類／実施した初期対応／医師報告の有無と時刻／
パス継続・離脱の別／判断者。

**原因分類**（集計用）：`患者要因` / `疾病要因` / `治療・薬剤要因` / `医療者要因` /
`システム・運用要因` / `家族・社会的要因`。

## 5. 時間軸の規約

疾患・治療の性質に応じて時間単位を選ぶ。**根拠のある時間指定には必ずエビデンスIDを付す。
根拠のない時間指定は `【院内検討事項】` と明記する。**

| パス種別 | 時間軸 |
|----------|--------|
| 予定手術・予定血管内治療（01・06・07） | 入院前外来 → 入院日 → 術前 → 術直後 → 帰室時 → 1h → 3h → 6h → 当日夜間 → POD1 → POD2 → POD3 → POD4 → 退院前 → 退院時 |
| 予定検査（02〜05・08） | 入院前外来 →（前日入院の場合：入院日）→ 検査前 → 検査直後 → 帰室時 → 1h → 3h → 6h → 当日夜間 → 翌朝 → 退院時 |
| 脳梗塞・脳出血（09・10・12） | 入院直後（0h）→ 0〜6h → 6〜24h → Day1 → Day2 → Day3 → Day4〜7 → 退院／転院前 |
| 静注血栓溶解療法（13） | 病院到着 → 適応評価 → 投与直前 → 投与開始 → 投与中 → 投与終了直後 → 〜2h → 〜6h → 〜24h → 24h以降 |
| ALS薬物療法（14） | 導入前評価 → 導入日 → 投与期第1クール → 休薬期 → 第2クール以降 → 定期再評価 |

**時刻の書き分け**
- `POD1` = 術後第1病日（手術日を POD0 とする）。
- `Day1` = 入院／発症日を Day0 とした翌日。**院内でどちらを起算日とするか統一が必要**
  → `【院内検討事項 G-共通01】`。

## 6. 電子カルテ実装上の規約

1. **1行＝1オーダ／1観察項目**に分解できる粒度で記述する。
2. 観察項目には **測定値の型**（数値／選択肢／自由記載）を想定して記述する。
3. 「該当なし」は空欄にせず **明示的に「該当なし」と記載**する
   （空欄＝未実施か非該当かが判別できないため）。
4. 達成判定欄は **「達成／未達／該当なし」の3値**とし、未達を選択した場合は
   バリアンス記録画面へ遷移する運用を想定する。
5. エビデンスIDは項目末尾に `[E01]` 形式で付す。院内判断項目は `[院内]` を付す。

## 8. 全パス共通の「医師への即時報告基準」

各パスの S（離脱基準）に加え、**全パス共通の即時報告基準**を定める。
パス種別によらず、以下は **発見時点で直ちに医師へ報告**する。

| 領域 | 即時報告する所見 |
|------|------------------|
| 意識 | JCS/GCS が前回評価より低下（JCS 1桁→2桁、GCS 2点以上の低下） |
| 神経 | 新規の運動麻痺・構音障害・失語・共同偏視・瞳孔不同・対光反射消失 |
| けいれん | けいれん発作（初発・再発を問わない） |
| 頭痛・嘔吐 | 突発する激しい頭痛、噴出性嘔吐 |
| 呼吸 | SpO2低下（酸素投与下でも改善しない）、努力呼吸、上気道閉塞音、誤嚥徴候 |
| 循環 | 各パスに定める血圧目標域からの逸脱、新規不整脈、ショック徴候 |
| 出血 | 穿刺部の拍動性出血・増大する血腫、創部の持続出血、消化管出血徴候、血尿 |
| 薬剤 | アナフィラキシー徴候、薬剤性と疑われる急変 |

> 上記の **具体的な閾値（何mmHg、SpO2何%）** は疾患・治療により異なるため、
> 各パスの K・M・S に個別に記載する。ここで一律の数値は定めない。
