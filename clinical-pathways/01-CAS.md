# パス01　頚動脈ステント留置術（CAS）

対象診療科：脳血管外科／脳神経血管内治療
種別：予定入院・予定血管内治療
参照：`00-共通設計方針.md`（記号・分類）／`00-エビデンス一覧.md`（E**nn**）

---

## A. 疾患・治療概要

頚動脈狭窄症に対して、経皮的に頚動脈へステントを留置し狭窄を拡張する血行再建術である。
**治療目的は狭窄そのものの改善ではなく、同側脳梗塞の発症・再発の予防**に絞られる [E20][E21]。
したがってパスの最終アウトカムも「狭窄が拡張したこと」ではなく
**「新規の神経脱落症状を生じずに、再発予防治療（抗血小板療法・危険因子管理）を
継続できる状態で退院すること」**に置く。

### このパスが管理すべき主要リスク

| リスク | 発生しやすい時期 | パス上の対応セクション |
|--------|------------------|------------------------|
| 周術期脳卒中（塞栓性） | 術中〜術後24時間 | I・K・S |
| 過灌流症候群（CHS） | 術直後〜術後数日 | I・K・M・S |
| 頚動脈洞反射（徐脈・血圧低下） | 拡張時〜術後数時間 | I・K |
| 穿刺部合併症（出血・血腫・仮性動脈瘤・後腹膜出血） | 術中〜POD1 | K・S |
| ステント内血栓症 | 抗血小板薬の中断時 | M・P |
| 造影剤腎症（CIN） | 造影後72時間以内 | L・M |

CASとCEAの比較では、**CASは周術期心筋梗塞・脳神経損傷が有意に少ない一方、
軽症脳卒中のリスクは高く、長期の脳卒中リスクは同等**とされる。
また **80歳超（特に認知機能低下を伴う例）はCAS・CEAいずれも脳卒中リスクが高い** [E21]。
この点は D（適用基準）・T（患者説明）に反映する。

## B. エビデンスサマリー

1. **適応判断**：症候性／無症候性の別・狭窄度・CEAとの比較でCASを選択する枠組みが
   ガイドラインに示されている [E20]。**具体的な狭窄度の閾値は原典で確定すること（未照合）**。
2. **周術期リスク**：CASとCEAのリスクプロファイルの差、解剖学的・年齢的リスク因子 [E21]（Level C）。
3. **抗血小板療法**：ステント内血栓症予防に必要。**薬剤・開始時期・期間はガイドラインおよび
   使用デバイスの添付文書で確定すること** [E23]（本資料では数値を記載しない）。
4. **過灌流症候群**：血行再建後に頭痛・けいれん・局所症状・脳出血を呈しうる。
   血圧管理が重要 [E24]。**目標血圧値は未照合**。
5. **造影剤腎症**：eGFR<30 がリスク評価・予防の対象 [E02]。生食補液の方法 [E03]、
   ビグアナイド薬の一時休薬 [E04]。
6. **観察頻度・安静時間・食事開始時刻**：本作業では医学的根拠を特定できず
   → `【エビデンス不足・院内検討事項】`（G-共通02〜04）。

## D. 適用基準

**すべてを満たす患者を本パスの対象とする。**

| # | 適用条件 | 評価方法 |
|---|----------|----------|
| D1 | 頚動脈狭窄症に対し、血行再建の適応があると判断されている [E20] | 診療録上の適応判断の記載（狭窄度・症候性の別を含む） |
| D2 | CEAではなくCASを選択する方針が決定されている [E20][E21] | カンファレンス記録／術式決定の記載 |
| D3 | **予定（待機的）** 入院である | 入院区分 |
| D4 | 抗血小板療法が実施可能であり、術前導入が完了している [E23] | 服薬状況の確認（薬剤・開始日） |
| D5 | ヨード造影剤の使用が可能である [E02] | アレルギー歴・腎機能 |
| D6 | 治療内容・合併症について説明し、同意が得られている | 同意書 |
| D7 | 本パスの標準的な観察・安静・離床に協力が得られる ADL・認知機能である | 入院時ADL評価・認知機能の確認 |

> **年齢について**：80歳超は CAS・CEA いずれも脳卒中リスクが高いとされる [E21]。
> 年齢のみを除外基準とはしないが、**D2 の術式決定時に明示的に考慮した記録**を残す。

## E. 除外基準（本パスの対象としない）

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | 急性期脳梗塞に伴う緊急血行再建 | 時間軸・観察密度が全く異なる。パス09/13で管理 |
| E2 | ヨード造影剤に対する重篤な過敏症の既往 | 造影不可 |
| E3 | 重篤な腎機能障害があり、造影の可否が未決定 | CINリスク [E02]。腎臓内科と協議のうえ個別管理 |
| E4 | 抗血小板療法が禁忌、または継続困難と判断される | ステント内血栓症リスク [E23] |
| E5 | 活動性出血・重篤な出血性素因を有する | 抗血小板療法との両立不能 |
| E6 | 全身状態・併存疾患により標準的な周術期管理が困難 | 個別診療 |
| E7 | 意識障害・重度認知機能低下等により、症状申告・安静保持が困難 | 神経症状の早期検出が成立しない |

## G. 最終アウトカム（退院時に評価）

| 領域 | # | 最終アウトカム | 判定基準 |
|------|---|----------------|----------|

| 医学的 | G2 | 過灌流症候群を発症していない | 頭痛・けいれん・局所症状・頭蓋内出血：**なし** [E24] |
| 医学的 | G3 | 穿刺部合併症がない | 出血・拡大する血腫・拍動性腫瘤・末梢動脈触知不良：**なし** |
| 医学的 | G4 | 循環動態が安定している | 昇圧薬・降圧薬の**持続静注なし**で目標血圧域を維持：**安定** |
| 医学的 | G5 | 腎機能の悪化がない | 造影後の血清Cr上昇がCIN基準に該当しない [E02]：**なし** |
| 看護 | G6 | 疼痛が許容範囲で日常生活を妨げない | 患者の主観的評価で「日常生活に支障なし」：**達成** |
| ADL | G7 | 病棟内歩行が入院前レベルに復している | 入院前と同等：**自立／見守り**（入院前が介助の場合は入院前レベル） |

## H. 中間アウトカム（最終アウトカムからの逆算）

```
G1-G12 退院可能な状態
   ↑
M6  服薬・危険因子・緊急時対応を患者（または管理者）が説明できる
   ↑
M5  病棟内歩行が入院前レベルに復し、疼痛が生活を妨げない
   ↑
M4  穿刺部が安定し（出血・血腫の増大なし）、安静解除に耐えられる
   ↑
M3  過灌流症候群を示唆する症状がなく、血圧が目標域で安定している
   ↑
M2  術直後〜24時間に新規神経脱落症状を認めない
   ↑
M1  安全に治療を実施できる状態（F1-F13すべて充足、抗血小板療法導入済、腎機能評価済）
```

| # | 中間アウトカム | 達成判定 | 到達目標時期 |
|---|----------------|----------|--------------|
| M1 | 治療実施可能な状態 | F1-F13すべて「確認済」 | 術前まで |
| M2 | 新規神経脱落症状なし | F2ベースラインと比較して新規所見：なし | 帰室〜24時間の各評価時点 |
| M3 | 血圧が目標域で安定・CHS症状なし | 医師指示の目標血圧域内、かつ頭痛・けいれん・局所症状なし [E24] | 術直後〜POD1 |
| M4 | 穿刺部安定 | 出血なし・血腫増大なし・末梢動脈触知良好 | 圧迫解除〜安静解除時 |
| M5 | 歩行・疼痛が退院可能レベル | 病棟内歩行が入院前レベル、疼痛が生活を妨げない | POD1〜POD2 |
| M6 | 教育内容を説明できる | G8-G11すべて「達成」 | 退院前 |

## N. 離床・ADL

**「POD1に離床」という日程起点の設定を行わない。以下の条件充足を起点とする。**

### N-1　離床開始条件（**すべて満たすこと**）

| # | 条件 | 確認方法 |
|---|------|----------|
| N1 | 新規神経脱落症状がない | ベースライン（F2）との比較で新規所見なし |
| N2 | 意識レベルがベースラインと同等 | JCS/GCS |
| N3 | 循環動態が安定している | 医師指示の目標血圧域内、徐脈がない [E24][E25] |
| N4 | 穿刺部の止血が良好 | 出血なし、血腫の拡大なし、末梢動脈触知良好 |
| N5 | 疼痛が離床を妨げない範囲 | 患者の申告 |
| N6 | 医師の安静解除指示が出ている | 指示簿 |

### N-2　離床を延期する条件

- 新規の神経症状（軽微でも）
- **新規または増強する頭痛**（CHSの可能性 [E24]）
- 血圧が目標域を逸脱（高値・低値いずれも）
- 穿刺部の出血・血腫増大・末梢動脈触知不良
- 起立時のふらつき・失神様症状・血圧低下

### N-3　離床時の観察

段階的に進める：**端座位 → 立位 → 室内歩行 → 病棟内歩行**。各段階で以下を確認。

| 観察項目 | 中止・後退の基準 |
|----------|------------------|
| 起立時の血圧・脈拍 | 起立性の血圧低下、徐脈 |
| 自覚症状 | めまい、ふらつき、眼前暗黒感、頭痛、悪心 |
| 神経症状 | 新規の脱力、構音障害 |
| 穿刺部 | 出血、疼痛増強 |

### 頚動脈ステント留置術を受けられる方へ

首の血管（頚動脈）が細くなっている部分に、金属の筒（ステント）を入れて広げる治療です。

### ⚠ この症状があれば、すぐにナースコールしてください

- 手や足が急に動かしにくい、力が入らない
- 言葉が出にくい、ろれつが回らない
- 顔の片側がゆがむ
- **強い頭痛、今までにない頭の痛み**
- 吐き気、吐いてしまう
- けいれん（体が勝手にふるえる）
- 目が見えにくい、片側が見えない
- 息が苦しい
- **カテーテルを入れた場所からの出血、腫れ、どんどん強くなる痛み**
- 足（または手）が冷たい、しびれる、色が悪い
- **腰や背中の痛み**（鼠径部から治療した場合）

### 退院後、すぐに病院へ連絡・受診していただきたいこと

- 上に挙げた脳梗塞のサイン（顔のゆがみ・腕の力が入らない・言葉が出にくい）
  → **症状が出た時刻を確認して、すぐに救急要請してください**
- カテーテルを入れた場所の出血・腫れ・強い痛み
- 血が止まりにくい、黒い便が出る、尿が赤い
- **お薬を飲み忘れた・なくなった場合は、自己判断で中止せず必ずご連絡ください**
