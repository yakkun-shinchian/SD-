# パス03　脳血管造影・前日入院・鼠径アクセス

対象診療科：脳血管外科
種別：予定入院（前日入院）・診断的血管造影／アクセス＝鼠径部（大腿動脈）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`

> 治療（塞栓術・ステント留置）を併施する場合は本パスを適用せず、パス01・06 を用いる（F14）。

---

## A. 疾患・治療概要

大腿動脈からカテーテルを挿入し、頚部・頭蓋内血管を選択的に造影する **診断的検査**である。
パスの最終アウトカムは **「合併症なく検査を完遂し、日常生活に復帰できること」**に置く。

### このパスが管理すべき主要リスク

| リスク | 発生しやすい時期 | 対応セクション |
|--------|------------------|----------------|
| 神経合併症（塞栓性脳梗塞、一過性神経症状） | 検査中〜検査後24時間 | I・K-1・S1 |
| 穿刺部合併症（出血・血腫・仮性動脈瘤・動静脈瘻） | 検査中〜当日夜間 | K-4・S3 |
| **鼠径アクセス特有：後腹膜出血** | 検査中〜当日夜間 | **K-4F**・S3 |
| **下肢虚血**（穿刺部血栓・塞栓） | 圧迫中〜圧迫解除後 | **K-4F**・S3 |
| 迷走神経反射 | 穿刺時・圧迫解除時 | K-3 |
| **床上安静に伴う合併症**（腰背部痛、排尿困難、静脈血栓） | 安静中 | K-6・N |
| 造影剤アレルギー／造影剤腎症 | 直後〜72時間 | K-5・L・S6・S7 |

### 鼠径アクセスの管理上の特徴（上肢アクセスとの差）

| 観点 | 鼠径アクセス（本パス） | 上肢アクセス（パス02/04） |
|------|------------------------|---------------------------|
| 検査後の安静 | **床上安静・穿刺肢の伸展保持を要する** | 床上安静を要さない場合が多い |
| 最も警戒する出血 | **後腹膜出血（外からは見えない）** | 前腕コンパートメント症候群 |
| 観察の要点 | **腰背部痛・腹部膨満・原因不明の血圧低下、足背/後脛骨動脈の触知** | 手指の色調・冷感・しびれ、橈骨動脈触知 |
| 排泄 | **床上排泄となるため排尿援助が必須** | 歩行可能な場合が多い |

> **後腹膜出血は穿刺部の外表所見に乏しいまま進行しうる。**
> 「穿刺部に血腫がない＝出血なし」ではないことを、K-4F に明記している。

## B. エビデンスサマリー

1. **造影剤腎症**：CIN定義（造影後72時間以内に血清Cr 0.5mg/dL以上または25%以上上昇）、
   リスク評価・予防の対象は eGFR<30 [E02]。
2. **CIN予防補液**：生食1mL/kg/h を造影6時間前〜後6〜12時間（参考値・未照合）[E03]。
   **前日入院の医学的利点はこの計画的補液にある。**
3. **ビグアナイド系糖尿病薬の一時休薬** [E04]。
4. **観察頻度・圧迫解除時間・床上安静時間・食事開始時刻**：医学的根拠を特定できず
   → `【エビデンス不足・院内検討事項 G-共通02〜04】`。**鼠径アクセスでは安静時間が
   患者負担・合併症（腰背部痛・排尿困難）に直結するため、V-02 の審議優先度が高い。**
5. **前日入院という形態**の根拠は特定できず → `G-共通05`（V-04）。

## D. 適用基準

| # | 適用条件 | 評価方法 |
|---|----------|----------|
| D1 | 診断的脳血管造影の適応がある | 検査目的の記載 |
| D2 | **鼠径部（大腿動脈）** をアクセス部位とする方針である | 術者の方針記載、**大腿動脈の触知、鼠径部の皮膚状態** |
| D3 | **予定（待機的）** 検査であり、**前日入院**の方針である | 入院区分 |
| D4 | ヨード造影剤の使用が可能である [E02] | アレルギー歴・腎機能 |
| D5 | 説明と同意が得られている | 同意書 |
| D6 | 検査中の指示（呼吸停止・体動抑制）に協力が得られる | 認知機能・意思疎通 |
| D7 | **検査後の床上安静・穿刺肢伸展保持が保持できる** | 認知機能、腰痛・関節痛の既往、体位保持能力 |

**前日入院を選択する理由**を以下から選び記録する（V-04 の集計に用いる）。

- (a) **CIN予防補液を検査前から実施する必要がある**（eGFR低下例）[E03] ← **医学的根拠あり**
- (b) 併存疾患の管理・薬剤調整を要する
- (c) 遠方居住等により当日来院が困難
- (d) 検査開始時刻が早い等の運用上の理由 ← 医学的根拠なし
- (e) 慣習 ← 医学的根拠なし。**V-04 で見直し対象**

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | 緊急・急性期の脳血管造影 | 時間軸・観察密度が異なる（パス09・12・13） |
| E2 | 造影と同時に血管内治療を予定 | パス01・06 を適用 |
| E3 | ヨード造影剤に対する重篤な過敏症の既往 | 造影不可 |
| E4 | 重篤な腎機能障害があり造影の可否が未決定 | [E02] |
| E5 | **鼠径部の感染・皮膚障害、高度の末梢動脈疾患、大腿動脈の触知不良** | 穿刺部合併症・下肢虚血のリスク → 上肢アクセス（パス02/04）を検討 |
| E6 | 意識障害・認知機能低下等により **床上安静の保持や症状申告が困難** | 穿刺部合併症の早期検出が成立しない |
| E7 | 抗凝固療法中で休薬・調整方針が未決定 | 穿刺部合併症リスク |
| E8 | 高度肥満・腹部膨満等により **穿刺部の圧迫・観察が困難** と判断される | 後腹膜出血の検出が困難 |

## H. 中間アウトカム（逆算）

```
G1-G13 退院可能な状態
   ↑
M6  穿刺部・下肢の注意点と再開薬を患者が説明できる
   ↑
M5  歩行が入院前レベルに復し、自排尿があり、疼痛が生活を妨げない
   ↑
M4  安静解除・圧迫解除後も穿刺部が安定し、後腹膜出血・下肢虚血がない
   ↑
M3  床上安静を安全に完遂できている（穿刺部安定、循環動態安定、疼痛が耐えられる）
   ↑
M2  検査直後〜数時間に新規神経脱落症状・造影剤反応を認めない
   ↑
M1  安全に検査を実施できる状態（F1-F15充足）
```

| # | 中間アウトカム | 達成判定 | 到達目標時期 |
|---|----------------|----------|--------------|
| M1 | 検査実施可能 | F1-F15 すべて「確認済」 | 検査前まで |
| M2 | 新規神経症状・造影剤反応なし | F2 比較で新規所見なし、皮疹・呼吸困難なし | 検査直後〜6時間 |
| M3 | 床上安静を安全に完遂 | 穿刺部の出血・血腫増大なし、血圧が安定、腰背部痛が耐えられる範囲 | 帰室〜安静解除 |
| M4 | 穿刺部・下肢が安定 | 出血なし、血腫増大なし、**後腹膜出血徴候なし**、足背/後脛骨動脈触知良好 | 安静解除〜翌朝 |
| M5 | 歩行・排尿が復帰 | 入院前レベルの歩行、自排尿あり | 安静解除後〜翌朝 |
| M6 | 教育内容を説明できる | G10-G12 すべて「達成」 | 退院前 |

## I. 時間軸別アウトカム

| 時期 | 順調な状態 | 逸脱時に疑うこと |
|------|-----------|------------------|
| **入院前外来** | 検査目的・アクセス部位が決定。腎機能評価済 [E02]。休薬指示が伝達済 | 腎機能未評価→延期の可能性 |
| **入院日（前日）** | F1-F15 確認済（M1）。**ベースラインの神経所見・下肢末梢動脈・Hb・血圧**を記録。CIN予防補液を要する場合は開始 [E03] | 記録不備→検査後の判定不能 |
| **検査前（当日朝）** | 絶食・補液・休薬が指示どおり実施済。**排尿を済ませている**。穿刺部の除毛・皮膚確認済 | 未実施→医師報告 |
| **検査中〜直後** | 検査完遂。術者による神経学的確認済。穿刺部圧迫が適切 | 検査中の神経症状→S1 |
| **帰室時** | 意識・神経所見がベースラインと同等（M2）。穿刺部圧迫良好、**足背/後脛骨動脈触知良好**、下肢色調正常。**床上安静・穿刺肢伸展を保持**（M3） | 下肢の触知不良→S3（下肢虚血） |
| **1時間後** | M2・M3 維持。血圧が安定 | **血圧低下＋腰背部痛→後腹膜出血を疑う（S3）** |
| **3時間後** | M2・M3 維持。飲水可。腰背部痛が耐えられる範囲 | 造影剤反応（皮疹・掻痒）→S7 |
| **6時間後** | M2・M3 維持。圧迫解除後も出血なし。**排尿ができている** | 排尿困難→導尿の要否を医師と協議 |
| **当日夜間** | 睡眠が確保でき、夜間も M2・M3 が維持。尿量が確保されている [E02] | 尿量減少→CIN・脱水／血圧低下→後腹膜出血 |
| **安静解除時** | 起立時の症状なし。**穿刺部の再出血なし**（M4） | 起立時の出血→再圧迫（V2） |
| **翌朝** | M4・M5 達成。**穿刺部に拍動性腫瘤・血管雑音なし**、下肢末梢動脈触知良好。歩行が入院前レベル | 拍動性腫瘤・雑音→**仮性動脈瘤／動静脈瘻を疑い医師報告** |
| **退院時** | G1-G13 達成。教育完了（M6） | 教育未完了→退院前に補完 |

> **造影後72時間以内の腎機能再評価** [E02] は、退院がそれより前になる場合、
> **外来での実施計画を退院時に確定**する（Q5）。

### N-2　離床を延期する条件

- 新規の神経症状（軽微でも）
- 穿刺部の出血・血腫増大
- **腰背部痛の増強、腹部膨満、原因不明の血圧低下**（→ 離床でなく S3 対応）
- **下肢の冷感・しびれ・色調不良・末梢動脈触知不良**
- 起立時のふらつき・血圧低下（迷走神経反射）

- **お休みしていたお薬は、決められた日から再開してください。** 自己判断で変更しないでください。
