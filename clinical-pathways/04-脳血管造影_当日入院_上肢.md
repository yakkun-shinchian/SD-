# パス04　脳血管造影・当日入院・上肢アクセス

対象診療科：脳血管外科
種別：予定入院（当日入院）・診断的血管造影／アクセス＝上肢動脈（橈骨動脈または上腕動脈）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`

> 治療（塞栓術・ステント留置）を併施する場合は本パスを適用せず、パス01・06 を用いる（F13）。

---

## A. 疾患・治療概要

上肢動脈からカテーテルを挿入し、頚部・頭蓋内血管を選択的に造影する **診断的検査**である。
**入院当日に検査を行う**ため、**入院前外来での準備完了が本パスの成否を決める。**

### 当日入院に固有の管理上の論点（本パスの中核）

| 論点 | 内容 | 対応 |
|------|------|------|
| **術前評価の完了** | 入院日に評価不足が判明しても、検査を延期する以外の選択肢が乏しい | **F0（外来完了チェック）を設け、入院前外来で完結させる** |
| **CIN予防補液の実施可能性** | 生食1mL/kg/h を **造影6時間前**から開始する予防法 [E03] は、当日入院では実施が困難 | **eGFR<30 等の予防対象例は当日入院に適さない → パス02（前日入院）へ振り分ける（D・E9）** |
| **休薬の確実性** | 抗血栓薬・ビグアナイド薬の休薬 [E04] が外来指示のまま未確認になりうる | **F6・F7 で入院時に実薬・最終服用時刻を確認** |
| **観察時間の確保** | 検査後の観察時間が短くなりうる | **退院可否は時間ではなく G・N-1 の条件で判断（V-04）** |

### このパスが管理すべき主要リスク

| リスク | 発生しやすい時期 | 対応セクション |
|--------|------------------|----------------|
| 神経合併症（塞栓性脳梗塞、一過性神経症状） | 検査中〜検査後24時間 | I・K-1・S1 |
| 穿刺部合併症（出血・血腫） | 検査中〜当日夜間 | K-4・S3 |
| **上肢アクセス特有**：橈骨動脈閉塞、手の虚血、前腕コンパートメント症候群、神経障害 | 圧迫中〜圧迫解除後 | **K-4U**・S3 |
| 造影剤アレルギー（即時型・**遅発型**） | 直後〜数日 | K-5・S7・**P7（退院後）** |
| 造影剤腎症（CIN） | 造影後72時間以内 | L・**Q5（外来評価の計画）** |
| 迷走神経反射 | 穿刺時・圧迫解除時 | K-3 |

> **当日入院・短期滞在では、遅発性の合併症（遅発型造影剤反応、CIN、橈骨動脈閉塞）が
> 退院後に顕在化する。** したがって **P（患者教育）と Q（退院支援）の比重が
> 前日入院パスより大きい。**

## B. エビデンスサマリー

1. **造影剤腎症**：CIN定義（造影後72時間以内に血清Cr 0.5mg/dL以上または25%以上上昇）、
   リスク評価・予防の対象は eGFR<30 [E02]。
   → **当日入院では造影後72時間の時点で既に退院しているため、
   「外来での腎機能再評価」を退院時に必ず計画する（Q5）。**
2. **CIN予防補液**：生食1mL/kg/h を造影6時間前から（参考値・未照合）[E03]。
   → **当日入院では実施困難。予防対象例は前日入院（パス02）へ振り分ける。**
3. **ビグアナイド系糖尿病薬の一時休薬** [E04]。
4. **観察頻度・圧迫解除時間・食事開始時刻・退院可能時刻**：医学的根拠を特定できず
   → `【エビデンス不足・院内検討事項 G-共通02〜04】`、および **V-04（退院時刻の判断基準）**。

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | 緊急・急性期の脳血管造影 | 時間軸・観察密度が異なる（パス09・12・13） |
| E2 | 造影と同時に血管内治療を予定 | パス01・06 を適用 |
| E3 | ヨード造影剤に対する重篤な過敏症の既往 | 造影不可 |
| E4 | 重篤な腎機能障害があり造影の可否が未決定 | [E02] |
| E5 | 上肢動脈の触知不良・シャント造設肢・穿刺困難が予想される | アクセス部位の再検討（鼠径アクセス＝パス05） |
| E6 | 意識障害・認知機能低下等により、検査中の指示従命や症状申告が困難 | 神経症状の早期検出が成立しない |
| E7 | 抗凝固療法中で休薬・調整方針が未決定 | 穿刺部合併症リスク |
| E8 | **入院前外来での術前評価が未完了**（F0 に未達項目がある） | 当日入院では入院日に補完する時間的余裕がない |
| **E9** | **CIN予防の術前補液を要する（eGFR<30 等の予防対象）** [E02][E03] | **造影6時間前からの補液が実施できないため。→ パス02（前日入院・上肢）へ振り分ける** |
| E10 | **退院後に異常を申告できる環境がない**（独居で連絡手段がない等） | 遅発性合併症の検出が成立しない。**入院期間の延長または前日入院を検討** |

**下表がすべて「済」でなければ当日入院としない。** 未完了項目があれば E8 に該当し、

## H. 中間アウトカム（逆算）

```
G1-G14 退院可能な状態
   ↑
M5  退院後に自分で異常を検出し、連絡・受診できる（G8-G12を説明できる）
   ↑
M4  歩行・上肢の使用が入院前レベルで、起立時症状がない
   ↑
M3  圧迫解除後も穿刺部が安定し、穿刺肢の血流・神経障害がない
   ↑
M2  検査直後〜数時間に新規神経脱落症状・造影剤反応を認めない
   ↑
M1  安全に検査を実施できる状態（F0すべて済＋F1-F13充足）
```

| # | 中間アウトカム | 達成判定 | 到達目標時期 |
|---|----------------|----------|--------------|
| M1 | 検査実施可能 | **F0 すべて「済」**＋F1-F13 すべて「確認済」 | 検査前まで |
| M2 | 新規神経症状・造影剤反応なし | F2 比較で新規所見なし、皮疹・呼吸困難なし | 検査直後〜6時間 |
| M3 | 穿刺部・穿刺肢が安定 | 出血なし、血腫増大なし、手指の色調・感覚・運動が正常、橈骨動脈触知良好 | 圧迫解除〜退院前 |
| M4 | 歩行・上肢使用が復帰 | 入院前レベル、起立時症状なし | 離床後〜退院前 |
| M5 | 退院後の自己管理ができる | G8-G12 すべて「達成」 | 退院前 |

## I. 時間軸別アウトカム

| 時期 | 順調な状態 | 逸脱時に疑うこと |
|------|-----------|------------------|
| **入院前外来** | **F0 の10項目がすべて完了**。腎機能評価済で予防補液の要否が判定済 [E02][E03]。休薬指示が伝達済 | 未完了項目→E8（当日入院に不適） |
| **入院日（検査前）** | F1-F13 確認済（M1）。**ベースライン神経所見・穿刺肢の所見を記録**。絶食・休薬が守られている | 未休薬・記録不備→医師報告 |
| **検査中〜直後** | 検査完遂。術者による神経学的確認済。穿刺部圧迫が適切 | 検査中の神経症状→S1 |
| **帰室時** | 意識・神経所見がベースラインと同等（M2）。**穿刺部圧迫良好、手指の色調・感覚・運動正常、橈骨動脈触知良好**（M3） | 手指の異常→S3 |
| **1時間後** | M2・M3 維持。圧迫による疼痛が許容範囲 | 前腕の緊満・激痛→**コンパートメント症候群を疑う（S3）** |
| **3時間後** | M2・M3 維持。飲水可 | 造影剤反応（皮疹・掻痒）→S7 |

| **翌朝（入院継続時）** | **橈骨動脈触知良好**、手指の感覚・運動正常。歩行が入院前レベル | 触知不良→橈骨動脈閉塞（医師報告） |

### ⚠ 入院中：この症状があれば、すぐにナースコールしてください

- **管を入れた手のしびれ、冷たさ、色が悪い（白い・紫っぽい）**
- **管を入れた腕の、どんどん強くなる痛み／腕がパンパンに張る感じ**
- 管を入れた場所からの出血、ふくらみ
- 手や足が急に動かしにくい、力が入らない
- 言葉が出にくい、ろれつが回らない／顔の片側がゆがむ
- 強い頭痛、吐き気
- 息が苦しい、のどがつまる感じ
- 体のかゆみ、じんましん
- 気分が悪い、冷や汗が出る

### ⚠ 退院後：この症状があれば、すぐにご連絡ください（連絡先は説明書に記載します）

- **管を入れた場所からの出血、ふくらみ、強い痛み、熱をもつ、膿が出る**
- **手のしびれ・冷たさ・力が入らないのが続く、または新しく出た**
- **かゆみ・発疹**（**造影剤の反応は、数時間から数日たってから出ることがあります**）
- 尿の量が減った、体がむくむ
- **顔のゆがみ・腕の脱力・言葉が出にくい** → **症状が出た時刻を確認して、すぐに救急要請してください**

### 退院後のお願い

- **お休みしていたお薬は、お伝えした日から再開してください。** 自己判断で早めたり遅らせたりしないでください。
- **管を入れた腕は、お伝えした期間、重い物を持たないでください。**
- **血液検査の予約がある方は、必ず受けてください**（造影剤のあとの腎臓の働きを確認するためです）。
