# パス05　脳血管造影・当日入院・鼠径アクセス

対象診療科：脳血管外科
種別：予定入院（当日入院）・診断的血管造影／アクセス＝鼠径部（大腿動脈）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`

> 治療（塞栓術・ステント留置）を併施する場合は本パスを適用せず、パス01・06 を用いる（F13）。

---

## A. 疾患・治療概要

大腿動脈からカテーテルを挿入し、頚部・頭蓋内血管を選択的に造影する **診断的検査**である。
本パスは **「当日入院」と「鼠径アクセス」という2つの制約が重なる**ため、
14パス中で最も **退院可否の判断** が問題になりやすい。

### 本パス固有の管理上の論点（最重要）

| 論点 | 内容 | 対応 |
|------|------|------|
| **術前評価の完了** | 入院日に不足が判明しても補完する時間がない | **F0（外来完了チェック）を必須化** |
| **CIN予防補液の実施可能性** | 生食1mL/kg/h を **造影6時間前**から [E03] は当日入院で実施困難 | **予防対象例は本パスの対象外 → パス03（前日入院・鼠径）へ（E9）** |
| **床上安静と在院時間の衝突** | 鼠径アクセスは床上安静を要するため、安静解除〜離床〜歩行確認までに時間を要する | **退院可否は時刻でなく G1-G15・N-1 の条件で判断（V-04）** |
| **後腹膜出血の遅発性** | 外表所見に乏しいまま進行し、**退院後に顕在化しうる** | **S3 の観察を退院直前まで継続し、T で退院後の申告項目に明記** |
| **退院後の申告環境** | 短期滞在では退院後の自己申告が安全網となる | **D9・E10・Q10 で支援環境を要件化** |

### 主要リスク

| リスク | 発生しやすい時期 | 対応セクション |
|--------|------------------|----------------|
| 神経合併症（塞栓性脳梗塞、一過性神経症状） | 検査中〜検査後24時間 | I・K-1・S1 |
| 穿刺部合併症（出血・血腫・仮性動脈瘤・動静脈瘻） | 検査中〜**退院後** | K-4・S3・**P11** |
| **後腹膜出血** | 検査中〜当日夜間・**退院後** | **K-4F**・S3・**T（退院後申告）** |
| **下肢虚血** | 圧迫中〜圧迫解除後 | **K-4F**・S3 |
| 迷走神経反射 | 穿刺時・圧迫解除時 | K-3 |
| 床上安静に伴う合併症（腰背部痛・排尿困難） | 安静中 | K-6 |
| 造影剤アレルギー（即時型・**遅発型**）／CIN | 直後〜72時間（**多くは退院後**） | K-5・L・**Q5・P9** |

## B. エビデンスサマリー

1. **造影剤腎症**：CIN定義（造影後72時間以内に血清Cr 0.5mg/dL以上または25%以上上昇）、
   予防・リスク評価の対象は eGFR<30 [E02]。
   → **当日入院では造影後72時間の時点で退院済みのため、外来での再評価を必ず計画（Q5）。**
2. **CIN予防補液**：生食1mL/kg/h を造影6時間前から（参考値・未照合）[E03]。
   → **当日入院では実施困難。予防対象例はパス03へ振り分ける（E9）。**
3. **ビグアナイド系糖尿病薬の一時休薬** [E04]。
4. **床上安静時間・圧迫解除時間・食事開始時刻・退院可能時刻**：医学的根拠を特定できず
   → `【G-共通02〜05】`。**本パスでは V-02・V-04 の審議優先度が最も高い。**

## D. 適用基準

| # | 適用条件 | 評価方法 |
|---|----------|----------|

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | 緊急・急性期の脳血管造影 | 時間軸・観察密度が異なる（パス09・12・13） |
| E2 | 造影と同時に血管内治療を予定 | パス01・06 を適用 |
| E3 | ヨード造影剤に対する重篤な過敏症の既往 | 造影不可 |
| E4 | 重篤な腎機能障害があり造影の可否が未決定 | [E02] |
| E5 | **鼠径部の感染・皮膚障害、高度の末梢動脈疾患、大腿動脈の触知不良** | 穿刺部合併症・下肢虚血のリスク → 上肢アクセス（パス04）を検討 |
| E6 | 意識障害・認知機能低下等により **床上安静の保持や症状申告が困難** | 合併症の早期検出が成立しない |
| E7 | 抗凝固療法中で休薬・調整方針が未決定 | 穿刺部合併症リスク |
| E8 | **入院前外来での術前評価が未完了**（F0 に未達項目がある） | 当日入院では補完する時間的余裕がない |
| **E9** | **CIN予防の術前補液を要する（eGFR<30 等の予防対象）** [E02][E03] | **造影6時間前からの補液が実施できない → パス03（前日入院・鼠径）へ振り分ける** |
| **E10** | **退院後に異常を申告できる環境がない**（独居で連絡手段がない等） | **後腹膜出血・仮性動脈瘤は退院後に顕在化しうる。** 入院延長または前日入院を検討 |
| E11 | 高度肥満・腹部膨満等により **穿刺部の圧迫・観察が困難** と判断される | 後腹膜出血の検出が困難 |

## F. パス開始条件

### F0　**入院前外来完了チェック（当日入院パス固有・最重要）**

**下表がすべて「済」でなければ当日入院としない。** 未完了があれば E8 に該当し、
前日入院（パス03）への変更または検査延期を検討する。

| # | 外来で完了しておくべき事項 | 未完了時の対応 |
|---|----------------------------|----------------|
| F0-1 | 検査目的とアクセス部位の決定 | 術者へ確認 |
| F0-2 | **血液検査（血算〔Hb〕・凝固・生化学／eGFR）の実施と結果確認** [E02] | 結果を待つ時間がない → 延期を検討 |
| F0-3 | **eGFR に基づくCIN予防の要否判定** [E02][E03] | 予防対象なら **E9 → パス03 へ** |
| F0-4 | 造影剤アレルギー歴・喘息／アレルギー歴の聴取 | 既往あり→E3 |
| F0-5 | 抗血栓薬・**ビグアナイド薬の休薬指示**と患者への説明 [E04] | 指示漏れ→延期を検討 |
| F0-6 | 心電図等の術前検査 | 未実施→院内基準に従い判断 |
| F0-7 | **鼠径部・下肢の評価**（大腿動脈の触知、皮膚状態、肥満度、**足背・後脛骨動脈の触知**） | 触知不良・皮膚障害→E5 |
| F0-8 | **床上安静の保持能力の評価**（腰痛・関節痛の既往、仰臥位保持の可否） | 困難→E6、上肢アクセスを検討 |
| F0-9 | 説明と同意 | 未取得→実施不可 |
| F0-10 | **絶食開始時刻・来院時刻の指示と患者の理解** | 不徹底→当日中止のリスク |
| F0-11 | **退院後の支援環境の確認**（同居者・連絡手段・帰宅手段） | 不足→E10 |
| F0-12 | **床上安静・床上排泄の事前説明** | 未説明→当日の混乱・安静保持困難 |

| # | 確認項目 | 確認内容 | 未達時の対応 |
|---|----------|----------|--------------|

## H. 中間アウトカム（逆算）

```
G1-G15 退院可能な状態
   ↑
M6  退院後に自分で異常（特に腰背部痛・脚の症状）を検出し、連絡できる
   ↑
M5  歩行が入院前レベルで、歩行後も穿刺部の再出血がなく、自排尿がある
   ↑
M4  安静解除・圧迫解除後も穿刺部が安定し、後腹膜出血・下肢虚血がない
   ↑
M3  床上安静を安全に完遂できている
   ↑
M2  検査直後〜数時間に新規神経脱落症状・造影剤反応を認めない
   ↑
M1  安全に検査を実施できる状態（F0すべて済＋F1-F13充足）
```

| # | 中間アウトカム | 達成判定 | 到達目標時期 |
|---|----------------|----------|--------------|
| M1 | 検査実施可能 | **F0 すべて「済」**＋F1-F13 すべて「確認済」 | 検査前まで |
| M2 | 新規神経症状・造影剤反応なし | F2 比較で新規所見なし、皮疹・呼吸困難なし | 検査直後〜6時間 |
| M3 | 床上安静を安全に完遂 | 穿刺部の出血・血腫増大なし、血圧が安定、腰背部痛が耐えられる範囲 | 帰室〜安静解除 |
| M4 | 穿刺部・下肢が安定 | 出血なし、**後腹膜出血徴候なし**、足背/後脛骨動脈触知良好 | 安静解除〜退院前 |
| M5 | 歩行・排尿が復帰 | 入院前レベルの歩行、**歩行後の再出血なし**、自排尿あり | 離床後〜退院前 |
| M6 | 退院後の自己管理ができる | G10-G13 すべて「達成」 | 退院前 |

## I. 時間軸別アウトカム

| 時期 | 順調な状態 | 逸脱時に疑うこと |
|------|-----------|------------------|
| **入院前外来** | **F0 の12項目がすべて完了**。腎機能評価済で予防補液の要否が判定済 [E02][E03]。**床上安静・床上排泄を事前説明済** | 未完了→E8（当日入院に不適） |
| **入院日（検査前）** | F1-F13 確認済（M1）。**ベースラインの神経所見・下肢末梢動脈・Hb・血圧を記録**。絶食・休薬が守られている | 未休薬・記録不備→医師報告 |
| **検査中〜直後** | 検査完遂。術者による神経学的確認済。穿刺部圧迫が適切 | 検査中の神経症状→S1 |
| **帰室時** | 意識・神経所見がベースラインと同等（M2）。穿刺部圧迫良好、**足背/後脛骨動脈触知良好**。**床上安静・穿刺肢伸展を保持**（M3） | 下肢の触知不良→S3 |
| **1時間後** | M2・M3 維持。血圧が安定 | **血圧低下＋腰背部痛→後腹膜出血（S3）** |
| **3時間後** | M2・M3 維持。飲水可。腰背部痛が耐えられる範囲 | 造影剤反応→S7 |

## N. 離床・ADL

### N-1　安静解除・離床開始条件（**すべて満たすこと**）

| # | 条件 | 確認方法 |
|---|------|----------|
| N1 | 新規神経脱落症状がない | ベースライン（F2）比較 |
| N2 | 意識レベルがベースラインと同等 | JCS/GCS |
| N3 | 循環動態が安定している | 血圧がベースライン域、頻脈・徐脈がない |
| N4 | 穿刺部の止血が良好 | 出血なし、血腫の拡大なし |
| N5 | **後腹膜出血を示唆する所見がない** | 腰背部痛の増強なし、腹部膨満なし、原因不明の血圧低下なし（K-4F） |
| N6 | **穿刺側下肢の血流が保たれている** | 足背/後脛骨動脈触知良好、色調正常、冷感・しびれなし |
| N7 | 医師の安静解除指示が出ている | 指示簿 |

### N-2　離床を延期する条件

- 新規の神経症状（軽微でも）
- 穿刺部の出血・血腫増大
- **腰背部痛の増強、腹部膨満、原因不明の血圧低下**（→ 離床でなく S3 対応）
- **下肢の冷感・しびれ・色調不良・末梢動脈触知不良**
- 起立時のふらつき・血圧低下

### N-3　離床の手順（**各段階の前後で穿刺部と下肢末梢動脈を確認**）

| 段階 | 実施内容 | 中止・後退の基準 |
|------|----------|------------------|
| ① 頭部挙上・体位変換 | 穿刺肢の伸展を保ったまま体位を変える | 穿刺部の出血・疼痛増強 |
| ② 端座位 | **穿刺部を手で押さえながら**起き上がる | 出血、めまい、血圧低下 |
| ③ 立位 | 見守りのもと立位保持 | 起立性の血圧低下、ふらつき、穿刺部出血 |
| ④ 室内歩行 | 見守り歩行 | 穿刺部の疼痛・出血、下肢症状 |
| ⑤ 病棟内歩行・トイレ歩行 | 自立を確認 | 同上 |

> **⑤の完了後に穿刺部を必ず再確認する。** これが G9（歩行後の再出血なし）の判定となり、
> **退院要件となる。**

### N-4　離床後アウトカム

| # | アウトカム | 判定 |
|---|-----------|------|
| N-O1 | 起立時症状なく立位・歩行ができる | あり／なし |
| N-O2 | **歩行後に穿刺部の再出血がない** | あり／なし（**退院要件 G9**） |
| N-O3 | トイレ歩行が自立し、自排尿がある | 達成／未達（G8・G9へ接続） |

## T. 患者用クリニカルパス

### 脳血管造影（足の付け根の血管から・入院当日に検査）を受けられる方へ

**入院した日に検査を行います。** 足の付け根の血管から細い管を入れ、
造影剤を使って脳の血管の形を詳しく調べます。
検査のあとは、**血が止まるまでベッドの上で、脚をまっすぐ伸ばしたまま**過ごしていただきます。

**入院期間が短いため、ご自宅に帰られてからご自身で気づいていただくことがとても大切です。**

### ⚠ 入院中：この症状があれば、すぐにナースコールしてください

- **腰や背中の痛み（新しく出た、だんだん強くなる）** ← とても大切です
- **お腹の張り、お腹の痛み**
- **管を入れた脚のしびれ、冷たさ、色が悪い（白い・紫っぽい）**
- 管を入れた場所からの出血、ふくらみ、どんどん強くなる痛み
- **冷や汗が出る、気分が悪い、目の前が暗くなる**
- 手や足が急に動かしにくい、力が入らない
- 言葉が出にくい、ろれつが回らない／顔の片側がゆがむ
- 強い頭痛、吐き気
- 息が苦しい、のどがつまる感じ
- 体のかゆみ、じんましん
- **尿が出ない、尿意はあるのに出せない**

### ⚠ 退院後：この症状があれば、すぐにご連絡ください（連絡先は説明書に記載します）

- **腰や背中の痛み、お腹の張り、冷や汗、ふらつき** ← **体の奥での出血のことがあります。すぐにご連絡ください**
- **管を入れた場所からの出血、ふくらみ、強い痛み、熱をもつ、膿が出る、ドキドキと拍動するしこりがある**
- **脚のしびれ・冷たさ・力が入らないのが続く、または新しく出た**
- **かゆみ・発疹**（**造影剤の反応は、数時間から数日たってから出ることがあります**）
- 尿の量が減った、体がむくむ
- **顔のゆがみ・腕の脱力・言葉が出にくい** → **症状が出た時刻を確認して、すぐに救急要請してください**

### 退院後のお願い

- **お休みしていたお薬は、お伝えした日から再開してください。** 自己判断で変更しないでください。
- **お伝えした期間は、重い物を持つ・激しい運動・入浴を控えてください。**
- **血液検査の予約がある方は、必ず受けてください**（造影剤のあとの腎臓の働きを確認するためです）。
