# パス07　未破裂脳動脈瘤・開頭クリッピング術

対象診療科：脳血管外科
種別：予定入院・予定開頭手術（全身麻酔）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`

---

## A. 疾患・治療概要

未破裂脳動脈瘤に対し、開頭して動脈瘤頚部にクリップをかけ、
**将来のくも膜下出血を予防する治療**である。

### 本パスの本質的な特徴

> **本治療は「予防的治療」かつ「開頭手術（全身麻酔）」である。**
> 多くの患者は治療前に無症状であり、**治療によって新たな神経障害・機能障害を
> 生じさせないことが治療の成否そのもの**である。
> さらに血管内治療（パス06）と異なり、**開頭・全身麻酔に伴う合併症群**（創部・髄液・
> けいれん・脳浮腫・全身合併症）を管理対象に含む。

この構造から、本パスでは次を設計に反映している。

1. **最終アウトカムの第一項目を「新規神経脱落症状がないこと」に置く**（G1）。
2. **適応判断の記録（3要素）と、経過観察・血管内治療という代替選択肢の説明を
   パス開始条件に含める**（F16・F17）。
3. **在院期間が長く、遅発性合併症（けいれん・創部感染・髄液漏・低ナトリウム血症）が
   POD数日以降に出現しうる**ため、時間軸を POD7 以降まで設定する。

### 自然歴（適応判断と患者説明の基礎）

| 指標 | 数値 | 出典 |
|------|------|------|
| 本邦の未破裂脳動脈瘤の年間平均破裂率 | **0.95%** | UCAS Japan [E30] |
| 最大径5mm未満の破裂率 | 約 **0.5%/年** | SUAVe study 2010 [E31] |
| 破裂率と最大径 | **相関する** | [E30] |

> **⚠ 「5〜7mm以上」「後方循環」「前交通動脈」「内頚動脈−後交通動脈分岐部」
> 「dome-neck aspect比が大きい」「不整形」等の治療考慮基準は
> `脳卒中治療ガイドライン2009` の記載に由来する [E33]。**
> **最新版で必ず確認すること（V-01）。**

1. **自然歴**：本邦の年間平均破裂率 0.95%（UCAS Japan）[E30]、5mm未満は約0.5%/年（SUAVe）[E31]。
2. **適応判断の枠組み**：**患者背景・推定自然歴・施設および術者の治療成績**を勘案する [E32]
   → **F16 で3要素の記録を必須化。**
3. **治療を考慮する動脈瘤の特徴**：旧版（2009）の記載 [E33]。**最新版で要確認（V-01）。**
4. **血管内治療と開頭術の選択**：部位・形態・患者背景・施設成績による [E34]。**要確認。**
5. **深部静脈血栓症の予防**：脳卒中領域では推奨が示されている [E45]。
   **開頭術後の予防法・適応は原典および院内の周術期規約で確定すること。**
6. **術後けいれん予防薬の投与・期間、創部管理、ドレーン管理、抗菌薬の投与期間**：
   本作業では医学的根拠を特定できず → `【エビデンス不足・院内検討事項】`（V-06〜V-09）。
7. **観察頻度・離床時期・食事開始時刻・在院日数**：根拠を特定できず → `【G-共通02〜05】`。

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | **破裂脳動脈瘤（くも膜下出血）** | 病態・時間軸・観察密度が全く異なる。個別診療 |
| E2 | 切迫破裂が疑われ緊急手術を要する | 緊急対応。個別診療 |
| E3 | **全身麻酔・開頭手術のリスクが許容できない全身状態** | 麻酔科・関連科と協議のうえ個別判断 |
| E4 | 活動性感染（特に頭皮・全身の感染） | 創部感染・髄膜炎のリスク |
| E5 | 出血傾向が是正できない、または抗血栓薬の休薬ができない | 術後出血のリスク |
| E6 | 意識障害・重度認知機能低下等により、症状申告・術後管理への協力が困難 | 神経症状の早期検出が成立しない |
| E7 | **適応判断の記録（D3）が不十分** | 予防的治療の正当性が担保されない |

## N. 離床・ADL

**「POD1に離床」という日程起点の設定を行わない。以下の条件充足を起点とする。**

### N-1　離床開始条件（**すべて満たすこと**）

| # | 条件 | 確認方法 |
|---|------|----------|
| N1 | **意識レベルがベースラインと同等で、指示に従える** | JCS/GCS、指示従命 |
| N2 | 新規神経脱落症状がない、または離床を安全に行える範囲である | ベースライン（F2）比較 |
| N3 | **瞳孔・対光反射が正常** | 経時比較 |
| N4 | **増強する頭痛・嘔吐がない** | F4 のベースラインと比較 |
| N5 | 循環動態が安定している | 医師指示の目標血圧域内 |
| N6 | **ドレーンの管理方法（クランプの要否等）について医師指示がある** | 指示簿 |
| N7 | 創部からの出血・髄液漏がない | K-5 |
| N8 | けいれん発作がない | ― |
| N9 | 疼痛が離床を妨げない範囲 | 患者の申告 |
| N10 | 医師の離床許可が出ている | 指示簿 |

### N-2　離床を延期する条件

- 意識レベルの低下、指示従命の不良
- 新規の神経症状（軽微でも）
- **増強する頭痛・嘔吐**
- 瞳孔不同・対光反射の異常
- **けいれん発作の既往（当該入院中）** → 医師の判断を要する
- 創部からの出血・髄液漏、ドレーン排液の異常
- 血圧が目標域を逸脱（高値・低値いずれも）
- 起立時のふらつき・失神様症状・血圧低下

### N-3　離床の手順（**各段階で神経症状と創部・ドレーンを確認**）

| 段階 | 実施内容 | 中止・後退の基準 |
|------|----------|------------------|
| ① 頭部挙上 | 医師指示の角度まで段階的に | 頭痛の増強、悪心、意識レベルの変化 |
| ② 端座位 | 見守りのもと保持 | めまい、血圧低下、頭痛の増強 |
| ③ 立位 | 見守りのもと保持 | 起立性の血圧低下、ふらつき |
| ④ 室内歩行 | 見守り歩行 | ふらつき、新規の神経症状 |
| ⑤ 病棟内歩行 | 自立を確認 | 同上 |

**各段階の前後で、意識レベル・頭痛・創部・ドレーン排液を確認する。**

### N-4　離床後アウトカム

| # | アウトカム | 判定 |
|---|-----------|------|
| N-O1 | 起立時症状なく端座位・立位が保持できる | あり／なし |
| N-O2 | 室内歩行が安全に行える | 自立／見守り／介助 |
| N-O3 | 病棟内歩行が退院可能なレベルに達した | 達成／未達（G11へ接続） |
| N-O4 | 離床後に頭痛・神経症状の悪化がない | あり／なし |

### N-5　リハビリテーション

| 項目 | 内容 |
|------|------|
| 介入の開始 | **N-1 の条件充足後、医師指示によりPT/OTが介入** |
| 評価項目 | 筋力、バランス、歩行、ADL、高次脳機能 |
| 中止基準 | N-2 の条件に該当した場合、および施設のリハビリ中止基準に該当した場合 |
| 継続の判断 | 退院時に **入院前レベルに達していない場合**、外来リハビリまたは回復期リハビリ病棟への転院を検討（G18） |

## T. 患者用クリニカルパス

### 脳動脈瘤の開頭手術（クリッピング術）を受けられる方へ

頭を開けて、脳の血管にできた「こぶ（動脈瘤）」の根元に小さなクリップをかけ、
**将来こぶが破れて出血（くも膜下出血）を起こさないように予防する手術**です。

**この手術は、今ある症状を治すためのものではなく、これから起こるかもしれない出血を
防ぐためのものです。** そのため、**手術によって新しい症状が出ないこと**をいちばん大切にして、
意識・手足の動き・言葉・目の症状を繰り返し確認します。

| 日・時期 | 今日の目標 | 検査・治療 | お薬 | 食事 | 安静・歩行 | 排泄・清潔 | 説明・練習 | 患者さんに確認してほしい症状 |

### ⚠ この症状があれば、すぐにナースコールしてください

- **強くなる頭痛、吐き気、勢いよく吐く**
- **なんとなくぼんやりする、眠くて起きられない**（ご家族が気づかれた場合も含みます）
- **けいれん（体が勝手にふるえる、意識がなくなる）**
- 手や足が動かしにくい、力が入らない
- 言葉が出にくい、ろれつが回らない
- **ものが二重に見える、まぶたが下がる、見えにくい**
- 首の後ろが硬く、動かしにくい
- 熱が出た
- **傷からの出血、液のしみ出し（特に透明な水のような液）**
- 傷のまわりが赤い、腫れている、押すと痛い、ぶよぶよする
- ふくらはぎの腫れ・痛み、息苦しさ・胸の痛み
- 息が苦しい

### 退院後、すぐに病院へ連絡・受診していただきたいこと

- **けいれん発作**（**まわりの方は、体を無理に押さえず、けがをしないように周囲の物をどけ、
  発作の時間を計ってください。長く続く・繰り返すときは救急要請してください**）
- **強い頭痛、吐き気、意識がぼんやりする**
- **傷の赤み・腫れ・膿・透明な液のしみ出し**、**熱が出た**
- 顔のゆがみ・腕の力が入らない・言葉が出にくい
  → **症状が出た時刻を確認して、すぐに救急要請してください**
- **お薬（けいれんを予防する薬など）は、自己判断でやめないでください**

### 退院後の生活について

- **入浴・洗髪の開始時期、お仕事への復帰、車の運転**については、**主治医が個別にご説明します。**
  自己判断で再開しないでください。
- **手術のあとも、定期的に画像検査で確認していきます。** 次回の予定は退院時にお伝えします。
- 傷の痛みや、頭の違和感、口の開けにくさは、**時間をかけて改善していくことが多い**症状です。
  気になるときはご相談ください。
