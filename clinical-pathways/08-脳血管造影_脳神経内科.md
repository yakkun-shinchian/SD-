# パス08　脳血管造影（脳神経内科）

対象診療科：脳神経内科
種別：予定入院・診断的血管造影（アクセスは上肢・鼠径のいずれも可。**選択に応じて観察項目を切り替える**）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`

---

## A. 疾患・治療概要

脳神経内科が診断目的で施行する脳血管造影である。
主な検査目的は、**脳梗塞・TIAの病因検索、頭蓋内外血管の狭窄／閉塞の評価、
動脈解離、もやもや病、血管炎（中枢神経系血管炎）、可逆性脳血管攣縮症候群、
静脈系病変の評価** など、**非侵襲的画像（MRA・CTA・エコー）では診断が確定しない病態**である。

### 脳血管外科の造影パス（02〜05）との決定的な違い

| 観点 | 脳神経内科（本パス） | 脳血管外科（パス02〜05） |
|------|----------------------|--------------------------|
| **患者の神経学的ベースライン** | **既存の神経脱落症状を有する患者が多い**（脳梗塞後・TIA後等） | 無症状のことが多い |
| 検査後の神経症状の判定 | **「新規」か「既存の症状の変動」かの判別が難しい** → **NIHSS・詳細な所見のベースライン記録が決定的に重要** | ベースラインとの単純比較で判定しやすい |
| 抗血栓薬 | **休薬できない、または休薬すべきでない症例が多い**（再発予防中） | 休薬可能なことが多い |
| 検査の帰結 | 診断確定 → **内科的治療方針の決定**（抗血栓療法の選択、免疫療法の適応判断等） | 治療（外科・血管内治療）の適応判断 |
| 併存病態 | 脳血管障害の危険因子（高血圧・糖尿病・腎機能低下・心疾患）を有する頻度が高い | 同左だが無症候例を含む |

> **本パスの設計上の中核は「ベースラインの精密な記録」である。**
> 既存の症状がある患者では、**記録がなければ検査後の悪化を検出できない。**

### このパスが管理すべき主要リスク

| リスク | 発生しやすい時期 | 対応セクション |
|--------|------------------|----------------|
| 神経合併症（塞栓性脳梗塞、一過性神経症状、**既存症状の増悪**） | 検査中〜検査後24時間 | I・K-1・S1 |
| 穿刺部合併症 | 検査中〜当日夜間 | K-4・K-4U／K-4F・S3 |
| **抗血栓薬継続下での出血** | 検査中〜検査後 | K-4・M・S3 |
| 造影剤アレルギー（即時型・遅発型） | 直後〜数日 | K-5・S7 |
| **造影剤腎症（CIN）**（**糖尿病・腎機能低下の併存が多い**） | 造影後72時間以内 | L・M・S6 |
| 迷走神経反射 | 穿刺時・圧迫解除時 | K-3 |
| **原疾患の増悪**（検査と無関係な脳梗塞の再発を含む） | 全期間 | S1・R |

## B. エビデンスサマリー

1. **造影剤腎症**：CIN定義（造影後72時間以内に血清Cr 0.5mg/dL以上または25%以上上昇）、
   リスク評価・予防の対象は **eGFR<30** [E02]。**本パスの対象患者は糖尿病・腎機能低下の
   併存頻度が高いため、全例で術前評価を必須化する。**
2. **CIN予防補液**：生食1mL/kg/h を造影6時間前から、造影後6〜12時間継続（参考値・未照合）[E03]。
3. **ビグアナイド系糖尿病薬の一時休薬** [E04]。
4. **抗血栓療法**：脳梗塞・TIA の再発予防として抗血小板薬・抗凝固薬が投与されている場合、
   その適応と休薬の可否は原疾患のガイドラインに基づき医師が判断する [E40][E41][E42]。
   **本資料では休薬日数を記載しない。**
5. **観察頻度・安静時間・食事開始時刻・在院日数**：医学的根拠を特定できず
   → `【エビデンス不足・院内検討事項 G-共通02〜05】`。

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| E1 | 急性期（超急性期）の脳血管造影・血栓回収を前提とする検査 | 時間軸・観察密度が異なる。パス09・13、および血栓回収の体制で対応 [E10] |
| E2 | 造影と同時に血管内治療を予定 | 治療パス（01・06 等）を適用 |
| E3 | ヨード造影剤に対する重篤な過敏症の既往 | 造影不可 |
| E4 | 重篤な腎機能障害があり造影の可否が未決定 | [E02]。腎臓内科と協議のうえ個別管理 |
| E5 | **神経症状が不安定で増悪傾向にある**（進行性脳梗塞、症状の動揺が続くTIA等） | **検査後の変化と原疾患の進行を区別できない。** 病状が安定してから、または急性期病態として個別管理 |
| E6 | 意識障害・重度認知機能低下等により、症状申告・安静保持が困難 | 合併症の早期検出が成立しない |
| E7 | 抗血栓療法の休薬・継続方針が未決定 | 出血／血栓のいずれのリスクも管理できない |
| E8 | アクセス予定部位の動脈触知不良・皮膚障害・穿刺困難 | アクセス部位の再検討 |

```
G1-G13 退院可能な状態
   ↑
M5  再開薬・受診基準・今後の方針を患者（または家族）が説明できる
```

## K. 看護師用観察・実施項目

> 観察**頻度**は `【G-共通02】`。**何を見るか**は下表で確定する。

### K-1　神経（**本パスの中核。既存所見との1項目ずつの対比が必須**）

| 項目 | 具体的な観察内容 | 異常と判断する所見 |
|------|------------------|--------------------|
| 意識レベル | JCS または GCS | ベースラインより低下 |
| 瞳孔・対光反射 | 左右径、対光反射 | 新規の瞳孔不同、対光反射消失 |
| **運動麻痺** | 上肢Barré徴候、下肢Mingazzini徴候。**既存麻痺がある場合は「F2に記録された程度と比べてどうか」を評価** | **新規の麻痺、または既存麻痺の悪化** |
| 感覚 | 触覚・痛覚（既存の感覚障害の範囲と比較） | 範囲の拡大、新規の感覚障害 |
| **構音・失語** | 発語明瞭度、呼称、指示従命。**既存の失語がある場合は種類と程度を比較** | 新規または悪化 |
| 視野・半側空間無視 | 対座法、食事の残し方 | 新規の視野欠損・片側無視 |
| 失調・歩行 | 指鼻試験、**歩行の様子（既存の歩行状態と比較）** | 新規のふらつき・失調 |

| **NIHSS** | **帰室時・翌朝・症状変化時に測定し、F3 のベースラインと比較** | **ベースラインからの悪化＝直ちに医師報告（S1）** |

| N8 | 医師の離床許可が出ている | 指示簿 |

### N-2　離床を延期する条件

- **新規の神経症状、または既存症状の悪化**
- 穿刺部の出血・血腫増大
- アクセス肢の血流障害・神経症状（K-4U／K-4F）
- **鼠径アクセス時：腰背部痛の増強、腹部膨満、原因不明の血圧低下**
- 起立時のふらつき・血圧低下

### N-3　離床時の配慮（**既存の神経障害がある患者への対応**）

| 状況 | 配慮 |
|------|------|
| 片麻痺がある | **健側から起き上がる／立ち上がる**。介助者の立ち位置を患側に配置し転倒を予防 |
| 失調・平衡障害がある | 歩行器・介助者による見守りを確保 |
| 半側空間無視がある | **無視側の障害物を除去**し、声かけを無視側からも行う |
| 上肢アクセス＋麻痺 | **麻痺側と穿刺肢が重なる場合、起き上がり・移動の方法を事前に検討**（健側で支えられない可能性） |
| 鼠径アクセス＋麻痺 | 床上排泄・体位変換の介助方法を事前に検討 |

### ⚠ この症状があれば、すぐにナースコールしてください

- 手や足が急に動かしにくい、力が入らない
- **もともとあった症状が、前より強くなった** ← これも大切なサインです
- 言葉が出にくい、ろれつが回らない／顔の片側がゆがむ
- 目が見えにくい、片側が見えない、ものが二重に見える
- 強い頭痛、吐き気
- **管を入れた手（脚）のしびれ、冷たさ、色が悪い**
- **管を入れた腕がパンパンに張る／脚の付け根から入れた方は、腰や背中の痛み・お腹の張り**
- 管を入れた場所からの出血、ふくらみ、強い痛み
- 冷や汗が出る、気分が悪い、目の前が暗くなる
- 息が苦しい、のどがつまる感じ
- 体のかゆみ、じんましん
- （糖尿病の方）**冷や汗・手のふるえ・空腹感が強い**（低血糖のことがあります）

### 退院後に注意していただきたいこと

- **お薬について**：**血をサラサラにする薬は、自己判断でやめないでください。**
  お休みしていた薬は、お伝えした日から再開してください。
- **数時間〜数日たってから、かゆみや発疹が出ることがあります**（造影剤による遅れて出る反応）。
- 管を入れた場所の **出血・腫れ・熱をもつ・膿が出る・拍動するしこり** があればご連絡ください。
- **顔のゆがみ・腕の力が入らない・言葉が出にくい症状**が出たら、
  → **症状が出た時刻を確認して、すぐに救急要請してください**
  （**いつ始まったかによって、受けられる治療が変わります**）。
