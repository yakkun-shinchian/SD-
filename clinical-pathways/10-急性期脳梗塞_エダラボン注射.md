# パス10　急性期脳梗塞・エダラボン注射

対象診療科：脳神経内科／脳卒中診療科
種別：緊急入院・急性期内科治療（**エダラボン注射剤を併用する場合**）
参照：`00-共通設計方針.md`／`00-エビデンス一覧.md`／**`09-急性期脳梗塞.md`**

> **本パスは パス09（急性期脳梗塞）に「エダラボン注射剤の投与管理」を上乗せするパスである。**
> 脳梗塞そのものの管理（神経観察・嚥下・離床・再発予防・退院支援）は **パス09 に従う**。
> 本ファイルでは、**エダラボン投与に固有の適応判定・投与管理・安全性監視・中止基準**を
> A〜X の構成で網羅する。**両パスを併用すること。**

---

## A. 疾患・治療概要

エダラボン注射剤（ラジカット®注30mg／点滴静注バッグ30mg）は、
**「脳梗塞急性期に伴う神経症候、日常生活動作障害、機能障害の改善」** を効能・効果とする
薬剤である [E11]。

### 用法・用量（電子添文 [E11]）

| 項目 | 内容 |
|------|------|
| 1回量 | **エダラボンとして30mg（1袋／1管）** |
| 投与方法 | **30分かけて点滴静注** |
| 投与回数 | **1日朝夕2回** |
| **投与開始時期** | **発症後24時間以内に投与を開始する** |
| **投与期間** | **14日以内** |

> **上記はすべて電子添文の記載である。院内での確定にあたっては、
> 必ず最新の電子添文を参照すること（本資料は二次情報で確認した内容である）。**

### 警告・禁忌（電子添文 [E12]）

| 区分 | 内容 |
|------|------|
| **警告** | **急性腎障害の増悪または腎機能障害の増悪、重篤な肝障害、播種性血管内凝固症候群（DIC）** があらわれ、**致命的な経過をたどることがある**。これらの症例では、腎機能障害・肝機能障害・血液障害等を同時に発現する重篤な症例が報告されている |
| **禁忌** | **重篤な腎機能障害のある患者には投与しない** |
| **重要な基本的注意** | **脱水のある患者**では投与に際し全身管理を徹底する必要がある。**BUN/クレアチニン比が高いなど脱水状態が認められた患者では致命的経過をたどる例が多く報告されている** |

> **本パスの設計上の中核は「腎機能・肝機能・血液障害・脱水の監視」である。**
> エダラボン投与そのものが、パス09 に **新たな監視項目と離脱基準を追加する**。

### このパスが管理すべき主要リスク（**パス09 のリスクに加えて**）

| リスク | 発生しやすい時期 | 対応セクション |
|--------|------------------|----------------|
| **急性腎障害・腎機能障害の増悪** | 投与開始後〜投与期間中 | **L・K-6・S1** |
| **重篤な肝障害** | 同上 | **L・S2** |
| **播種性血管内凝固症候群（DIC）** | 同上 | **L・K-4・S3** |
| **脱水（腎障害の増悪因子）** | 投与前〜投与期間中 | **F・K-6・M** |
| 過敏症（発疹・アナフィラキシー） | 投与中〜投与後 | K-5・S4 |
| 投与ラインのトラブル・血管外漏出 | 投与中 | K-4 |
| **投与開始時期の逸失（発症24時間以内）** | 入院直後 | **F1・R** |

## B. エビデンスサマリー

1. **効能・効果**：脳梗塞急性期に伴う神経症候、日常生活動作障害、機能障害の改善 [E11]。
2. **用法・用量**：1回30mgを30分かけて1日朝夕2回点滴静注。
   **発症後24時間以内に開始、投与期間は14日以内** [E11]。
3. **警告**：急性腎障害の増悪・腎機能障害の増悪、重篤な肝障害、DIC が現れ致命的経過をたどりうる [E12]。
4. **禁忌**：重篤な腎機能障害のある患者 [E12]。
5. **脱水**：BUN/クレアチニン比が高いなど脱水が認められた患者で致命的経過の報告が多い [E12]。
6. **脳梗塞そのものの管理**：パス09 の全項目（[E01][E05]〜[E10]、[E40]〜[E47]）に従う。
7. **投与中の検査頻度（腎機能・肝機能・血算の測定間隔）**：
   **本作業では具体的な測定間隔を特定できなかった** → `【エビデンス不足・院内検討事項 V-01】`。
   **電子添文の記載を院内で確認し、測定間隔を明文化すること。**

## D. 適用基準

**パス09 の適用基準（D1-D4）を満たしたうえで、以下をすべて満たすこと。**

| # | 適用条件 | 評価方法 |
|---|----------|----------|
| D1 | **急性期脳梗塞と診断されている** | 画像・臨床所見（パス09 D1） |
| **D2** | **発症後24時間以内に投与を開始できる** [E11] | **発症時刻（最終健常確認時刻）から算出**（F1） |
| D3 | **重篤な腎機能障害がない** [E12] | 血清Cr、eGFR、既往（**F3 で必ず確認**） |
| D4 | **脱水状態にない、または補正されている** [E12] | BUN、血清Cr、**BUN/クレアチニン比**、身体所見（F4） |
| D5 | 肝機能・血液検査に投与を妨げる異常がない | 肝機能、血算、凝固（F5） |
| D6 | エダラボンに対する過敏症の既往がない | 薬剤アレルギー歴 |
| D7 | 点滴静注のための静脈路が確保できる | 入院時評価 |
| D8 | **投与の目的とリスク（腎・肝・血液障害）について説明がなされている** | 説明記録 |

## E. 除外基準

| # | 除外条件 | 理由 |
|---|----------|------|
| **E1** | **重篤な腎機能障害のある患者** | **電子添文で禁忌** [E12] |
| **E2** | **発症後24時間を超えている** | **電子添文の用法・用量に適合しない** [E11] |
| E3 | エダラボンに対する過敏症の既往 | 薬剤過敏 |
| E4 | **脱水状態が是正されていない** | **致命的経過の報告が多い** [E12]。補正後に再評価 |
| E5 | 重篤な肝機能障害 | [E12]（警告に肝障害の記載）。**医師が個別に判断** |
| E6 | 活動性の出血・DIC を疑う所見がある | [E12]（警告にDICの記載） |
| E7 | 脳梗塞以外の病態（脳出血等） | 適応外。パス12等へ |
| E8 | 全身状態により標準的な管理が適さない | 個別診療 |

> **本パスは「エダラボンを投与しないこと」を否定するものではない。**
> **投与しない場合はパス09 のみを適用する。** 投与の可否は医師の判断による。

## G. 最終アウトカム（投与終了時／退院時）

**パス09 の G1-G20 に加えて、エダラボン投与に関する以下を評価する。**

| 領域 | # | 最終アウトカム | 判定基準 |
|------|---|----------------|----------|
| 医学的 | **EG1** | **投与に伴う急性腎障害・腎機能障害の増悪がない** | **投与前（F3）と比較して血清Cr・eGFRの悪化：なし** [E12] |
| 医学的 | **EG2** | **重篤な肝障害を生じていない** | 肝機能検査値の異常な上昇：**なし** [E12] |
| 医学的 | **EG3** | **DIC を生じていない** | 血小板数の低下、凝固異常、出血傾向：**なし** [E12] |
| 医学的 | EG4 | 脱水を生じていない | in-out バランス、尿量、BUN/Cr比：**適正** [E12] |
| 医学的 | EG5 | 過敏症状（発疹・アナフィラキシー）を生じていない | 皮疹・掻痒・呼吸困難：**なし** |
| 医学的 | EG6 | 投与部位の障害（血管外漏出・静脈炎）がない | 発赤・腫脹・疼痛：**なし** |
| 医学的 | **EG7** | **投与が計画どおり完了した、または中止理由が明確に記録されている** | 完了／中止（**理由・時刻・判断医師を記録**） |
| 患者教育 | EG8 | **投与した薬剤の名称と目的**を本人または家族が述べられる | 説明可能：**達成** |
| 退院支援 | EG9 | **投与終了後の腎機能・肝機能のフォロー方針**が確定している | 確定：**達成** |

> **注意**：「神経症状が改善したこと」は本剤の効能・効果に関わるが、
> **改善の程度は個々の症例で異なるため、最終アウトカムの達成条件とはしない。**
> 神経学的転帰の評価は **パス09 の G1・G11（NIHSS・ADL）** で行う。

## H. 中間アウトカム（逆算）

```
EG1-EG9 投与を安全に完了し、退院可能な状態
   ↑
EM4  投与終了までの全期間で、腎・肝・血液の異常を認めない
   ↑
EM3  投与中に脱水を生じず、in-out バランスが保たれている
   ↑
EM2  初回投与を安全に完了し、過敏症状・投与部位の障害がない
   ↑
EM1  投与前の適応判定が完了している（発症24時間以内・腎機能・脱水・肝機能・血算）
```

| # | 中間アウトカム | 達成判定 | 到達目標時期 |
|---|----------------|----------|--------------|
| EM1 | 投与前評価完了 | F1-F10 すべて「確認済」 | **発症24時間以内・投与開始前** |
| EM2 | 初回投与を安全に完了 | 30分で完遂、過敏症状なし、投与部位に異常なし | 初回投与時 |
| EM3 | 脱水がない | 尿量・in-out・BUN/Cr比が適正 | 投与期間中（毎日） |
| EM4 | 腎・肝・血液の異常なし | **定期検査で悪化なし** [E12] | 投与期間中〜投与終了時 |

## I. 時間軸別アウトカム

**エダラボン投与の時間軸は「発症からの時間」と「投与日数」の2軸で管理する。**

| 時期 | 順調な状態 | 逸脱時に疑うこと |
|------|-----------|------------------|
| **入院直後（0h）** | **発症時刻が確定し、24時間以内の投与開始が可能と判定されている** [E11]。腎機能・脱水・肝機能・血算が評価済（F3-F5） | 発症時刻不明→投与可否の判断不能 |
| **投与開始前** | EM1 達成。**禁忌（重篤な腎機能障害）・脱水が除外されている** [E12]。静脈路が確保され、測定計画が指示されている | 禁忌該当→E1（投与しない） |
| **初回投与中（30分）** | 予定どおり30分で投与。**過敏症状（発疹・掻痒・呼吸困難・血圧低下）がない**。投与部位に異常がない | 過敏症状→**直ちに中止し医師報告（S4）** |
| **初回投与直後** | EM2 達成。バイタルサインが安定 | ― |
| **投与1日目（朝夕2回）** | 2回とも完遂。尿量が確保されている | 尿量減少→脱水・腎障害を疑う |
| **投与2〜3日目** | EM3 維持。**定期検査で腎機能・肝機能・血算に悪化がない** [E12] | **血清Cr上昇→S1**／肝機能上昇→S2／血小板低下→S3 |
| **投与4〜7日目** | EM3・EM4 維持。パス09 の中間アウトカムも並行して達成 | 同上 |
| **投与8〜14日目** | EM4 維持。**投与14日目を超えない** [E11] | 14日超→**用法・用量からの逸脱（R参照）** |
| **投与終了時** | EG1-EG7 達成。**投与終了日が記録されている** | 中止した場合は理由・時刻・判断医師を記録 |
| **退院時** | EG8・EG9 達成。**投与終了後の腎・肝機能のフォロー方針が確定** | ― |

> **投与期間14日以内は電子添文の記載である** [E11]。
> **14日を超える投与は用法・用量からの逸脱であり、行わない。**

## S. 安全停止・パス離脱基準

**パス09 の S1-S11（脳梗塞に関する離脱基準）に加えて、以下を適用する。**
いずれも **エダラボン投与の中止を検討する基準** であり、離脱時は
「時刻・該当基準・検査値・判断医師」を記録する。

| # | 離脱基準（**エダラボン投与に関するもの**） | 判断根拠 |
|---|--------------------------------------------|----------|
| **ES1** | **急性腎障害の発症、または腎機能障害の増悪**（血清Crの上昇、eGFRの低下、尿量減少） | **電子添文の警告事項。致命的経過をたどることがある** [E12] |
| **ES2** | **重篤な肝障害**（肝機能検査値の著明な上昇、黄疸） | **同上** [E12] |
| **ES3** | **播種性血管内凝固症候群（DIC）**（血小板減少、凝固異常、出血傾向） | **同上** [E12] |
| **ES4** | **過敏症・アナフィラキシー**（発疹、呼吸困難、血圧低下） | 薬剤過敏 |
| **ES5** | **脱水の進行が補正できない** | **脱水患者での致命的経過の報告** [E12] |
| **ES6** | **重篤な血管外漏出による組織障害** | 局所の個別治療を要する |
| **ES7** | **投与期間14日を超える** | **用法・用量からの逸脱** [E11]。**14日を超えて投与しない** |

> **ES1〜ES3 は電子添文の警告に基づく。** これらは **「同時に発現する重篤な症例が
> 報告されている」** とされているため、**一つを認めた場合は他の2つも必ず評価する** [E12]。

### ⚠ この症状があれば、すぐにナースコールしてください

**点滴中・点滴の直後**
- **体のかゆみ、発疹、じんましん**
- **息が苦しい、のどがつまる感じ、ゼーゼーする**
- 気分が悪い、冷や汗、めまい
- **点滴の針が入っている所が痛い、腫れてきた、漏れている感じがする**

**点滴を行っている期間中**
- **尿の量が減った、尿が出ない**
- 体がむくむ
- **体に あざ ができやすい、鼻血が出る、歯ぐきから血が出る、尿が赤い、便が黒い**
- **白目や皮膚が黄色くなってきた**
- 強いだるさ、食欲がない
- 熱が出た

**あわせて、脳梗塞そのものの症状（パス09 の申告項目）にも注意してください**
- 手足が動かしにくくなった／言葉が出にくくなった／ぼんやりする など

### ご協力のお願い

- **お水・お茶などの水分は、決められた方法（とろみの有無など）で、しっかりとってください。**
  **体の水分が足りないと、腎臓への負担が大きくなります。**
- **尿の量を測らせていただきます。** トイレのたびにお声かけください。
- **定期的に血液検査を行います。** 腎臓・肝臓・血液の状態を確認するために必要な検査です。
