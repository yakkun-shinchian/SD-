# 90 バリアンス管理表（成果物④・全パス横断）

本ファイルは、14パス共通で用いる **バリアンスの記録様式・集計様式・分析方法**を定める。
各パスの **R セクション**（時期別のバリアンス一覧）と対で使用する。

参照：`00-共通設計方針.md` §4（バリアンス分類）

---

## 1. バリアンス分類（再掲）

| 区分 | 名称 | 定義 | 標準対応 |
|------|------|------|----------|
| **V0** | 正のバリアンス | 予定より早期に中間アウトカムを達成 | パス継続。前倒しの可否を医師判断。**記録は必須** |
| **V1** | 軽度負のバリアンス | パス内の標準対応で解決可能 | 病棟内対応。記録し次勤務帯へ申し送り |
| **V2** | 中等度バリアンス | 追加評価・検査・治療変更を要するが、パス継続の可能性が残る | **医師報告必須**。追加指示を受けパス継続可否を判断 |
| **V3** | 重大バリアンス | 標準パスの継続が不適切 | **パス離脱**。離脱理由・時刻・判断医師を記録 |

> **重要**：**「ADLが目標に達しない」「退院先が決まらない」「疾患が進行した（ALS）」は
> V3（離脱）ではない。** 計画的なバリアンス（V1〜V2）として扱い、
> リハビリ継続・転院調整・支援の見直しへ接続する。

## 2. バリアンス記録様式（**1件＝1レコード**）

電子カルテへの実装を想定した項目定義。**太字は必須項目**。

| # | 項目名 | 型 | 内容・選択肢 |
|---|--------|-----|--------------|
| 1 | **記録ID** | 自動採番 | ― |
| 2 | **患者ID** | 参照 | ― |
| 3 | **適用パス** | 選択 | 01〜14 |
| 4 | **発生日時** | 日時 | 分単位 |
| 5 | **発見日時** | 日時 | 発生と発見が異なる場合に区別（**観察頻度の妥当性検証に用いる**） |
| 6 | **発生時期区分** | 選択 | 各パスの I／J の時期区分（例：帰室時、POD1、0〜6時間、投与中 等） |
| 7 | **該当する中間アウトカム** | 選択 | 各パスの M1〜M7 等 |
| 8 | **バリアンス内容** | 選択＋自由記載 | 各パスの R に列挙された事象から選択。該当なしは自由記載 |
| 9 | **分類** | 選択 | **V0／V1／V2／V3** |
| 10 | **原因分類** | 選択（複数可） | `患者要因` / `疾病要因` / `治療・薬剤要因` / `医療者要因` / `システム・運用要因` / `家族・社会的要因` |
| 11 | **原因の詳細** | 自由記載 | ― |
| 12 | **実施した初期対応** | 自由記載 | ― |
| 13 | **医師報告の有無** | 選択 | あり／なし／不要 |
| 14 | **医師報告日時** | 日時 | 報告ありの場合は必須（**発見から報告までの時間を集計する**） |
| 15 | **報告を受けた医師** | 参照 | ― |
| 16 | **医師の指示内容** | 自由記載 | ― |
| 17 | **パスの継続／離脱** | 選択 | **継続／離脱** |
| 18 | **離脱の場合：該当する離脱基準** | 選択 | 各パスの S1〜S11 等 |
| 19 | **離脱の判断者** | 参照 | **医師名** |
| 20 | **離脱後の移行先** | 選択＋自由記載 | 個別診療／他パス（番号）／ICU等／転院 |
| 21 | **転帰** | 選択 | 解決／継続中／悪化／不明 |
| 22 | **記録者** | 参照 | ― |
| 23 | **記録日時** | 日時 | ― |
| 24 | **医療安全部門への報告の要否** | 選択 | 要（報告済／未）／不要 |

### 実装上の要点

1. **各パスの J（電子カルテパス）の「達成判定」欄で「未達」を選択した場合、
   本記録様式へ自動遷移する**運用を想定する。
2. **項目5（発見日時）と項目4（発生日時）を分けて記録する**ことで、
   **観察頻度が妥当かどうか**（G-共通02 の検証）を後から評価できる。
3. **項目14（医師報告日時）を記録する**ことで、
   **報告体制の実効性**を評価できる。
4. 選択肢は各パスの R セクションからマスタとして生成する。

## 3. 集計様式

### 3-1　パス別サマリ（**改訂の要否を判断する基礎**）

| 集計項目 | 算出方法 | 判断の目安 |
|----------|----------|------------|
| **パス適用件数** | 期間内の適用症例数 | 適用が極端に少ないパスは、**適用基準が実態と合っていない**可能性 |
| **完遂率** | パスを離脱せず完了した症例数 ÷ 適用件数 | **完遂率が低い＝適用基準（D・E）が実態と乖離している**可能性 |
| **V0 発生率** | V0 件数 ÷ 適用件数 | **高い＝パスの設定が保守的すぎる**可能性（前倒しを検討） |
| **V1 発生率** | V1 件数 ÷ 適用件数 | 標準対応で解決できている範囲 |
| **V2 発生率** | V2 件数 ÷ 適用件数 | **高い項目は、パスに組み込むべき管理が不足**している可能性 |
| **V3（離脱）率** | V3 件数 ÷ 適用件数 | **高い＝適用基準または除外基準の見直しが必要** |
| **離脱基準別の内訳** | S1〜S11 別の件数 | **特定の離脱基準に集中する場合、その予防・早期発見策を強化** |
| **時期別のバリアンス発生分布** | 時期区分別の件数 | **特定の時期に集中する場合、その時期の観察・管理を強化** |
| **原因分類別の内訳** | 原因分類別の件数 | **「医療者要因」「システム・運用要因」が多い＝手順・教育・仕組みの問題** |

### 3-2　**院内検討事項（V項目）の検証用集計**

各パスの V セクションで「症例データで検証」を選択した項目について、
**バリアンスデータから検証する**ための集計。

| 検証したい項目 | 用いる集計 | 該当パス |
|----------------|------------|----------|
| **観察頻度は妥当か**（G-共通02） | **項目4（発生日時）と項目5（発見日時）の差の分布**。**発見の遅れが大きい事象を特定** | 全パス |
| **安静・圧迫解除の時間は妥当か**（G-共通03） | 穿刺部合併症の発生時期と、当時の安静度・圧迫状況 | 01〜08 |
| **食事開始の条件変更は妥当か**（G-共通04） | 誤嚥・悪心の発生率（変更前後の比較） | 01〜13 |
| **在院日数・入院形態は妥当か**（G-共通05） | 完遂率、退院時の未達項目、退院後の予定外受診 | 01〜08 |
| **離床の「短時間・頻回」原則は運用できているか** | 離床の回数・1回あたり時間の記録と、離床時バリアンスの関係 | 09・10・12・13 |
| **嚥下スクリーニングの実施率** | 「スクリーニング前の経口摂取」バリアンスの件数 | 09〜13 |
| **rt-PA の到着〜投与時間** | 投与開始遅延バリアンスの件数と、時間の分布 | 13 |
| **薬剤有害事象の検出時期** | 検査値異常の検出日と、直前の測定日の差 | 10・14 |

### 3-3　全パス横断の集計

| 集計項目 | 目的 |
|----------|------|
| **原因分類「システム・運用要因」の内容一覧** | **複数パスに共通する運用上の問題**（オーダの仕組み、情報伝達、人員配置）を抽出 |
| **原因分類「医療者要因」の内容一覧** | **教育・手順書の整備が必要な領域**を抽出 |
| **医師報告までの時間の分布** | 報告体制の実効性を評価 |
| **医療安全部門への報告に至った件数** | パスとインシデント報告の関係を把握 |

## 5. バリアンス分析からパス改訂へのサイクル

```
① 日々の記録
   各パスの J（達成判定「未達」）→ 本記録様式に記録
        ↓
② 定期集計（推奨：3か月ごと）
   3-1 パス別サマリ ／ 3-2 V項目の検証用集計 ／ 3-3 横断集計
        ↓
③ 分析（パス委員会）
   ・V2・V3 が集中している時期・項目は何か
   ・原因分類が「医療者要因」「システム・運用要因」の事象は何か
   ・各パスの V セクション（院内検討事項）の検証データは揃ったか
        ↓
④ 判断
   ・パスの内容を変更する（観察項目・頻度・条件・時期）
   ・適用基準／除外基準を変更する
   ・手順書・教育・仕組みを変更する（パスは変えない）
   ・エビデンス不足項目について「継続／削除／さらに検証」を決議する
        ↓
⑤ 改訂と周知
   各パスの W（既存パスとの比較欄）に改訂内容と根拠を記載
        ↓
   ①へ戻る
```

### 改訂を検討すべきサイン

| サイン | 示唆されること | 対応の方向 |
|--------|----------------|------------|
| **V3（離脱）率が高い** | 適用基準・除外基準が実態と乖離 | **D・E の見直し** |
| **V0 が多い** | 設定が保守的すぎる | 時期・条件の前倒しを検討 |
| **特定の時期に V2 が集中** | その時期の管理が不足 | 観察項目・頻度・介入の追加 |
| **同じバリアンスが繰り返される** | 標準対応が有効でない | 対応方法の見直し |
| **「システム・運用要因」が多い** | 仕組みの問題 | **パスではなく手順・オーダ・人員配置を変更** |
| **「医療者要因」が多い** | 教育・周知の不足 | **教育計画・チェックリストの整備** |
| **発生日時と発見日時の差が大きい** | **観察頻度が不足** | **G-共通02 の見直し** |
| **バリアンス記録がほとんどない** | **記録されていない**（発生していないとは限らない） | **記録の運用・負担を見直す** |

> **⚠ 最後の項目に注意する。**
> **「バリアンスが記録されていない」ことは「バリアンスが発生していない」ことを意味しない。**
> 記録の負担が大きい、記録の意義が共有されていない、といった理由で
> 記録されないことがある。**記録件数が極端に少ないパスは、まず記録運用を点検する。**

## 6. 記録の負担を減らすための設計上の配慮

| 配慮 | 内容 |
|------|------|
| **選択式を基本とする** | 各パスの R に列挙した事象を選択肢としてマスタ化し、自由記載を最小限にする |
| **達成判定からの自動遷移** | J の「未達」選択で記録画面へ遷移し、時期区分・中間アウトカムを自動入力 |
| **V0 の記録も簡便に** | 正のバリアンスは記録が漏れやすい。**選択のみで完了できるようにする** |
| **既存記録の再利用** | バイタル・検査値・投与記録は既存データから自動参照する |
| **報告と記録を二重にしない** | 医療安全部門への報告が必要な事象は、**同じ入力から報告様式を生成**できるようにする |

## 8. 運用開始時の留意事項

1. **最初の3か月は「記録すること」を目標とする。**
   分析は件数が集まってから行う。
2. **V3（離脱）は必ず全件記録する。** 患者影響が最も大きい。
3. **V0（正のバリアンス）の記録を軽視しない。**
   パスが保守的すぎるかどうかは V0 でしか分からない。
4. **「バリアンス＝ミス」ではないことを、運用開始前に全スタッフへ周知する。**
   バリアンスは **患者の個別性とパスの標準のずれ** を記録するものであり、
   **記録することが評価される文化**をつくることが、この仕組みの前提である。
5. **医療安全部門への報告が必要な事象**（インシデント）とは目的が異なる。
   **重複する事象は、どちらにも記録されるよう運用を設計する。**
