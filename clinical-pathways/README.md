# 脳血管障害クリニカルパス 改訂原案（院内検討用）

本ディレクトリは、脳血管外科・脳神経内科／脳卒中領域の **クリニカルパス改訂原案** を
院内検討会（パス委員会・医療安全部門・看護部・薬剤部）での審議に供するために
文書化したものである。

> **本資料の位置づけ（必読）**
>
> - 本資料は **院内検討用のたたき台（原案）** であり、そのまま診療に適用してよい
>   完成版パスではない。各パスは、施設の診療体制・人員・機器・電子カルテ仕様、
>   および **最新の原典（ガイドライン本文・添付文書）との照合** を経て確定すること。
> - 個々の患者への適用可否は、担当医師の医学的判断に優先されない。
>   パスは標準化の道具であり、個別判断を置き換えるものではない。
> - 本資料には **特定個人の診療情報は一切含まれていない**。公開ガイドライン・学会指針・
>   医薬品情報のみを情報源としている。

## 3. 本資料作成時の制約（重要・院内で必ず補完すること）

本資料の作成環境は **外部ネットワークが制限されており、学会公式PDF（日本脳卒中学会
`jsts.gr.jp`、日本脳神経血管内治療学会 `jsnet.website`、日本神経学会 `neurology-jp.org`）、
PMDA医薬品情報（`info.pmda.go.jp`）、J-STAGE本文への直接アクセスができなかった**。

そのため本資料では、

1. **出典の特定（文献名・版・発行年・発行学会）は行ったが、本文の逐語照合は行えていない**
   項目が大半を占める。
2. すべてのエビデンス項目に **原典照合状況（◎／○／△／×）** を付し、
   院内で原典に当たるべき項目を明示している（`00-エビデンス一覧.md`）。
3. **数値（投与量・投与時間・血圧閾値・観察頻度）を推測で補完していない。**
   出典で確認できない数値は空欄とし、`【要・原典照合】` または
   `【エビデンス不足・院内検討事項】` と明記した。

> **院内での必須作業**：パス確定前に、`00-エビデンス一覧.md` の照合状況が
> ◎ 以外の全項目について、原典（ガイドライン本文の該当CQ、最新の電子添文）を
> 参照し、記載内容・推奨度・エビデンスレベル・数値を確定すること。
> 特に **薬剤の用法用量・禁忌・血圧閾値** は、確定時点の最新電子添文を正とする。

## 4. 主要な指摘事項（検討会で優先審議を推奨）

本作業の過程で、**医学的整合性に関わる指摘**が1件抽出された。

> ### ⚠ 「脳梗塞・エダラボン経口薬」パス（No.11）の適応整合性
>
> 本邦で承認されているエダラボンの **経口剤（ラジカット®内用懸濁液2.1%）の効能・効果は
> 「筋萎縮性側索硬化症（ALS）における機能障害の進行抑制」のみ**であり、
> **脳梗塞急性期の適応は有していない**。
> 脳梗塞急性期に適応を有するのは **注射剤（ラジカット®注30mg／点滴静注バッグ30mg）** である。
>
> したがって「脳梗塞・エダラボン経口薬」という名称の院内パスは、
> (a) パス名称の誤り（実際は注射剤を運用している）、
> (b) 対象疾患の誤り（実際はALSパスである）、
> (c) 適応外使用、
> のいずれかである可能性が高い。**No.11 で3つの可能性を切り分ける検証手順を提示**し、
> (b) の場合の受け皿として **No.14（ALS・エダラボン）を新設**した。
>
> 詳細と根拠は [`11-脳梗塞_エダラボン経口_現行パス検証.md`](11-脳梗塞_エダラボン経口_現行パス検証.md) を参照。

## 5. 検討会での使い方（推奨手順）

1. `00-共通設計方針.md` で記号・バリアンス分類の共通了解を取る。
2. `00-エビデンス一覧.md` の **原典照合作業を分担**（医師＝ガイドライン、薬剤師＝電子添文）。
3. パスごとに **W（既存パスとの比較欄）** に現行院内パスを転記し、差分を可視化する。
4. **V（院内検討事項）** に列挙された「エビデンス不在項目」について、
   `継続 / 削除 / 症例データで検証` のいずれかを決議する。
5. 決議結果を反映して確定版を作成し、電子カルテへ実装する。
6. 運用開始後は `90-バリアンス管理表.md` でバリアンスを集計し、次期改訂に反映する。

## 6. この文書と NurseTube 本体の関係

本ディレクトリは **医療者向けの臨床文書** であり、リポジトリ本体（NurseTube）の
学習コンテンツとは目的・読者・文体が異なる。
`CLAUDE.md` に定める「ずんだもん口調（〜なのだ）」は NurseTube の番組コンテンツ
（`data.js` / `scenes.js`）に適用される規約であり、**本ディレクトリの臨床文書には
適用していない**（院内検討・電子カルテ実装用のため、通常の医学文書体で記述）。

アプリ本体のコード（`app.js` 等）には一切変更を加えていない。
