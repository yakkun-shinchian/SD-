# CoeFont 台本と音声取り込み

PR #28 の head `c1d631da026e68eff79312922049a4ad223abe6b` を基準に、29番組・118シーンを追加出力します。画面・字幕・ブラウザ音声合成の原文は引き続き `scenes.js`。既存VOICEVOX処理には変更を加えません。

## 台本生成

```bash
node tools/build-coefont.mjs
node --test tools/coefont.test.mjs
```

- `narration.txt`: 1行1シーン、118行。PROGRAMS順→シーン順。行をまとめた音声を自動分割する機能ではありません。
- `scripts/001_anat01-1.txt` 等: 1シーンずつ貼り付ける本文のみのテキスト。
- `manifest.json` / `manifest.csv`: seq、従来の音声キー、表示原文、音声本文、原文ハッシュ、希望話者・速度。
- `review.csv`: 読みの採用箇所、原語、読み、前後の文脈、AI文字校正・人による確認・実音声試聴の独立した欄。Excel用UTF-8 BOM付き。
- `text-review.json`: 118シーンの校正記録（原文・かな本文のハッシュ、校正者、日付、個別所見、試聴項目）。生成物ではなくレビューの根拠として保存します。
- `scene-review.csv`: 原文とかな全文を並べた118行の校正表。詳細は [校正報告](TEXT_REVIEW_2026-11-03.md)。
- `readings.tsv`: 医学用語・略語・数値と単位・助数詞・文脈読みの明示辞書。長い一致を優先します。片仮名のみ機械的にひらがな化します。

単独の「尿」は利用者指定の「にょ」。原尿・尿細管・利尿薬・糖尿病・尿量などは標準的な複合語の読みです。音声だけの指定であり、字幕は「尿」のままです。読みはAIが原文と照合していますが、後藤さんの実音声の試聴は未実施。今回の人による確認欄は未確認、実音声欄は未試聴です。AIの校正で人の承認や試聴済みに変更しません。医学的内容の再監修を完了したという意味ではありません。

未登録の漢字・数字・英字・記号は生成エラーにします。`source-lock.json` は原文ごとのSHA-256と順序の固定です。原文やシーン構造が変わると生成を停止します。更新時は変更箇所と数値・単位を確認し、辞書と回帰テストを更新してから、`sourceRows().map(r => [r.key, sha(r.display_text)])` の結果でロックを更新してください。単にロックだけを更新して確認を省略しないでください。

review.csv と scene-review.csv は生成物です。恒久的な読みの修正は辞書へ反映します。実際に人が確認・試聴した場合は、その事実と確認者を text-review.json に記録してください。AI文字校正の再実施では、全文を照合してから該当行の原文・かな本文ハッシュ、日付、所見を更新します。ハッシュだけの更新で確認を省略しないでください。原文またはかな本文が記録と不一致、あるいは記録が欠落したシーンは「要再校正」と表示し、以前の確認済み状態を引き継ぎません。

辞書への複合語追加で分割方法だけが変わり、かな本文が同一なら既存音声のハッシュは有効です。かな本文が変わった場合は対応する音声を作り直してください。レビュー状態は音声取り込みを新たに禁止する条件ではありません。取り込み時の原文・かなハッシュ検査は従来どおりです。

## 後藤さんの音声を取り込む

CoeFontへの直接接続は今回の環境では利用できません。台本をCoeFontに貼り付け、後藤さんの声を選び、**シーンごと**に音声を書き出してください。話者ラベルは自己申告の記録であり、声の本人性をプログラムが判定する機能はありません。

1. `import-template.json` を `import.json` にコピー。
2. 各 `file` を実際の音声パスに変更（import.jsonの場所からの相対パス、または絶対パス）。mp3/wav/m4a/ogg対応。
3. 通常速度で生成した音声は `input_speed: 1`。CoeFont側で既に1.3倍速なら `input_speed: 1.3`。ハッシュ・キーを変えないこと。
4. `node tools/import-coefont.mjs coefont/import.json` を実行。Nodeとffmpeg/ffprobeが必要です。

一部だけ取り込む場合は、その行だけを残した対応表にして `--partial` を付けます。標準では118件すべてを要求します。順番やファイル名の自然順から対応を推測しません。キー不明・重複・音声ファイル重複・台本更新後の古い対応表・欠損・破損音声を拒否します。

音声は `atempo=1.3/input_speed` で処理するため、既に1.3倍速なら再加速しません。声の高さを保ち、WAVに書き出します。元ファイルは変更しません。出力時間が期待値と一致するか検証した後、バッチ専用の `audio/coefont-<UUID>/` に保存し、既存の `AUDIO_FILES` にキーで合流します。他シーンの音声を保持します。アプリの再生コード変更は不要です。

全音声の変換が成功するまで `audio/manifest.js` を更新しません。更新は一時ファイルからrenameします。バッチフォルダの `previous-manifest.js` を `audio/manifest.js` に戻せば取り込みを取り消せます。`import-report.json` に入力速度・処理倍率・入力/出力時間を記録します。別ツールとの同時書き込みは避けてください。従来の `link-audio.mjs` を後から実行すると、従来仕様どおりVOICEVOXの対応表に置き換わります。
