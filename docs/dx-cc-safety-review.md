# 主訴別アプローチ：初期対応の安全性点検

点検日：2026-11-02。対象：PR #27、確認した先頭コミット `e3a3406978a0895004d15c27b5d38c53643f9cf3`。
対象は `dx-cc.js` の18主訴（緊急疾患、鑑別注記、問診・診察項目）。処置の適応条件・検査順序・検査を待たない対応に限定し、診断エンジンの医学的全面検証とは区別する。

## 主要な修正

- 緊張性気胸を疑い、循環不安定または重度呼吸障害を伴う場合の画像前減圧と、安定例の画像評価を区別。熟練した医療者による減圧とし、特定の穿刺手技を全例に指示しない。NICE NG39は外傷の指針であり、その対象範囲も出典に明記した。
- 髄膜炎はCTを一律に先行させない。占拠性病変リスク、局在神経徴候、瞳孔異常、GCS≦9、進行性・持続性／急速な意識低下を画像先行の条件として記載。腰椎穿刺の禁忌・安定化条件を別途列挙し、正常CTだけで安全としない。
- 安全に実施でき治療を有意に遅らせなければ抗菌薬前に腰椎穿刺。遅延・危険があれば抗菌薬と全身安定化を画像より先に行い、安全になり次第穿刺。デキサメタゾンの準備も抗菌薬を遅らせない。
- 同じ条件を発熱・頭痛・意識障害・痙攣の各カードで共有。これらは**説明文の条件分岐**であり、アプリが患者ごとの処置適応を自動判定する機能ではない。

## 根拠

詳細な書誌・URLは `dx-refs.js` の各IDと画面の出典欄に収録。

- [NICE NG240](https://www.nice.org.uk/guidance/ng240/chapter/Recommendations)：1.4.6–1.4.13、1.6、1.9。腰椎穿刺前の画像適応、禁忌、抗菌薬の遅延防止。
- [NICE NG39](https://www.nice.org.uk/guidance/ng39/chapter/Recommendations)：1.4.1–1.4.2。画像前の胸腔減圧の条件（外傷）。[BTS pleural disease](https://www.brit-thoracic.org.uk/clinical-resources/guidelines/pleural-disease/) は関連資料の入口であり、この緊急減圧条件の直接根拠はNG39を使用。
- [SSC 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8486643/)：ショック・高い感染可能性と、ショックのない疑い例を分ける。
- [IDSA脳炎](https://academic.oup.com/cid/article/47/3/303/313455)：推奨21、検査結果待ちでアシクロビルを遅らせない。
- [IDSA軟部組織感染](https://www.idsociety.org/practice-guideline/skin-and-soft-tissue-infections/)：VIII、画像で外科治療を遅らせない。
- [TG18初期管理](https://doi.org/10.1002/jhbp.509)、[成人DKA 2024](https://doi.org/10.2337/dci24-0032)、[NICE NG234](https://www.nice.org.uk/guidance/ng234/chapter/recommendations)：それぞれ重症度、K、神経症状に基づく処置条件。

薬剤の国内適応や自施設手順をこのアプリが置き換えるものではない。新しい投与量・減圧手技のプロトコルは追加していない（DKAのK閾値は2024成人コンセンサスを明記）。
