# 臨床スコアの未回答対策（2026-11-01）

PR #23 の 27baa3389ab7d95887e91ecd9fb81bfc5dab08e1 を基準に修正。

- 選択式21スコアは全項目の有効回答が揃うまでリスク区分を算出しない。
- 未入力は「未評価／—」、部分入力は「暫定評価／入力済み分の点数」、完全入力は従来の判定。API の未完成 score は null。
- 不足項目を表示。boolean は未評価・該当なし・該当ありの3択。false を明示した0点を有効回答として扱う。
- 無効な選択肢、空白、非有限値を回答数に含めない。
- ISTH DIC は4要素、MELD-Na はNaを含む4検査値が必要。未充足は null を返し画面に未評価と表示。
- CKD は蛋白尿区分を入力する機能がないため、eGFRが計算できても「暫定評価：GFR区分のみ」。重症度全体の確定とはしない。
- 複合条件で未測定を正常と補完する自動入力を制限。SOFAの尿量・呼吸補助情報は手動確認が必要。自動入力のみのカードは元データ変更時に再計算。
- 加算・減算・最大値方式の計算式、完全入力時の閾値、TTP/HUS判定は維持。
- 既存カードとCSSを維持。チェックボックスのみ既存の選択欄形式へ変更。
