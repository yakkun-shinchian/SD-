# 未測定項目の正常誤認修正（PR #23）

対象先頭: 6782b51fbaf9a0a32b1f1e8b2fd12da1548f8091

## 判定変更

- PT（INR・秒・活性）とフィブリノゲンを基準範囲内／外／未測定の3状態で評価。複数PT指標の不一致は異常を優先。空白・非数値は未測定扱い。
- 貧血＋血小板減少＋LD高値はTMA／DIC等の緊急鑑別警告を残す。正常と断定せず測定状況を表示し、未測定項目の確認を促す。凝固異常でもTMA合併を除外しない。
- 薬剤性ループス、MCTD、橋本病、RF関連判定、陰性スクリーニングでは測定済みの陰性根拠を要求。ANA 40倍を陰性スクリーニングと呼ばない。
- ACDの網赤血球非増加は測定を必須化。
- BUN優位上昇、肝酵素上昇、著明な高血糖、フィブリノゲン高値は陽性所見の警告を残し、未測定の他項目を正常と説明しない。AG未評価でHHSに絞らずDKA・混合病態の確認を促す。
- PTのみ／APTTのみ延長の対側「正常」は基準範囲内を明示的に確認。
- 残る好中球減少・血小板減少・ワルファリンINRの否定条件は、同じ測定値での重症度の分岐であり未測定正常の誤認ではない。ACDのRDWは既に測定ガードあり。自己抗体の定性陰性は明示値を使用。

## 医学的根拠と限界

ISTH Good practice statements, statements 1–3: 血小板減少と微小血管症性溶血性貧血でTTPを疑う。凝固検査は通常比較的正常だが重症例・DIC合併で異常となりうる。疑いが強ければ緊急対応を要する。
https://pmc.ncbi.nlm.nih.gov/articles/PMC7880820/

2025 focused update（支持療法の該当記載継続）:
https://doi.org/10.1016/j.jtha.2025.06.002

Hb・血小板・LDの3値のみでは溶血やTMAを確定できない。今回の赤判定は診断ではなく緊急鑑別の促し。PTの施設基準・抗凝固薬の影響、実際の検査結果と臨床経過を合わせた専門家レビューが必要。
