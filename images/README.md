# 写真・断層画像（CT / MRI）を入れるフォルダ 🩻

このフォルダに画像を置いて `images/manifest.js` に登録すると、その番組のシーンで
**図解（SVG）の代わりに実際の写真**が表示されます（CT・MRI・X線・臨床写真など）。

## 入れかた（3ステップ）

1. 画像を `images/` に置きます。ファイル名は **「番組ID-シーン番号.拡張子」** が分かりやすいです。
   - 例：脳梗塞(`dis03`)の1枚目 → `images/dis03-1.jpg`
   - 対応形式：jpg / png / webp / gif など、ブラウザで表示できる画像。
2. `images/manifest.js` の `IMAGES` に登録します：

   ```js
   const IMAGES = {
     "dis03-1": "images/dis03-1.jpg",
     // 出典を表示したいときはオブジェクトで:
     "dis03-3": {
       src: "images/dis03-3.jpg",
       alt: "頭部MRI DWI 急性期梗塞",
       credit: "Case courtesy of ◯◯, Radiopaedia.org (CC BY-NC-SA)"
     },
   };
   ```
3. ブラウザでアプリを開くと、そのシーンで写真が表示されます（`credit` は画像の隅に小さく表示されます）。

## どのシーンに割り当てる？

「番組ID-シーン番号」は `voicevox/manifest.csv` の `key` 列と同じです。
たとえば脳梗塞の番組(`dis03`)はシーンが4つあるので、`dis03-1`〜`dis03-4` に画像を割り当てられます。

> 初期状態では、`dis03`(CT/MRI) や `dis04`(胸部CT) などに **学習用のCT/MRI風の図解(SVG)** が入っています。
> 実際の写真を登録すると、その図解が写真に置き換わります。

## ⚠️ 画像の権利について（とても重要です）

CT・MRIなどの画像には**著作権・症例の権利**があります。次のいずれかを使ってください：

- **自分で権利を持つ画像**（自施設の教材として許可を得たもの、個人情報を削除したもの）
- **CC0 / パブリックドメイン**の画像（出典表記が不要なものでも、記載しておくと親切です）
- **CC BY などライセンスが明確な画像**（**必ず出典・ライセンスを `credit` に明記**してください）

代表的な入手先の例：
- Wikimedia Commons（ライセンス表記を要確認）
- Radiopaedia（多くは CC BY-NC-SA。表示と非営利などの条件あり）

> このアプリには初期状態では**写真は同梱していません**（権利のため）。実画像はご自身で適切なものを用意してください。
> 写真が無くても、CT/MRI風の**図解**で学べるようにしてあります。
