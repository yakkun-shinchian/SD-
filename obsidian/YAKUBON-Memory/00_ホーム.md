# YAKUBON 長期記憶（Obsidian Vault）

Claude と一緒に育ててきたスキルと記憶を、**消さずに・上書きせずに**残しておく場所です。

## まず開くところ
- [[スキル一覧]] … 自作スキル全34本と、いまの版・最終更新日
- [[欠番・失われた版]] … 名前は覚えているのに、今は見つからない版（C2・C3・V3・医療動画2/3など）
- [[Claudeへの記憶の使い方]] … Claudeが毎回どう読みに来るかのルール

## しくみ（3つの層）
| 層 | ファイル | 役目 |
|---|---|---|
| 最新版 | `スキル/<名前>/<名前>.md` | いまClaudeが使っている姿。毎回書き直されます |
| 版スナップショット | `スキル/<名前>/履歴/vN_日付.md` | その時点の**原文そのまま**。一度書いたら二度と上書きしません |
| 変更履歴 | `スキル/<名前>/<名前>_変更履歴.md` | どこを足して、どこを消したか（差分）と理由 |

スキルを直したら、次のひとことで記録されます：

```bash
node tools/skill-vault-sync.mjs --note "なぜ変えたか"
```

変更があったスキルだけ v2, v3… と版が積み上がり、「変更前」「変更後」「差分」が並びます。

## この Vault を Obsidian で開くには
1. GitHub のこのリポジトリをPCにクローン（または GitHub Desktop で取得）
2. Obsidian →「フォルダを保管庫として開く」→ `obsidian/YAKUBON-Memory` を選ぶ
3. 自動で最新にしたいときは、Obsidian のコミュニティプラグイン **Obsidian Git** を入れて「起動時に pull」をオンに
