# Claudeへの記憶の使い方

この Vault は Claude の**長期記憶**です。毎回ぜんぶ読む必要はありません。図書館のように「索引→必要な棚だけ」読みます。

## 読むとき
1. 会話の最初に [[00_ホーム]] と [[スキル一覧]] だけ読む（軽い索引）
2. 依頼に関係するスキルが分かったら、その `スキル/<名前>/<名前>.md`（最新版）を読む
3. 「前はどうだった？」「元に戻して」と言われたら、`<名前>_変更履歴.md` と `履歴/` の版を読む

## 書くとき
- スキルを直したら、必ず `node tools/skill-vault-sync.mjs --note "理由"` を実行して版を残す
- 版スナップショット（`履歴/`）は**絶対に書き換えない・消さない**
- 学んだこと・決めたことは `記憶/` フォルダに日付つきノートで残す（例：`記憶/2026-11-28_スキル保管庫を作った.md`）

## 元に戻したいとき
「C1 を v2 に戻して」と言えば、Claude は `履歴/v2_*.md` の本文をそのままスキルに貼り直し、その戻した事実も新しい版（v4 など）として記録します。歴史は前にしか進みません。
