# 動画CTスキル（CT・MRI 断面図 → 縦型教育動画）

## 2026-11-08 の方針変更（最優先・旧ルールより上）
伸作さんから以前の型をやめるよう指示がありました。古い動画やお手本（白黒とカラーを上下に並べた胸部CT動画など）に引っ張られないこと。

1. **白黒とカラーを並べない**。上下に並べる・重ねて線でつなぐ型は廃止。
2. **CTは基本白黒**。見やすければカラーだけでもよいし、白黒だけでもよい。どちらか一方で見せる。
3. **CT・MRIのイラスト（画像）を動かさない**。アップ・ズーム・パン・「少し引く→少しアップ」・ゆらし・AI動画化・フロー変形、すべてなし。画像は静かに置き、変化は「次の断面への切り替え」と「ラベル・カードの出し入れ」で作る。
4. **本物のCTのように連続でズラズラ流す動画（スライススクロール）は、作る前に必ず伸作さんに相談する**。枚数・速さ・範囲・前後の構成を確認してから作る。勝手に入れない。

## 守ること
- ラベルは大きく（1080幅で34px以上）、黒い余白に置き、線で引き出す。構造の上に直接文字を書かない。
- 引き出し線とラベル文字の色は、指している構造の色と必ずそろえる。
- テロップは太字の明朝体（エメラルドグリーン。白を使うときも太字明朝）。大きく太く。
- 頼まれていないBGMは入れない（音はInstagram側で乗せる）。カチカチ音もなし。
- テンポは速く、全体で約25〜50秒。引き出し線は1本ずつでなく一斉にパッと出す。
- 基本は文字なしで映像を作り、テロップとナレーション（CoeFont）は後から入れる。
- 臨床の中身は正確に。書いた要点は最後に伸作さんへ確認をお願いする。

## 素材
- **各高さの断面図**：同じ構図・同じ位置でそろえたもの。6〜10枚。小さなラベルが焼き込まれていれば消す（下記）。
- **白黒**：本物の白黒CT/MRIがあればそれを使う。なければ色分けから作る（下記 `ct_gray`）。
- **スカウト用の全身/頭部画像**：半透明の人体1枚（使う場合）。断面ラインが焼き込まれていれば消す。

## 構成（縦 1080×1920・30fps・約25〜50秒）
| 区間 | 中身 |
|---|---|
| フック | 「この白黒CT、どこを切ったか言える？」などの問い。画像は静止のまま |
| 各断面 | 白黒（またはカラーのみ）の断面1枚＋引き出し線ラベル＋カード |
| 断面の切り替え | カット、または短いクロスフェード。画像自体は動かさない |
| まとめ | 断面の一覧と「保存して、実習前・国試前にもう一回！」 |

連続スクロールを入れたい場合 → 上の4に従い、まず相談。

## 本編レイアウト（1080×1920の座標・目安）
- ヘッダ y16〜120：「頭部CT **横断像** の見かた」（56px、太字明朝）
- 左上スカウト (28,136)-(318,436)：切る高さの線を引いた静止の人体（使う場合）
- 右上情報 (334,136)-(1052,436)：丸数字＋レベル名（46px）、構造名（26px）、POINT＋2行（34px）。先輩Qのときは「先輩に聞かれたら？」→「シン先輩」の質問→1.2秒後に「答え」
- 断面パネル (28,452)-(1052,1400)前後：断面1枚を大きく。PACS風HUD（`Im: 045/100`・`Z: +54.4 mm`・`W:80 L:40`、MRIは `T2 AXIAL`、R/L）
- 病気カード (28,1592)-(1052,1904)：「病気のとき」札＋病名（44px）、▶3行（32px）、「国試」箱1行

## 引き出し線のルール
- ラベルは左右の黒い余白の列に置く。札は角丸・濃紺の塗り・構造色の枠・左に色の丸・文字34px。
- 線は直角に引き、構造の点に「黒縁＋色＋白芯」のドットを打つ。
- 同じ側の札は縦に74px以上あける。線どうしが重ならないよう、アンカーのxを15px以上ずらす。
- 出し方：一斉にパッと出す。消すときは0.22秒でフェード。

## コードの要点（Python + PIL、フレームごとに描いて ffmpeg へパイプ）
```python
# 色分け → CTらしい白黒（骨は白、髄液は暗く、ノイズ少し）
def ct_gray(rgb, seed=0, noise=6):
    a = np.asarray(rgb).astype(np.float32)
    g = 0.30*a[...,0] + 0.59*a[...,1] + 0.11*a[...,2]
    g = np.clip((g-40)*1.25, 0, 255); g = 255*(g/255)**1.15
    g += np.random.default_rng(seed).normal(0, noise, g.shape)
    return Image.fromarray(np.clip(g,0,255).astype(np.uint8)).convert("RGB")
```
- 焼き込みラベルの消し方：①Nano Banana 2 の編集で「小さなラベル・線・点だけ消す」を作る（2K・24クレジット/枚）。②元画像とその差分のうち、ラベル箱と線の周りだけを元画像に合成して戻す（それ以外の解剖は元のまま）。③残った色の線は色相マスク＋inpaintで消す。
- PACS風HUD：等幅フォント（DejaVu Sans Mono）、四隅に `HEAD CT AXIAL`・`Se: 2 Im: 045/100`・`Z: ±mm`・`W:80 / L:40`・`Thk 1.0 mm`・`教育用イメージ`、A/P/R/L。
- 確認：静止画を数枚書き出して（`STILLS=t1,t2,...`）レイアウト・ラベル位置を目で見てから全編を書き出す。

## 各高さの中身（骨盤動画の型）
- **POINT**：その高さで何が見えるか（2行、1行17字前後）
- **病気のとき**：病名＋▶3行（CTでどう写る／症状／看護で気をつけること）
- **国試**：1行で言い切る（例「pinpoint pupil ＝ 橋出血」「三日月形＝硬膜下血腫／凸レンズ形＝硬膜外血腫」）
- **先輩に聞かれたら？（シン先輩）**：全体の3〜4か所。臨床でそのまま聞かれる質問と、1行の答え
- まとめ一覧：「① レベル名 — 病気・キーワード」

頭部CT10枚での内容例：頭頂部・中心溝（ACA梗塞・錐体交叉）／半卵円中心（慢性硬膜下血腫）／側脳室体部・放線冠（ラクナ梗塞・DWI）／側脳室前角（水頭症・iNPHの3徴）／基底核・内包（被殻出血・共同偏視）／第三脳室・四丘体槽（視床出血・脳槽の消失）／中脳・鞍上槽（SAH・攣縮4〜14日目）／橋上部・トルコ鞍（橋出血・両耳側半盲）／橋・蝶形骨洞（小脳出血・急性水頭症）／眼窩・副鼻腔・延髄（ワレンベルグ・大孔ヘルニア）。

## 他の部位・MRIへの置きかえ
- 胸部・腹部・骨盤：スカウトを半透明の体幹（または骨盤）に替える。ヘッダは「胸部CT 横断像の見かた」など。
- MRI：HUDを `T2 AXIAL` などに。T1/T2で水が黒/白になる点をPOINTかTIPSに入れる。

## 仕上げチェック
- [ ] 白黒とカラーを並べていない（どちらか一方だけ）
- [ ] CT・MRI画像にズーム・パン・動きを付けていない
- [ ] 連続スクロールを入れるなら、事前に伸作さんと相談済み
- [ ] ラベル34px以上、引き出し線とラベルの色が構造の色と一致、線どうしが重なっていない
- [ ] BGM・カチカチ音なし、全体25〜50秒
- [ ] 病気カード・国試・先輩Qの内容を伸作さんに確認してもらった
