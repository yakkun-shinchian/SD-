# 医療透明動画 イラスト台本（チャッピー用）

このスキルの名前は「医療透明動画」。チャッピー（ChatGPT）にイラストを描いてもらうための、医療透明動画のスキル。「医療動画1」とは呼ばない（2026-11-14 本人指示で改名）。

## チャッピーに使わせるスキルは「医療動画2」（2026-11-25 本人指示）
- これからは全部、チャッピーへの指示の1行目に「ChatGPTの『医療動画2』スキルを使って描いてください。」と書く。
- 新しい台本・描き直し・1枚だけの追加・参照画像つきの依頼など、チャッピーに出す指示はすべて同じ。
- 以前の「ChatGPTの『医療透明動画』スキルを使って描いてください。」は使わない。昔の台本を出し直すときも、1行目を『医療動画2』に差し替えてから出す。

## 目的
YAKUBON STUDIOの医療解説動画（縦型ショート）のために、まずストーリーを作り、次にチャッピー（ChatGPT）の「医療透明動画」スキルへ渡すイラスト制作台本を書く。チャッピーはイラストを作るだけ。動画化・文字入れ・ナレーションは後工程で行う。

## いちばん大事：「なぜ起きるのか」を動かす（2026-11-18 本人指示）
- 合併症・病気の動画は「○○が起きました」で終わらせない。それなら動画はいらない（例：CABG後に心房細動が起きた、だけでは、もともと心臓が悪い人なのだから当たり前に見える）。
- 芯は「なぜ、その時期・その場面で起きるのか」。引き金（炎症・交感神経・虚血・水分・薬など）を1つずつ、体の中で動くカットにする。
- しくみのカットは2〜4枚。引き金ごとに1枚＋最後に「全部が重なって病気が起きる」1枚。動画の中でいちばん時間を使う。
- ComfyUIで動かすので、絵の中に動く物（火花が飛ぶ・矢が降る・ふくらむ・流れる・渦ができる）を入れる。
- 例（CABG後の心房細動）：①心膜の炎症が心房に火花を飛ばす ②痛み・ストレスで交感神経の光の矢が降りそそぐ ③点滴の水分と手術中の虚血で心房が引き伸ばされ弱る ④3つが重なって心房に電気の渦が生まれる →「だから術後2〜4日目に多い」

## 0. まずストーリーを作る（台本より先）
- **最初に yakubon-procedure-motion-first を読む。** ストーリーの主役は、体の中（臓器・血管・気道・消化管）で処置が行われてダイナミックに動くところ、器具（気管支鏡・カテーテル・鉗子など）が動くところ、手術で術者の手が動くところ。人が出てくるのは最初と最後だけ（2026-11-17 本人指示）。
- 台本の前に、かならずストーリーを作って本人に見せる。
- ねらいは「感動」と「わかりやすさ」の両方。看護学生が1回見て分かることを基準にする。
- 型：①つかみ（3秒で驚かせる。体の中のヒーロー） ②何が起きたか（人を出すならここ1カットだけ） ③からだの中で起きていること（しくみ・病変を動きで） ④処置の工程（いちばん長く。器具・体の中・術者の手が動くカットを工程順に並べる） ⑤看護の目（観察・注意は、処置カットのテロップで言う。看護師のカットを増やさない） ⑥締め（処置の結果のカット、または回復した患者さん1カット＋一行の言葉）。
- 真ん中（②〜⑤）に、看護師が見守る・気づく・振り向く、患者さんが横になっている、モニターの光や数値が変わる、といったカットは入れない。状態の変化はテロップ1行で済ませる。
- 物語の軸を一行で決める（例：「首も胸も刺さずに、腕から心臓のそばまで届く一本の道」）。
- 場面ごとに「どの道具で作るか」の目安を添える：Blender（血管の中を進む、流れの比べっこ、カテーテルが伸びる、3Dの回り込み）／Kling（人が動く感動の場面・冒頭のヒーロー）／ComfyUI（それ以外のイラストの動画化）／HyperFrames＋IRIS（テロップ・切り替え・締め）。
- Blenderで作る場面はチャッピーの台本から外し、Blender用の指示として別に書く。

## むずかしい話は、かならずかみくだく（分子・細胞レベル）
- 基準は「高校生物の教科書に出てこない言葉・レベル」。分子、受容体、イオンチャネル、浸透圧、酵素、サイトカイン、遺伝子発現、膜電位などがこれにあたる。医学生でもむずかしい、と考える。
- 書く前に、その話が看護に本当に必要かを考える。要らなければ外す。
- 使うときは、同じ場面で必ず次の3つをそろえる。
  1. ひとことの言い換え（例：浸透圧＝水を引っぱる力、受容体＝薬がはまる鍵穴）
  2. 身近なたとえ（例：濃い薬を細い血管に入れる＝細い小川に濃い絵の具を流す）
  3. 絵で見せる（形・光・動きで、言葉なしでも分かるように）
- 1本の動画でむずかしい言葉は2〜3個まで。
- テロップは言い換えをメインに、専門用語は補足（小さい文字）に回す。専門用語だけのテロップは出さない。
- 略語（PICC、CRBSIなど）は、初めて出す場面で日本語の意味を添える。
- ナレーション原稿にも同じルールを使う。

## 絶対ルール
1. 時間振り（秒数・尺・タイムコード）はチャッピーの台本に書かない（ストーリーの目安時間は本人向けなのでよい）。
2. 画面内の文字は一切禁止。日本語・英語・数字・記号・矢印・ラベル・引き出し線・吹き出し・ロゴ・メーカー名・機械の銘板・モニター画面の文字やUI・名札の文字まで含めて描かせない。モニターは抽象的な光の図形だけ、名札は無地。台本冒頭の共通ルールと、文字が入りやすいカット（モニター、機械、書類、看板、カレンダーなど）の指示の中の両方に明記する。
3. チャッピーに動画を作らせない。冒頭に「イラストだけを作る。動画は作らない。動画化はこちらで行う」と書く。動画用プロンプトも書かせない。
4. 1枚生成するごとに文字の混入を自己チェックさせ、入っていたら作り直させる。
5. 文字で説明したい内容（回数・数値・病名）は絵の中に書かせない。絵は形と光で語り、言葉は台本の外の「テロップ素材」に回す。

## 絵柄
- 縦長9:16、高精細。
- **色の指示はしない**（背景色・臓器の色・光の色・質感も書かない）。心臓が青でなくてよい。絵柄はチャッピーに任せる（2026-11-18 本人指示）。背景を黒くそろえるのは、動画にするときの黒締めでこちらが行う。
- 人物のカットの背景色も台本には書かない（色の指示はしない）。
- 人物はアニメ寄りの「可愛い」ではなく「美しい絵」（AVM動画ラストの、ナイダスを両手で包む女の子が手本）。ただし**写真・実写風にはしない**。台本に「やわらかい日本のアニメ調イラスト（きれいな線画・やわらかい陰影）。写真風・リアルな肌の質感・欧米人風の顔にしない。日本人の女性」と必ず書く。
- **お手本画像を必ず添付する**：`C:\YAKUBON_STUDIO\characters\nurse_v1\approved_20261107_1to3\keyvisual.png` をチャッピーに貼り、「この女の子と同じ顔・髪型・服・画風で」と書く（チャッピー側で「医療透明動画」スキルが一覧にないと返されることがあり、そのときは文字の説明だけで描かれて実写の白人風になった。2026-11-10）。
- 生成後、女の子のカットはお手本と並べて顔・画風を目で確認する。リアル寄りになっていたら、PCの Qwen-Image-Edit-2511（画像1＝その絵、画像2＝keyvisual.png）でお手本のイラストに描き直す。
- ガイド役の女の子は、お手本画像を貼って「この子と同じ顔・画風で」と1行書くだけ。髪や服の色を文字で並べない。全カット同一人物。
- 登場人物は1カット原則1人。スタッフが必要な場面は手だけ（青い手袋）。
- 実在メーカーのロゴや特定製品そっくりのデザインは避け、汎用の機械として描く。

## 構成の型（台本）
1. ヒーローカット：病変や装置を3Dで立体的に見せる。回り込みに使えるよう別アングル（斜め前・斜め後ろなど）で2枚。Blenderで作る場合は台本から外す。ヒーローはSeedance 2.0 Miniで作り、始点・終点の2枚指定はできないので、1枚目（斜め前）がそのまま始点になる。1枚目をいちばん見せたい構図にする。
2. 何が起きたか：人を出すならここ1カットだけ（患者さんの症状など）。
3. しくみ（いちばん大事）：「なぜ起きるのか」を2〜4枚。引き金ごとに1枚、最後に全部が重なって病気が起きる1枚。全枚で同じ臓器・同じ向き・同じ大きさにし、起きていることだけを変える。動く物を入れる（むずかしい話はかみくだきルールに従う）。
4. 処置の工程（全体のいちばん多くの枚数をここに使う）：体の中・器具・術者の手（青い手袋）が動く場面を、工程の順番どおりに1工程＝1枚で。全枚で同じ構図・同じ臓器の形・同じカメラ位置にし、器具と体の中の状態だけを変える。
5. 変化の前後があるカットは「始点／終点」の2枚組（同じ構図・同じ画角・同じ人物で、変化させる部分だけ変える）。Seedance 2.5の始点・終点用。
6. 看護の視点：観察ポイントは処置カットのテロップで言う。看護師のカットは、看護の手技そのもの（体位を変えるなど）が話の主役のときだけ1枚。
7. ラスト：処置の結果のカット（止血・空気が流れる・網が密着など）か、回復した患者さん1カット。人が出てくるのは最初と最後だけ。
- 全体でおおむね15〜22枚。冒頭3枚で「すごい」と思わせる。

## 出力形式
1. 先にストーリー（軸の一行＋場面ごとの流れ＋道具の目安）を本人に見せる。
2. チャッピーにそのまま貼れる1つのコードブロック：①タイトル行（【医療透明動画】テーマ名）※【医療動画1】とは書かない　②タイトルのすぐ下の1行目に、毎回かならず「ChatGPTの『医療動画2』スキルを使って描いてください。」と書く（2026-11-18 本人指示、2026-11-25 に『医療動画2』へ変更。書かないとスキルを使わずに描かれることがある） ②役割と共通ルール ③カット一覧（カット番号｜ねらい（画面に出さない）｜絵の指示）。絵の指示は日本語で、何がどう見えるか（向き・構図・起きていること）だけを1〜3行で。色・背景色・質感・光の色は書かない。共通ルールは5行以内（イラストだけ・動画は作らない／縦長9:16／文字・数字・記号・矢印なし／同じカット群は同じ向き・同じ大きさ／人を出すかどうか）。長い前提条件は書かない。
3. ブロックの外に「あとで乗せる文字の素材」（テロップ用の短い説明文と、根拠となる論文・ガイドライン）を簡潔に添える。これはチャッピーには渡さない。

## 描き直し・追加を頼むとき（2026-11-18 本人指示）
チャッピーは前に描いた絵を覚えていない。参照の絵を貼り直さないと、構図・絵柄・目印（コイルの位置など）がそろわない。だから描き直しや1枚だけの追加を頼むときは、毎回かならず次の3つを出す。
1. **必要な画像の一覧**：「描いてもらうカット」と「まだ届いていないカット」を番号で全部書く。
2. **添付する参照画像**：どのカットを描くときに、どの絵を貼るか（例：10を描く→新しい07を貼る／08・09・15を描く→今の08と01ヒーローを貼る）。参照画像は「参照_番号_何の絵か.png」という名前でチャットに送る（SendUserFile、iPadで保存してそのまま貼れるように）。
3. **チャッピーに貼る指示**：1つのコードブロック。1行目は「ChatGPTの『医療動画2』スキルを使って描いてください。」、2行目に「添付した○○の絵と同じ構図・同じ大きさ・同じカメラ位置・同じ絵柄で」と、どの参照画像を使うかを書く。動画は作らない・文字なしも入れる。
- 同じ舞台のカットで目印がある場合（コイル・病変・細い血管・ドレーンなど）は、指示に「○○は参照の絵と同じ位置・同じ大きさ」と書く。
- 届いた絵は、参照の絵と並べて目印の位置がそろっているかを確かめてから ComfyUI に入れる。

## 仕上げチェック
- 体の中・器具・術者の手が動くカットが全体の8割以上か。人のカットは最初と最後だけか（どうしても必要な真ん中の1枚を足しても3枚まで）。モニターの光・数値だけのカットが0か
- ストーリーに「何が起きたか→からだの中→処置の工程→看護の目→締め」がそろっているか
- 「なぜ起きるのか」を体の中で動かすしくみカットが2枚以上あり、そこにいちばん時間を使っているか
- チャッピーの台本に色の指定がないか。共通ルールが5行以内か
- むずかしい言葉に、言い換え・たとえ・絵の3点がそろっているか。2〜3個以内か
- 専門用語だけのテロップがないか、略語に日本語の意味があるか
- 秒数・尺がチャッピーの台本に入っていないか
- 文字禁止が共通ルールとモニター等のカットの両方にあるか
- 「動画を作らない」が書いてあるか
- 医学的に正確か（解剖、手順、適応）
- 始点／終点が同じ構図の指定になっているか
