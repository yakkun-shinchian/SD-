# 線だけで描く立体細胞モデル

Claudeは画像を描けないが、線は正確に引ける。この性質を使い、点と点を結ぶ1ピクセルの線を数十万〜百万本重ねて、細胞（や他の生物構造）を立体的に組み上げる。完成物は1枚のHTMLアーティファクト。

## 参照実装
- 完成版：https://claude.ai/artifact/JeHTdy45SrWnt2wzeWA3Ly（Artifactツールの action "read" で読み、土台としてコピーして改造するのが一番速い）
- 真核細胞・13器官・約110万線分・生成約0.4秒

## 技術の核
1. **Canvas 2Dは使わない**。10万線分を超えると重い。**WebGL2 の indexed GL_LINES**（Uint32インデックス）で描く。
2. **加算合成**：`gl.blendFunc(gl.SRC_ALPHA, gl.ONE)`、深度テストなし。線が重なるほど光る＝発光した標本の見た目になる。背景はほぼ黒（#06070b）。
3. **頂点属性**：位置 float32×3、色 RGBA8（頂点ごとのグラデーション、Aは器官ごとの基本透明度）、フラグ uint8（器官ID＋32なら「断面で透かす対象」）。
4. **ビルダーAPI**（型付き配列を倍々で拡張）
   - `B(id, {c0, c1, a, cut})` 線の開始、`V(x,y,z,t)` 頂点追加（t=0〜1でc0→c1の色）、`E()` 線の終了
   - t は必ず0〜1にクランプ（Uint8Arrayは範囲外を折り返すため）
   - 補助：`ring`（円）、`wireBall`（直交3円の球）、`tube`（経路に沿う筒＝複数本の縦線＋輪）、`frames`（平行移動フレームで筒がねじれない）
5. **シーダー付き乱数**（mulberry32）で毎回同じ形にする。
6. **頂点シェーダー**：回転行列 uRot、回転中心 uPivot、透視（D=4.6）、器官表示 uVis[n]、断面 uCut（手前 r.z>0 の膜を5%に）、奥行きで暗く、フォーカス時は中心から離れた線を10%に。
7. **明るさの自動補正**：gain = ユーザー値 × (画面上の倍率/700)^0.62。拡大すると線がまばらになるぶん明るくする。

## ビューアの機能（必ず入れる）
- ドラッグ回転、ホイール・ピンチで拡大（カーソル位置を中心に）、右ドラッグ・2本指で移動
- フォーカスボタン：全体／核と染色体／ミトコンドリア／ゴルジ体／中心体／細胞骨格。回転中心を対象に移し、拡大し、周囲を薄くする（1.1秒でなめらかに移動）
- 断面（手前の膜を透かす）、自動回転、明るさスライダー
- 凡例ボタンで器官ごとに表示切替、各器官の線分数を表示
- 読み込み中表示（setTimeoutで生成してから描画）、WebGL2非対応時のメッセージ
- prefers-reduced-motion なら自動回転オフ

## 手順
1. 対象（例：神経細胞、赤血球、心筋細胞、肝小葉）を決め、構造を器官レシピの形に書き出す。
2. 参照実装を読み、ORG配列と build() の中身だけを差し替える。
3. 公開前に build() 部分だけを node で空実行し、頂点数・線分数・エラーを確認する（目安：線分50万〜120万、生成1秒以内）。
4. Artifactとして公開。自分では画面を見られないので、明るさの見え方をユーザーに確認してもらい、各器官の a（透明度）を調整する。

## 他の対象への応用のヒント
- 神経細胞：細胞体＋分岐する樹状突起（再帰的に枝分かれする筒）＋髄鞘の巻き（らせん）＋ランヴィエ絞輪＋シナプス小胞
- 赤血球：両凹円盤を同心輪と放射線で、膜骨格（スペクトリン網）を六角メッシュで
- 心筋細胞：サルコメアの縞（Z線・A帯をそろった平行線）、T管、介在板
