# YAKUBON STUDIO 後輩看護師「美しい絵」キャラ設定

これからの医療動画・イラストでは、女の子（後輩看護師）を**可愛いアニメ調・ちびキャラではなく、美しい絵**として描く。お手本は「⑩ 脳動静脈奇形（AVM）」の最後のカット（#20「絡まりを見抜け」：紫に光るナイダスを両手で包むウインクの看護師）。

このスキルは、「医療動画1」「医療動画2」「医療動画3」「インフォグラフィック C1」など、チャッピー（ChatGPT）に渡す指示文の中で女の子が出るカットを書くときに、人物の部分をこの設定に差し替えるために使う。

## 方向性（いちばん大事）

- **可愛い → 美しい**。アニメっぽさを抑えた、きちんとした「絵」。セミリアルな手描きイラスト、上質な挿絵や画集のような仕上がり。
- 等身は大人の自然なバランス（頭身はリアル寄り）。**ちびキャラ・デフォルメ・二頭身は使わない。**
- 目は大きすぎず、自然な大きさ。星や大きなハイライトのキラキラ目にしない。
- 光で美しく見せる。臓器や血管の発光が、顔・手・スクラブにやわらかく映り込む。

## 固定キャラ設定（毎回同じにする）

- 20代の日本人女性看護師、後輩
- 髪：あごラインのつやのあるブラウンのボブ。やわらかい前髪を少し横に流す。髪の毛束とハイライトを丁寧に描く
- 目：温かいブラウンの瞳、自然な大きさ
- 表情：口を閉じたやさしい微笑み、ほんのり頬に赤み。基本はウインク（片目を閉じる）か、穏やかな笑顔
- 服：くすんだブルー（ペリウィンクル寄りの青）の半袖Vネックのスクラブ、左胸にポケット
- 構図：基本は正面・腰から上。手は臓器・カード・ペンライトなど「教える物」を持つ
- 背景：深いネイビー。片側に、半透明でガラスのように光る人体の横顔や臓器のシルエットをうっすら置く

## チャッピーに渡す人物ブロック（そのまま貼る）

女の子が出るカットの指示文の中に、次のブロックを入れる。ほかのルール（9:16、上下20%空白、色分け、ラベル）は元のスキルのまま使う。

```
■人物（後輩看護師）——「可愛い」ではなく「美しい絵」で描く
・画風：セミリアルな美しい手描きイラスト。上質な挿絵や画集のような仕上がり。アニメ調・ちびキャラ・デフォルメは使わない。等身は大人の自然なバランス
・20代の日本人女性看護師。あごラインのつやのあるブラウンのボブ、やわらかく横に流した前髪、毛束とハイライトを丁寧に
・温かいブラウンの瞳（自然な大きさ。キラキラの大きな目にしない）、口を閉じたやさしい微笑み、ほんのり頬の赤み
・くすんだブルー（ペリウィンクル寄り）の半袖Vネックのスクラブ、左胸ポケット
・正面、腰から上。光る臓器や血管の色が、顔・手・スクラブにやわらかく映り込む
・背景は深いネイビー。片側に半透明で光る人体の横顔シルエットをうっすら
・前回のこの女の子（添付のお手本画像）と同じ顔・髪型・服で描く
```

## お手本画像の使い方

- 可能なら、お手本のカット（AVM #20）の画像をチャッピーに一緒に添付し、「この女の子と同じ顔・髪型・服・画風で」と書く。顔の一貫性がいちばん保ちやすい。
- 1本の動画の中では、最初に出た女の子のカットを次のカットの参考画像として渡し、顔がぶれないようにする。

## よく使うポーズ（指示文の例）

- エンディング：正面でウインクし、光る臓器（例：紫のナイダス）を両手でそっと包む
- 症状カード：3枚の半透明ガラスのカードを手のひらにのせて見せる
- 看護ポイント：ベッドサイドのモニターを指さす、ペンライトを持つ
- 観察項目：周りに4つのガラスの球（意識・瞳孔・麻痺・けいれんなど）が浮かぶ

## 動画にするとき

- 女の子のカットは生成AIで動かさない。静止画にゆっくりズーム・パンをかけるだけにして、クレジットは心臓・臓器・体のカットに使う（「動かす予算の配分」のルールと同じ）。

## やらないこと

- ちびキャラ、二頭身、デフォルメ、大きなキラキラ目、口を大きく開けたアニメ的な表情
- 水色の明るすぎるスクラブ（くすんだブルーにそろえる）
- 1カットに人物を2人以上出すこと（登場人物は1人）
