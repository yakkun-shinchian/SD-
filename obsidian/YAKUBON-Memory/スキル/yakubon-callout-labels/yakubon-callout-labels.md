# YAKUBON 引き出し線ラベル（これは何？）

たとえ（結晶＝凝固因子、輪＝番人、など）で描いた医療動画は、見る人に「この派手なマークは何？」が伝わらない。テロップとは別に、**絵の中の1つ1つに名前と引き出し線**を入れて仕上げる。

## いつ使うか
- 医療動画（医療動画1・2・3）を組み立てたあと、毎回かならず。
- 臓器・細胞・分子・薬・機械など、名前を知らないと分からないものが映っている場面すべて。
- 看護師の女の子だけの場面（静止カット）は付けなくてよい。

## 何に付けるか
- その場面の主役（例：Ⅹa、トロンビン、アンチトロンビン、薬の分子）は必ず。
- たとえで描いたもの（結晶・輪・葉っぱ・ビーズの鎖など）は、ほんとうの名前を付ける。
- 色が実物と違うもの（青い赤血球など）にも付ける。
- 1場面2〜4個が目安。まとめの場面だけ6個まで。
- 同じ種類が並ぶときは、ラベル1つから線を何本も出してよい（例：Ⅱ・Ⅶ・Ⅸ・Ⅹ因子の4つの結晶）。
- 名前は短く。必要なら（ ）で一言（例：「アンチトロンビン（番人）」「Ⅹa（活性化第Ⅹ因子）」「凝固因子（数日かけて減る）」）。「／」で2行に分けられる。
- 中身は台本・テロップと一致させる。台本にないものの名前を足すときは、イラストの指示文（image_jobs.json）で何として描かせたかを確認してから付ける。

## 色：ラベルは指している物の色にそろえる
色を見るだけで「どの絵のことか」が一目で分かるように、**文字・線・線の先の丸を、指している物のイラストの色にそろえる**。
- 色の取り方：その物のいちばん目立つ色（ハイライトや影ではなく、本体の色）をコマから拾う。光っている物は光の色でよい（例：金色の結晶→金色、青い輪→青、赤い赤血球→赤）。
- 読みやすさの調整：暗い色・くすんだ色はそのままだと濃紺の板に沈むので、**明るさを上げて**使う（色みは変えず、明るく・やや鮮やかに）。目安は、暗い板の上でパッと読める明るさ。
- 縁取りは今までどおり濃紺。どの色でも縁取りで文字の形を立たせる。
- 1つのラベルから何本も線を出すとき：対象が同じ色ならその色。色がばらばらなら、いちばん主役の物の色にするか、白にする。
- 同じ場面で隣どうしのラベルがほぼ同じ色になって見分けにくいときは、片方の明るさを少し変えて区別する。
- 物が白っぽい・灰色の場合は、白のままでよい。

## 見た目（毎回同じ）
- 文字：極太明朝（Noto Serif JP Black、無ければHG明朝E）、54px、色は上の「色」のルールで決める。
- 線と対象の小さな丸も文字と同じ色（文字・線・丸の色はそろえる）。どれも濃紺の縁取り。
- ラベルのうしろに半透明の濃紺の角丸の板。
- その場面のラベルは**一斉にパッと**出す（場面の頭から約0.4秒後、0.18秒のフェードイン）。1本ずつ出さない。
- 冒頭0.3秒は出さない（タイトルより先に出さない）。

## 出している時間は1.8秒以上（2026-11-18 本人指示）
- ラベルが0.5秒ほどで消えると、何が書いてあったか分からない。**1つのラベルは最低1.8秒、ラベルが3つ以上の場面は約2秒以上**出す。
- Tipsが出る場面は、まずラベルを約2秒見せてからTipsに切り替える（ラベル until 2.4 → Tips at 2.5）。そのぶん場面の長さ（min_dur）を約5秒にのばす。声が短くても、ラベルとTipsを読む時間を優先する。
- `add_callouts.py` は、出ている時間が1.8秒より短いラベルがあると「出ている時間が短い」と表示して書き出しを止める。0件になるまで、until を遅らせる・場面の長さをのばす・delay を早める。

## 文字は絶対に重ねない（2026-11-18 本人指示・最優先）
- **ラベルどうし、ラベルとテロップの帯、ラベルとTipsの板の文字が重なることは基本的に許されない。** 少しでも重なったら直してから仕上げる（縦隔炎の動画で「たまった膿」と「押し広げられた胸骨」、「皮膚の縫い目」と「縦隔」が重なって読めなかった）。
- 直し方は次の順で選ぶ：
  1. **ずらす**：同じ側に2段で置くときは、段と段の中心を **100px以上** 離す（ラベルの板は1行で高さ約85px。60pxでは重なる）。2段目は反対側の空いている所に回してもよい。
  2. **短くする**：長い名前（10字以上）は板が横に広がって反対側のラベルに届く。テロップで言っていることはラベルでくり返さず短くする（例：「縦隔（心臓の前の空間）」→「縦隔」、「菌（黄色ブドウ球菌など）」→「菌（ブドウ球菌など）」）。
  3. **時間をずらす（ゆっくり出す）**：どうしても場所が足りないときは、delay と until で出る時間を分け、同時に出さない。
  4. **絵を縮めて下げる**：テロップの帯と絵のすき間が足りないときは、edit.json の shrink・shift_y で絵を下げて、ラベルを置く場所をつくる。
- `add_callouts.py` は、同じ時間に出ているラベルどうし（板のまわり10px）とテロップの帯の重なりを自動で調べる。重なりがあると「重なり ○○：「A」と「B」が重なる」と表示し、本番の書き出しを止める。`--check` でも表示されるので、**重なりが0件になるまで直す**。
- 線どうしが交差する・線が別のラベルの板を横切る置き方も避ける（指す物と同じ側にラベルを置く）。

## 置き方
- 上のテロップ（メイン・補足）と重ねない。ラベルはテロップの下から画面下までの空いている暗い所に置く。
- ラベルは左右の端（中心 x≈180〜230 と x≈830〜890）に寄せ、線で中央の対象へ引っ張ると見やすい。
- 主役の形・病変・顔・手の上にラベルの板を置かない。線が主役を横切るのは最小限に。
- ラベル同士が重ならないよう、上下にずらす。
- カメラがゆっくり寄る・回り込む場面では、対象の位置を「場面の始め」と「終わり」の2点で測り、線の先を追いかけさせる。

## 手順（PC：C:\YAKUBON_STUDIO）
1. 完成動画から各場面の始め（+0.7秒）と終わり（−0.25秒）のコマを、100pxの目盛り入りで抜いて、対象の座標（1080×1920）を読む。同じコマから対象の本体の色も拾う。
2. 作品フォルダに `callouts.json` を書く。
   ```json
   {"scenes": {"03": [
     {"text": "Ⅹa（活性化第Ⅹ因子）", "label": [780, 760], "color": "#FFC94A",
      "targets": [{"from": [346, 745], "to": [346, 745]}], "delay": 0.4}
   ]}}
   ```
   - label＝ラベルの中心（動かない）。from／to＝場面の始め／終わりの対象の位置。
   - color＝文字・線・丸の色（読みやすく明るさを調整したあとの値）。省くと白。
   - あとから出てくる物（例：途中で現れるワルファリンの分子）は delay を大きくする。
   - `add_callouts.py` が color を読めない古い版なら、まず color（省略時は白）を文字・線・丸に使うよう直してから進める。
3. `python -X utf8 pipeline\add_callouts.py <作品フォルダ> --check` で確認用の一覧（_callout_check.jpg）を作り、線の先が対象に乗っているか、テロップや主役にかぶっていないか、端で切れていないか、**色が指している物と合っていて暗い板の上で読めるか**を見る。ずれていたら直して、もう一度 --check。
4. `python -X utf8 pipeline\add_callouts.py <作品フォルダ>` で `<title>_ラベル入り.mp4` を作る（元の _完成.mp4 は残す）。
5. 完成動画から各場面のコマを抜いて最終確認してから、チャットに送る（iPadで受け取れるように）。

## 確認のポイント
- **文字の重なりが0件か**（add_callouts.py の「重なり」表示が出ないこと。コマを目で見ても、板と板・板とテロップが触れていないこと）。
- **どのラベルも1.8秒以上出ているか**（Tipsの場面で、ラベルが一瞬で消えていないか）。
- 線の先の丸が、ちゃんとその物の上に乗っているか（ずれて隣の物を指していないか）。
- ラベルの色が指している物の色と合っているか。色だけで「どれのことか」が分かるか。
- スマホで読めるか（暗い色が沈んでいないか）。テロップより目立ちすぎていないか。
- 医学的に正しい名前か（たとえの絵と、ほんとうの名前の対応が合っているか）。
