# イラストはCodexに描かせ、Claudeが指示・編集・最終チェック（2026-11-27 シンサクさん指示）

これからの医療動画のイラストは、シンサクさんがチャッピーに貼って頼むのではなく、ClaudeがWindows PCのCodex（codex-cli）に直接指示して描かせる。Claudeは指示文を書き、届いた絵を確かめ、必要なら編集し、最後に医学と見た目のチェックをする。

## 役割
- **Codex**：絵を描いて作品フォルダの images\ に保存するだけ。動画は作らない。
- **Claude**：①指示文を書く ②Codexを動かす ③届いた絵を全部目で確かめる（文字の混入・解剖・左右・構図のずれ） ④必要なら編集（色を抜く・暗くする・切り抜く・名前と引き出し線を入れる。絵そのものを新しく描くことはしない） ⑤医学監修（yakubon-medical-review）と最終チェック。
- シンサクさんの手作業（チャッピーに貼る・保存する）は要らない。

## 動かし方（Windows PC）
- 道具：`C:\YAKUBON_STUDIO\pipeline\codex_image_v2.ps1 -Work <作品フォルダ> -Out <カット名.png> -Prompt <指示.txt> -Refs refs\参照.png`
  - codex-cli 0.170 以降は `--full-auto` が無い。`--approve-for-me` を使う（`-s` と同時に付けない）。
  - 指示は `-i`（参照画像）より前に置く。`-i` は複数ファイルを取るので、後ろに置くと指示まで画像として食われる（"No prompt provided" になる）。
  - 1枚あたり約9分。2列で並行して流してよい（作品フォルダの `_tga_series_run.py` が見本）。Start-Process で裏で流し、ログ（codex_<カット>.log、exit=0）と images\ を見て終わりを確かめる。
- 作品フォルダに `prompts\<カット>.txt`（指示）と `refs\`（参照画像）を置いてから流す。

## 指示文の書き方
- 共通の前置き（毎回）：縦長9:16の医療イラストを1枚／イラストだけ・動画は作らない／文字・数字・記号・矢印・ラベル・引き出し線は一切入れない（描いたあと自分で確認して描き直す）／美しく、すっきり、詰め込まない。
- 色は指定しない（酸素の多い血と少ない血が見分けられるように、だけは書く）。絵柄は参照画像に合わせてもらう。
- 1枚ずつ、毎回最初から全部書く（「前の絵と同じ」と書かず、添付した参照画像を名指しする）。
- 同じ構図で中身だけ変えるカットの組は、**最初の1枚をClaudeが確かめてから、その絵を参照画像にして残りを描かせる**（構図がそろう）。指示に「形と位置は参照画像のまま変えず、変えるのは○○だけ」と書く。
- Codexには『医療動画2』スキルが無いので、その一行は書かない。代わりに参照画像で絵柄をそろえる。

## チェック（Claude）
- 届いた絵は縮小一覧にして全部見る：文字の混入、解剖（血管のつながり・左右・弁）、色の意味（酸素の多い・少ない）、参照との構図のずれ、背景の純黒（四隅）。
- だめな絵はプロンプトを直して同じカットだけ描き直させる（参照画像も付け直す）。
- そのあとは今までどおり ComfyUI で動画化 → 組み立て → yakubon-medical-review（Fable）→ 納品。
