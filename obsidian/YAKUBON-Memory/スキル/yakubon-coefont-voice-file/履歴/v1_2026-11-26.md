# 医療動画の声は、本人のCoeFont音声ファイルで入れる

2026-11-26 シンサクさん指示。医療動画のナレーションは、**本人がCoeFontで作った音声ファイル**を使う。Claudeは声を作らない。
以前の「MiniMax（Japanese_IntellectualSenior）で声を作る」決まりより、こちらを優先する。

## Claudeがしないこと
- MiniMax・ElevenLabs・クリエイティブクローの speech など、**TTSで声を作って入れない**（クレジットも使わない）
- 本人の音声を待たずに、仮の声を作って「完成」としない
- 声を速くしない（atempo・倍速は禁止）。CoeFontの声はもともと約1.23倍速なので、これ以上は速めない
- 原稿をPCのファイルに入れて終わらせない（本人はiPadからコピーしてCoeFontに貼る）

## 流れ
1. **原稿を出す**：台本ができたら、スキル `coefont-hiragana-narration` で、全部ひらがな・句読点なし・1カット1段落の原稿を書く。チャットに直接、そのままコピーできる形で出す。出す前に、ひらがな・「ー」・改行以外の文字が入っていないかコードで確かめる。
2. **本人の音声を待つ**：待つあいだは、声なしで組み立てを先に進めてよい（ComfyUIのカット・テロップ・引き出し線・Tips）。声なしの仮の長さは1カット3秒。
3. **音声を取り込む**：届いたファイル（1本録りでも、段落ごとでもよい）を作品フォルダの `voice\` に置く。
   - 1本録りは、無音の谷と文字起こし（faster-whisper small、またはクリエイティブクローの transcribe）で段落の切れ目を出して、場面ごとに `voice\<場面ID>.wav` に切る。切る位置は谷のまん中。
   - 段落ごとの文字数÷秒が、だいたいそろっているかで切れ目を確かめる。段落の中の短い間（ま）で割れたら、つなぐ。
   - 手を入れてよいのは、段落ごとに切ることと、前後の無音を詰めることだけ。文の途中の間は詰めない。
4. **読みを確かめる**：文字起こしと原稿を照らす。読み間違い（「は」を「ハ」と読む、数字の読みなど）があれば、その段落だけ直したひらがな原稿をチャットに出して、録り直しを頼む（「は」→「わ」、「へ」→「え」、「じゅう」→「じゅー」など）。
5. **映像を声に合わせる**：`build_base_timed.py` で場面の長さを声に合わせる。50秒を超えても、声は速めずに映像で埋める。体の中のカットは逆再生（pingpong）を使わず、`fill: loop` か `max_stretch`（1.3〜1.5）で伸ばす。
6. **仕上げの確認**：書き出したあと、ffprobe で音声トラックがあるかを必ず確かめる。1秒以上の無音がないかも測る。

## 本人への伝え方
- 原稿を出すときは、「CoeFontで作った音声ファイルを、このチャットに送ってください（1本録りでも段落ごとでも大丈夫）」と一言添える。
- 音声が届いて入れ終わったら、どの段落をどの場面に入れたか、全体が何秒になったかを短く伝える。
