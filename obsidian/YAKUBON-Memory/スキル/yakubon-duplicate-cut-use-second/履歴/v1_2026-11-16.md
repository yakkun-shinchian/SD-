# 同じカットが2枚届いたら、2枚目を使う（YAKUBON STUDIO）

2026-11-17 シンサクさんが決定。チャッピー（ChatGPT）が同じカットの絵をもう1枚描いてくるのは、**1枚目がエラーだったので描き直したから**。だから、ダブって届いたカットは**必ず後から届いた方（2枚目）**を使う。

## いつ使うか
- チャッピーのイラスト一式を受け取って、医療動画（医療透明動画・医療動画2・3など）を組み立てる前に、毎回かならず。
- インフォグラフィックやカルーセルの絵でも同じ。

## 手順
1. 届いた順番どおりに絵を並べ、台本のカット番号に当てはめる。
2. 同じカット（構図・中身がほぼ同じ絵）が2枚以上あったら、**届いた順番で最後の1枚**を採用する。
   - 見た目の好み（光っている・きれい・リアルなど）で1枚目を選ばない。
   - 3枚以上あっても、最後の1枚。
3. 採用しなかった絵は消さずに `images\<カット>_first.png` のように別名で残す。
4. 組み立ての報告で「カット○は2枚届いたので、後の絵を使いました」と一言添える。

## 迷うとき
- 2枚が同じカットか、別のカット（始点と終点など）か分からないときは、台本のカット一覧と照らす。始点・終点の2枚組は「ダブり」ではないので両方使う。
- それでも判断がつかないときだけ、本人に短く聞く。

## 実際に起きたこと
- 2026-11-17 Y字人工血管置換術：カット6（開腹の切開線）が2枚届いた。1枚目の青く光る写真風の絵で作ってしまい、本人の指摘で2枚目（イラスト調）で作り直した。
