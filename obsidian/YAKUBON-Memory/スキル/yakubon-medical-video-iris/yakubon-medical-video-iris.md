# 医療動画をIRISまで使って仕上げる（YAKUBON STUDIO）

Windows PC（C:\YAKUBON_STUDIO）にある道具を、もったいなく残さず全部使って医療ショート動画を作る。
作業前に `C:\YAKUBON_STUDIO\CLAUDE.md`（とくに15章IRIS・16章声の速さ）と `logs\iris_rotation.md`、`logs\kaizen.md` の直近5件を読む。
関連スキル：`iryo-douga-1-illust-script`（イラスト台本）、`coefont-hiragana-narration`（原稿）、`yakubon-iris-telop`（IRISのルール）、`yakubon-motion-effects`（大技は3つまで）、`yakubon-sns-caption`（仕上げ）、`yakubon-workflow-kaizen`（振り返り）。

## 背景は真っ黒（全工程で守る）
- 背景は **純黒 #000000**。濃紺・暗いグレー・グラデーション・ビネット・ぼかし背景・床や壁の質感は不可。青い光は被写体のまわりだけ。
- イラスト・動画化の指示に `pure black background (#000000), no gradient, no vignette` を入れ、ネガティブに `navy background, gray background, gradient background, fog, haze, vignette, background texture, floor, wall` を入れる。
- 土台動画を作る前に各クリップを黒締め（ffmpeg `colorlevels=rimin=0.05:gimin=0.05:bimin=0.05` 相当。暗部がつぶれるなら0.03）。CT・MRIの本物の画像の内部にはかけない。
- 絵を縮めて空いた所・余白・つなぎの下地は黒。ぼかした同じ絵で埋めない。
- IRISの部品も、光の部分以外は透明にして下の黒を見せる（黒い板や濃紺の面を足さない）。

## 道具の役割
| 道具 | 使う場面 |
|---|---|
| チャッピー（医療動画1）／ `pipeline\gen_images_api.py`（OpenAI API・同じ画像モデル） | イラスト。作品フォルダの `image_jobs.json` から一括生成。nurse_v1 は ref "nurse" |
| Qwen-Image-Edit（ComfyUI） | できた絵の崩れ直し（手・顔・小物）、背景が黒くない絵の黒への塗り直し |
| **Seedance 2.0 Mini（クリエイティブクロー）＝冒頭ヒーローの標準**（2026-11-11 本人指示） | 最初のヒーロー（臓器の回り込み）は**毎回これで作る**。720p・9:16・generate_audio=false・6秒前後（約38クレジット）。**生成前に残高と見積もりを確認**し、足りなければ止めて本人に報告。Kling 3.0（アートリスト）は本人が指定したときだけ |
| Wan2.2 回り込みLoRA（`pipeline\wan22_rotation_orbit_api.json`） | ヒーローをローカルで回したいとき。**本人がヒーローの道具を指定しているときは勝手に使わない**。提案はしてよい |
| ComfyUI LTX-2.3（`pipeline\run_ltx_*.py` ＋ `jobs_ltx.json`） | ヒーロー以外の動かせるカット。始点・終点はキーフレーム（keys に2枚）。ワークフローは `pipeline\workflows\` の最新の標準版 |
| Blender（`blender\使い方.txt`、BP3Dの心臓・大動脈など） | 3Dモデルがあるテーマ（心臓・大血管など）の回り込み。ワールドの背景色は黒（0,0,0）。モデルがないテーマでは使わず、そう伝える |
| CoeFont（後藤さんの声） | ナレーション。1文＝1ファイルで届くことが多い |
| IRIS＋HyperFrames | テロップの文字エフェクト（568種）と動く演出（100種）。仕上げは必ずこれ |

## 手順
1. **シナリオ**：15場面前後。1場面＝テロップ（メイン＋補足）＋絵。根拠（国試・パス・ガイドライン）を控える。
2. **イラスト**：`iryo-douga-1-illust-script` の決まり（文字なし・純黒の背景×青・赤は標的だけ）。`image_jobs.json` を書き `gen_images_api.py` で生成 → 縮小一覧を作って全部目で確認（文字混入・解剖・左右・背景が純黒か）。
3. **動画化**：ヒーローは必ずクリエイティブクローの Seedance 2.0 Mini。Mini は「始点→終点」の2枚指定ができない（last_frame_url を付けると止まる）ので、正面の1枚を image_url（始点）にして、プロンプトで「斜め前→裏側まで約120〜180度、形・大きさ・光は変えない」と回す。9:16でない絵（3:4など）は黒で9:16に足してから上げる（そのままだと左右が切られる）。2枚ぶん（例：カット1・2）を1本6秒のヒーローにしてよい。それ以外は LTX-2.3。女の子のカットも動かせるなら少しでも動かす。ComfyUIはほかの作品と共有なので、`/queue` で待ち本数を見て、終わる時刻を本人に伝える。長く待つときは `send_later` で戻る。仕上がったら各クリップを4コマずつ並べて確認し、黒締めする。
4. **ナレーション原稿**：`coefont-hiragana-narration`（ひらがな・句読点なし・1場面1段落）でチャットに直接出す。
5. **声の割り当て**：届いたwavを番号順に並べ、原稿の文の数で場面に割り当てる（例：場面2が2文なら2・3番）。前後の無音だけ詰め、文と文の間は0.12秒。**速さは絶対に変えない（atempo禁止）**。`voice\01.wav〜` に置く。長くなっても映像で埋める。
6. **edit.json**：場面ごとに
   - **体内のカット（血流・出血・髄液・器具が写るもの）はすべて `"max_stretch": 1.5`。`"fill": "pingpong"`（順再生→逆再生）は使わない**。逆再生で血が逆流し、噴き出した血が穴へ戻り、医学的にあり得ない動きになる（2026-11-18 本人指摘）。pingpong を使ってよいのは人物の静かなカットだけ。尺が足りないときは49コマ（約2秒）で作って 1.5倍でちょうど3秒
   - 文字エフェクト番号 `"fx"`：IRISの `references\文字演出の意味対応表.md` で**意味から選ぶ**。テロップはある程度一定にそろえ、その場面に合うときだけパッと違うものを入れる。いちばん強い1場面だけ 49（着弾＋衝撃波）。上下に線が残る41のような番号は2行テロップでは使わない
   - 長いテロップは `"lines"` で読みやすい位置に2行
   - 動く演出が言葉を兼ねる場面は `"no_telop": true`
   - `"comps"`：大技は**冒頭・切り替え（または山場）・締めの3つまで**。`pipeline\iris_comps_all.py` から選ぶ（e10/e44/e54/e59/e71/e97/e32/e52/e56/e60/e72/e76、青版 e56b、上置き版 e72t）。`iris_rotation.md` で直近の番号を避ける。足りなければ `IRIS\teaser-pv\assets\motion100\compositions\eNN.html` から、動きの時刻はそのまま、縦・極太明朝・エメラルドに組み直して iris_comps_all.py に足す
   - 顔が上部テロップにかかる女の子の絵は、絵を80%に縮めて下へずらす（**まわりは真っ黒**）
7. **土台動画**：`python -X utf8 pipeline\build_base_timed.py <作品フォルダ>` → `_base.mp4`（声あり・文字なし）と `timings.json`。
8. **IRISを重ねる**：`python -X utf8 pipeline\make_iris_v2.py <作品フォルダ>` で `iris\` を作る → `Start-Process powershell -File pipeline\render_iris.ps1 -Work <作品フォルダ>` で書き出し（ほかの書き出し中は自動で順番待ち。node直接・PATH補正済み。画質は standard）。最後に土台の声を入れて `_完成.mp4`。前の版は `_完成_○○版.mp4` に名前を変えて残す。
8.5 **医学監修**：スキル `yakubon-medical-review` で Fable（Agent model fable）に場面ごとのコマ・テロップ・ラベル・Tipsを監修させ、「高」が0件になるまで直す。直したら再監修して「公開可」をもらってから納品する。
9. **確認**：完成動画から各場面のまん中と、大技の場面は2コマずつ抜いて並べる。文字の崩れ・線が文字に重なる・顔や病変にかかる・下の絵が隠れる（演出の黒い板）を見る。**四隅と上下の端の帯（5%幅）の平均値を測り、RGB 8 を超える場面があれば直す。** 1秒以上の無音がないか測る。
10. **記録**：`logs\iris_rotation.md` に「日付・動画名・場所・番号」と文字エフェクトの番号を追記。
11. **キャプション**：`yakubon-sns-caption` で1ブロック。作品フォルダに `caption.txt`。
12. **納品**：`device_stage_files` → `SendUserFile`（iPadで受け取れるように）。同じ返事に、どのカットをどの道具で動かしたか、使ったクレジットと残りを一言。
13. **カイゼン**：`yakubon-workflow-kaizen` で振り返り、ワークフロー・スクリプト・スキルを直す。返事の最後に「今回のカイゼン」を3行以内。

## つまずきやすい所（実際に起きたこと）
- IRISの部品の中では `mix-blend-mode: screen` が下の動画に効かず、真っ黒な板で絵が隠れる → 光の部分以外は透明にする（e56b）
- e72 の黒い板は画面の下半分をおおう → 主役が下にいる絵では上置き版 e72t
- npx 経由の書き出しは順番待ちの途中で止まることがある → `render_iris.ps1`（node直接）を使う
- このPCのHyperFramesの画質は draft／standard／high（looks は通らない）
- ffmpeg が見つからないと書き出しが失敗する → ps1 の中で PATH を読み直している
- 声を速くすると「早すぎる」。速さは変えず、長さは映像で埋める。短くしたいときは原稿を短くして録り直してもらう
- 声のない土台（音声トラックなし）を IRIS に渡すと「expected: audio」で書き出しが止まる → `make_iris_v2.py` が無音の音声を足すよう直した（2026-11-11）。`render_iris.ps1` は `-map 1:a?` で音なしでも通る
- 書き出し中に土台を作り直すと、古い土台のまま完成ができる → 作り直したら `_完成.mp4` を消してから書き出し直し、完成からコマを抜いて確かめる
- 背景が黒でなくなる原因になりやすい所：イラスト自体が濃紺背景で来る／LTXが背景に霧や濃紺をにじませる／顔よけで縮めた絵のまわりをぼかしで埋める → いずれも上の「背景は真っ黒」で防ぐ

## 声なし・「1枚3秒」と言われたとき（2026-11-11）
- 声を待たずに作る。各場面 dur 3.0（ヒーローは2枚ぶん6秒）、xfade 0.2。完成は無音のまま（音は本人がSNS側で乗せる）
- 1枚3秒は `pipeline\illust3s.py`（絵を始まりに1回だけ渡す標準）。ただし輪・点線・カテーテル・ワイヤー・ワイヤーフレームなど「形そのものが説明」のカットは、`prompts_3s.json` で frames 49（約2秒）にし、ネガティブに `rotating view, ring disappearing, ring breaking, catheter splitting, two catheters, new wires, new pins, white capsule, bright oval blob` を足す（2026-11-17 心房細動アブレーション：73コマでは1.5〜2秒すぎに輪が消える・カテーテルが2本になる・白いカプセル光が出た → 49コマで解消）。足りない長さは edit.json の `fill: pingpong` で埋める
- できたクリップは4コマ抜きで確認し、くずれ始める秒数がわかったら `clip_max` でその手前までにする
- ヒーローの Seedance 2.0 Mini は後半で形がくずれやすい。4コマで確かめ、きれいな頭の部分だけ使う（prep で `-t` で切る）
- あとから声が入る予定なら、ヒーローの min_dur は「声の長さ＋0.6秒」くらいにしておく（声なしの4.6秒のままだと、声のあとに1.3秒の無音が出た）
- CoeFont の1本録りは、まず無音検出（-35dB・0.1秒）で切り、段落ごとの「文字数÷秒」が10〜12字/秒でそろうかで切れ目を確かめる。段落の中の間（0.4秒前後）で割れたらつなぐ
- 始点→終点の2枚組（例：縦の面→横の面、輪切りの面が下りる）は、始点のカットを keys 2枚の変化クリップ（max_stretch 1.5）、終点のカットを1枚から動かすクリップにして、それぞれ3秒
- CT・MRIの本物の画像は AI で動かさず mode "still"（ゆっくり寄り）。引き出し線の位置がずれないよう ct モード（引く→寄る）は使わない。3:4 のCTは黒で9:16に足してから使う
- 引き出し線（lab）で区域名（S1〜S8 など）を全部の解剖カット・CTに入れる。区域ごとの色はイラストの色から取り、CTでも同じ色にそろえる。ラベルの札は上のテロップ帯（約410px、2行なら約550px）より下、臓器の外の黒い所に置く

## してはいけないこと
- BGM・効果音を勝手に入れない
- IRISの見本の写真・文言を残さない。IRISのファイルを配らない・上げない
- 本人が指定した道具（ヒーローの生成サービスなど）を、黙ってほかの道具に替えない
- 「国家試験対策」と入れない
