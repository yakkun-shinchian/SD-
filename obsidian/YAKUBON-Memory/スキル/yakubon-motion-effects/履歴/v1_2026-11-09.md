# モーションエフェクトは「ここぞ」で使う

YAKUBON STUDIOの縦型医療動画（9:16、25〜50秒）に、Claudeで作れるモーションエフェクトを取り入れる。
目的は「見せ場で記憶に残すこと」。飾りではない。**使わない勇気がいちばん大事。**

## いちばん大事なルール

- **1本に入れる「大技」は最大3つ。** 置き場所は次の3か所だけ。
  1. **つかみ**（冒頭0〜3秒）
  2. **山場**（いちばん伝えたい数値・病態の変化・危険）
  3. **締め**（まとめ・保存したくなる要点）
- 短い動画（30秒未満）なら大技は2つまで。
- **同じエフェクトを1本で2回使わない。** 大技と大技のあいだには、静止画（ズーム・パン）のカットを最低2つはさむ。
- **エフェクトは内容を説明するときだけ使う。** 「数値が大事 → Number→roll」のように、動き自体が意味を持つ場面を選ぶ。意味がないなら使わない。
- **医療の正確さが優先。** 解剖図・引き出し線・ラベルを隠したり動かしたりしない。テロップと重ねない。
- **ナレーションのキーワードと同期させる。** エフェクトのピークを、その言葉が読まれる瞬間に合わせる。
- 死・苦痛・患者の尊厳にかかわる場面では、派手なエフェクト（Confetti、Screen Shatter、Snap Zoom など）は使わない。
- テロップの出し方などの「小技」は1本につき1種類に統一する。

## 場面別のおすすめ

### つかみ（0〜3秒）
- Snap Zoom / Zoom Through Cut：病態イラストへ一気に飛び込む
- Headline Wall / Words→kinetic：「その一言、危ないです」などの強いコピー
- Magazine Cover：シリーズの表紙風に始める
- Particles→logo：シリーズ冒頭やYAKUBON STUDIOのロゴ演出（毎回は使わない）
- Orbit / Rings→orbit：心臓や臓器のまわりを回り込む

### 数値・データを見せる（山場向き）
- Number→roll：正常値・異常値・致死率・薬の量など「この数字を覚えて」
- Line→draw / Growth Curve：バイタルや検査値の推移（血圧低下、CVP上昇など）
- Ribbon→twist / Grid→wave：心電図・呼吸の波形のイメージ
- Glass→tilt / Liquid Glass / Glass Type：検査値カード、ガラス風テロップ

### 病態の変化を見せる（山場向き）
- Shape→morph：正常 → 異常（形が変わる）
- Liquid→merge：液がたまる、血栓ができる、合流する
- Pull-Back Reveal：局所 → 全体像（「実はこの臓器の話でした」）
- Zoom Portal：体の外 → 体の中へ

### 危険・急変・禁忌（山場向き、1本に1つまで）
- Dolly Zoom：急変に気づく瞬間の緊張感
- Screen Shatter：「これは絶対NG」の禁忌

### 比較・鑑別
- Cards→shuffle：鑑別疾患のカードを入れ替える
- Video Wall / UI World：症状や所見を一覧で見せる

### 先輩・後輩のやりとり
- Chat Takeover：LINE風に先輩とのやりとりを見せる
- Floating Phone / Phone Mockup / Phone→explode：スマホ画面・アプリ風の見せ方

### 締め（まとめ・保存を促す）
- Checklist Pop / Checklist：観察ポイント3つを順に出す（いちばん使いやすい締め）
- Confetti→burst：クイズの正解・「これで完璧」（明るいテーマのときだけ）

### やさしい解説向き
- Paper Cutout / Doodle Boil：手描き・切り絵風でやわらかく説明する

### 実写素材があるときだけ
- Studio Reveal / B-Roll Overlay / Green Screen / Digital Zoom / Frame Escape：人物の実写を使う回だけ。イラストのみの回では使わない。

### 基本使わない
- Button→pay、Globe→arcs、Gradient→flow（背景としてごく控えめにならOK）

## 作り方

1. カット表を作るとき、各カットに「エフェクト」の列を設ける。大技は3つまでに印をつけ、残りは静止画（ズーム・パン）にする。
2. エフェクトはHTML/CSS/JS（またはRemotion）で1080×1920・30fpsの短いクリップ（1〜2.5秒）として作り、MP4に書き出す。
3. 背景・色・フォントは元のイラストと動画全体のトーンに合わせる。
4. ffmpegでイラストのカットとつなぎ、ナレーション（CoeFont）のキーワードにピークを合わせる。
5. 書き出し後、通しで見て「大技が3つ以内か」「同じエフェクトが2回出ていないか」「ラベルやテロップを隠していないか」を確認する。
6. 完成したら、いつもどおりキャプション・キーワード・ハッシュタグまで作る。

## 迷ったときの判断

- 「このエフェクトを外したら、伝わり方が落ちる？」→ 落ちないなら外す。
- 「新人看護師が見て、内容より動きが記憶に残らない？」→ 動きが勝つなら控えめにする。
