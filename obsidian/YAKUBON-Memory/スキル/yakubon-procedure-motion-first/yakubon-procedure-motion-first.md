# 手技動画は「動き」が最優先（第一優先スキル）

医療動画の**すべてのストーリー**（検査・処置・治療・手術・合併症・疾患解説。血管内治療、内視鏡、気管支鏡、ERCP、IVR、穿刺、手術、急変対応など）で、**ストーリーを考える前に**このスキルをいちばん先に読む。ストーリー、チャッピーに渡すイラスト台本、動画化のどの段階にも当てはめる（2026-11-17 本人指示：「そうじゃないとバズらない、絶対に」）。ほかのスキル（iryo-douga-1-illust-script、medical-video-motion-budget、yakubon-medical-video-assembly、yakubon-medical-video-iris など）と食い違うときは、**構成と動きについてはこちらを優先**する。テロップの書体・背景・ナレーション・キャプションの細かい決まりは、これまでどおり各スキルに従う。

## いちばん大事なこと（焦点と枝葉）
- **焦点＝体の中で処置が行われ、臓器・血管・気道・消化管がダイナミックに動くところ。** 器具が進む・つまむ・ふさぐ・ふくらむ・吹きつける、血が噴き出す・あふれる・止まる、血流が流れる、空気が流れこむ、臓器がふくらむ・しぼむ。**手術で術者の手（青い手袋）が器具を動かすところ**（切る・縫う・つまむ・はさむ）も焦点に入る。動画の価値はここにある。
- **枝葉＝それ以外ぜんぶ。** 看護師の顔、患者さんの寝顔、モニターの光、数値が下がるだけの抽象カット。テロップで1行言えば済むものは、カットにしない。
- 迷ったら「このカットは、体の中で何が起きているかを見せているか？」と聞く。答えが「いいえ」なら切るか、ほかのカットのテロップに入れる。

## なぜこれがバズるのか
- 患者さんも看護師も、**手術中に何が行われているか、なぜそれがリスクなのか** が見えていない。
- だから「血管の中で今なにが起きているか」が動きで分かる動画が伸びる。基準はフローダイバーター治療の動画（約20万再生）。これがいまの最高品質で、これより下の品質ではフォロワーが頭打ちになる。

## 鉄則（毎回かならず）

### 1. 止まる瞬間をゼロにする
- **赤血球（血流）は全カットで流れ続ける。** 器具が主役のカットでも、背景の血流は必ず流す。最後のカットも最後のコマまで流す。
- 静止画にズーム・パンをかけただけのカット、止め絵のクロスフェードは使わない。
- 尺が足りないときに「最後の状態で止めてゆっくり寄る」はしない。同じ終わりの絵から **血流だけが流れ続ける続きのクリップ** をComfyUIで追加で作ってつなぐ。
- 変化のないカット（血流だけのカット）は pingpong で延ばしてよい。変化を見せるカット（器具が進む・開く・血栓化が進む）は逆再生しない。

### 2. 手技の動きは必ずComfyUIで動かす
次の動きは、こちら側の簡易演出で代用せず、ComfyUI（PCの LTX-2.3・画像→動画）で必ず動きをつける。
- ガイドワイヤーが先へ進む
- カテーテル（マイクロカテーテル）が進む
- ステント・フローダイバーターの網が少しずつ開いて血管の壁に密着する
- コイルがループを描いて瘤の中に入り、外枠→内側へ重なっていく
- 器具を抜いて、網やコイルだけが残る
- 治療後に流れが変わる（親血管は流れ、瘤への流れ込みが減る）
- 時間経過（瘤の中で血栓ができる、内膜が育って入口がふさがる）
- ComfyUIの設定は、**絵を始まりに1回だけ渡す設定**（動きが大きく出る）を基本にする。器具がどこまで進むかを決めたい工程だけ、始点・終点の2枚を渡す。

### 3. 人とモニターは枝葉。切る
- 主役は「処置中に体の中で何をしているか」。人（患者・医師・看護師・後輩看護師の女の子）は基本出さない。
- **人が出てくるのは、最初と最後だけ**（例：最初＝症状が出た患者さん、最後＝回復した患者さん）。真ん中は、体の中・器具・術者の手が動くカットだけでつなぐ。
- 真ん中に人を入れてよいのは、**どうしても必要なときだけ**（例：看護師が体位を変えるなど、看護の手技そのものが話の主役のとき）。それも1カット2秒程度まで。
- **処置と関係ない説明だけのカットは作らない・作ってしまったら切る。** 例：モニターの光や波形が変わるだけ、SpO2・血圧が下がるだけ、看護師が気づいて振り向くだけ、患者さんが横になっているだけ。状態の変化（「SpO2が下がった」「アラームが鳴る」）は、**処置のカットのテロップ1行**で言えば足りる。
- 同じことを2カットで言わない（例：「下がりはじめる」→「急降下」の2連続は1つにまとめるか、両方切る）。
- 締めの女の子の決めアクション（yakubon-ending-cheer）は、手技動画では付けない。最後は処置の結果のカット（止血した、空気が流れた、網が密着した）を、体の中の流れを動かしたまま終える。

### 3b. ストーリーと台本の段階でチェックする（チャッピーに出す前）
- ストーリーは、処置の工程の順番そのものを骨組みにする（例：気管支鏡が入る→鉗子でつまむ→出血がにじむ→あふれる→反対の肺へ流れこむ→ウェッジで吸う→止血薬→ブロッカー→きれいな肺に空気）。人の気持ちの場面で骨組みを作らない。
- 全カットを「体の中の処置カット（術者の手を含む）」「人のカット」「その他」に分けて数える。チャッピーに渡すイラスト台本も同じ数え方で確かめてから出す。
  - 体の中の処置カット：**全体の8割以上**
  - 人のカット：**最初と最後だけ（どうしても必要な真ん中の1カットを足しても3つまで）**
  - モニター・数値だけの抽象カット：**0**
- 守れていなければ、チャッピーに出す前に台本を直す。人やモニターのカットを、処置の工程（器具が進む、出血が広がる、止血が効いていく など）のカットに入れ替える。
- 失敗例（2026-11-17 気管支鏡中の出血と窒息）：22カット中、人のカットが7、モニターの光だけが2（C08・C09）。本人から「人が動くところが多い」「サチュレーションが下がりました、で終わり。処置と関係ないから切る」と指摘された。

### 4. 「舞台」を固定して工程を追わせる
- 全工程で **同じ血管・同じ瘤・同じ構図** を使う。変わるのは器具と血流の状態だけ。見る人が「今どの工程か」を迷わない。
- カメラは冒頭だけ回り込み、そのあとは固定かゆっくり寄る程度。カットごとに角度を変えない。

### 5. リスクを必ず見せる
- 「どうしてこれがリスクなのか」を1〜2カット入れる（例：直後はまだ瘤に血流が残る、器具が血管壁を傷つける危険、血栓が飛ぶ危険、コイルが親血管へはみ出す危険）。
- これも動きで見せる。医学的に正確な範囲で、怖がらせすぎない。

## 構成の型（50秒前後・12〜14場面）
フローダイバーター動画を基準にした並び。手技ごとに工程の中身だけ入れ替える。
1. 冒頭ヒーロー（0〜3秒）：血流が流れる病変を3Dでゆっくり回り込む（Seedance 2.0 Mini）
2. 病気の提示：病変と、そこに血流が入り込む様子（なぜ危ないか）
3. アクセス：ガイドワイヤーを先へ
4. カテーテルを進める
5. 展開①：器具が出始める（入口をまたぐ／ループを描く）
6. 展開②：網が開いて密着する／コイルが重なる
7. 器具を抜いて、網・コイルだけを残す
8. 効果：親血管は流れ、病変への流れ込みが減る
9. リスク・限界：直後はまだ血流が残る など
10. 経過①：病変の中で少しずつ血栓化（「時間経過を短縮したイメージ」と小さく表示）
11. 経過②：内膜が育って閉鎖を目指す
12. 締め：治療の要点を1行（例：時間をかけて進む治療）。血流は流したまま終わる
- テロップは1場面1つ、2行までの短い言葉（例：「ガイドワイヤーを先へ」「器具を抜き網を残す」）。
- 画面下に小さく「模式CG・工程を簡略化」を入れる。

## いちばん大事な2〜3カットは、ジェミニ（Veo）に渡す
- 処置の山場（器具でふさぐ、止血薬が効く、風船がふくらむ、網が開く など）は、LTX の小さな動きで終わらせない。本人に、**どの絵を使うかと英語のプロンプト**を渡す（3本まで）。
- **本人に聞かれる前に出す**：動画化を始めた時点で、ジェミニ候補を「1本目（本命）・2本目（ギリギリ作れたら）」の順で出しておく。本人は「ジェミニがもう1本使える」と言ったら、すぐ次の候補の絵とプロンプトを返す（2026-11-17 初回離床で肺塞栓症）。
- **選ぶ順番**：①病気の仕組みが「動き」で分かる山場（はがれる・流れる・つまる・裂ける・あふれる）②LTXで逆向き・崩れが出たカット ③終点の絵が届いていない変化のカット（1枚から変化を最後まで動かす必要があるもの）④ほかのカットにまたがる流れ（例：下大静脈→心臓→肺動脈で引っかかるまでを1本で）。人・モニター・CT・エコーは選ばない。
- **長さは5秒**で書く。プロンプトに「0〜1.5秒：静か／1.5〜2.5秒：きっかけ／2.5〜5秒：変化」のように秒ごとの動きを書き、向き（画面の上＝膝・心臓の方 など）と「逆向きに動かない」をはっきり書く。
- 返事は「どのカットか（1行の理由）→渡す絵→コピペ用の英語プロンプト（コードブロック1つ）」の形で、iPadからそのまま貼れるようにする。
- プロンプトには「Image-to-video, vertical 9:16, 5 seconds, one continuous shot, camera completely still, keep exactly the same composition」「The ○○ moves only upward/forward, never backward」「Pure black background (#000000), no gradient, no vignette, no floor」「Dynamic action:（何がどう動くかを具体的に）」「the device never splits or duplicates」「no text, no people, no hands」「No music, no narration」を入れる。
- 届いたら、そのカットを入れ替えて、ラベルの位置も合わせ直す。

## チャッピー（ChatGPT）へのイラストの頼み方
- 1工程＝1枚。**全枚で同じ構図・同じ血管の形・同じカメラ位置** を指定し、器具の状態だけ変えてもらう。
- 赤血球を必ず描き込んでもらう（ComfyUIで流す材料になる）。
- 文字なし。静止画（イラスト）までで止める。動画は作らせない。
- 指示の例（英語）：`Same composition, same vessel shape and same camera angle as the previous image. Translucent glass-like blue cerebral artery with an aneurysm, many red blood cells (blue-tinted discs) inside the vessel and aneurysm. Only change: [the guidewire tip has advanced past the aneurysm neck]. No text, no people, no hands. Still illustration only, do not make a video.`
- 背景色の指定は yakubon-medical-video-assembly に従う。

## ComfyUIのプロンプトの決まり
- どのカットも、動きを2層で書く。
  - (A) 体の中の流れ（止まらない層）：血管なら `red blood cells continuously flowing along the vessel, steady natural blood flow, never stopping`。気道なら空気の光の粒が流れる・肺が呼吸でふくらむ、消化管なら胆汁・腸液が流れる・ぜん動、出血の場面なら血が湧き続ける。どれも最後のコマまで止めない
  - (B) そのカットの手技の動き：例 `the guidewire slowly advances forward through the vessel` / `the mesh stent gradually expands and presses against the vessel wall` / `the coil forms loops inside the aneurysm`
- カメラ：`static camera` か `slow push-in`。
- 形を守る：`keep the same vessel shape, same composition, no new objects, no text`
- ネガティブ：`frozen, still image, static blood cells, morphing vessel, melting, extra devices, duplicated catheter, text, watermark, people, hands, flicker`
- 崩れたら、シードとネガティブを変えて作り直す。器具が逆に動く・増えるのは必ず作り直す。

## 確認（動きの計測・毎回かならず）
完成動画を、画面の真ん中（テロップを避けた上下20〜68%の帯）で、0.5秒ごとの動きの量をコードで測る。
```python
import subprocess, sys, numpy as np
f = sys.argv[1]; w, h = 90, 160
raw = subprocess.run(["ffmpeg","-v","error","-i",f,"-vf",f"fps=10,scale={w}:{h},format=gray","-f","rawvideo","-"],capture_output=True).stdout
a = np.frombuffer(raw,np.uint8).reshape(-1,h,w).astype(float)[:, int(h*.2):int(h*.68), :]
d = np.abs(np.diff(a,axis=0)).mean(axis=(1,2))
win = [(i/10, d[i:i+5].mean()) for i in range(len(d)-5)]
bad = [t for t,v in win if v < 0.5]
print("最小:", round(min(v for _,v in win),2), " 止まっている所(秒):", sorted(set(round(t) for t in bad)))
```
- **どの0.5秒をとっても 0.5 以上** を合格にする（基準のフローダイバーター動画は最小0.51。コイリング動画は最後の4秒が0.0で止まっていた＝これが不合格の例）。
- 不合格の場所は、その場面を作り直すか、血流の続きクリップを足す。
- あわせて各場面から3〜4コマ抜き、器具の崩れ・増殖・逆走、血管の形の変化、文字の混入がないか目で確認する。
