# 連続台本の置き場所と進行チェック

予定（スケジュール）で開いたチャットは、中身を開いて見るのが面倒で、どれを実行したか分からなくなる。だから連続ものの台本は、チャットの中だけに置かず、1つのClaude Docsにまとめる。

## 企画を立てる側（最初に1回）

1. シリーズ用のDocsを1つ作る。タブは次の順にする。
   - 「進行チェック表」（order a0）：全本数を `- [ ]` のチェックリストで並べる。項目名は「呼吸器内科7｜合併症 抗結核薬の薬剤性肝障害」のように、科（またはカテゴリ）＋番号＋題材。
   - 「企画（○本の一覧）」（order a1）：企画の一覧。台本はここに書き足さない。
   - 「台本」（order a2）：親タブ。中身は「台本は1本ずつ、この下のタブに入ります」の一文だけ。
2. 予定のチャットを1本ずつ作るとき、各チャットへの指示に「DocsのURL」「台本タブのid」「進行チェック表タブのid」「タブ名」「並び順（b01〜）」を書いておく。
3. 予定のチャットどうしが同じタブに同時に書くと、文章が混ざってしまう。だから1本ごとに別のタブにする。

## 予定のチャット側（台本を1本書くたび）

1. ふだんのYAKUBON STUDIOのルール（メモリとスキル）どおりに台本を書く。
2. 書き上げたら、Docsの「台本」タブの下に、その1本だけの新しいタブを作る。
   - タブ名：科の略＋番号＋題材。例「呼内7｜抗結核薬の肝障害」「心外4｜CABG後の心房細動」。
   - 合併症シリーズの略：消内・消外・呼内・呼外・循内・心外・脳外・脳内・美容。
   - 並び順：通し番号で b01〜b90（2けたにそろえる）。subtabOf は台本タブのid。
   - 1回のbatchで「ファイル作成 → 本文ノード作成 → ファイルの中身を本文へ → プロジェクトのtabsに名前・順番・親を設定」まで行う。
3. 進行チェック表タブを読み、その台本の項目（listItem）に `set attrs checked:true` で☑を付ける。
4. 企画タブやほかの台本のタブは変えない。
5. チャットの最後の返事は短く「○○の台本をDocsのタブに入れて☑を付けました」とする。

## 注意

- Docsのタブ間で文章を移動する機能はない。後からまとめ直すと全文の打ち直しになるので、最初から1本1タブにする。
- チャットそのものの名前変更やチャットへのチェックはClaudeからはできない。チェックはDocsの進行チェック表で行う。
- 合併症シリーズのDocs：https://claude.ai/artifact/EA7qEMfRyfh67V34BbRHfD（台本タブ 11a26ab7-2eef、進行チェック表タブ 251a5555-6b2c）。
