# 1本1テーマで、ステップ・バイ・ステップに積み上げる（YAKUBON STUDIO）

2026-11-27 シンサクさん指示（ファロー四徴の動画を見て）。
見るのは看護学生3年生〜配属されたばかりの新人看護師。血流がどう流れているかが、まだ分からない人たち。
病気の仕組み・手術の理由・術式を1本に詰め込むと、頭がパンクする。**1本の動画では、1つのことだけを分かってもらう。**

## いつ使うか
- 先天性心疾患（ファロー四徴、完全大血管転位、心室中隔欠損、心房中隔欠損、動脈管開存など）の動画すべて
- 1本の中に「病気の仕組み」と「手術」が両方入りそうなとき
- 術式が2つ以上ある病気（姑息術→根治術、ラステリ手術とジャテーン手術など）
- 台本を書く前に、かならず読む（`iryo-douga-1-illust-script`、`yakubon-procedure-motion-first` より先）

## 分け方（シリーズにする）
1. **病態の動画（1本目）**：その病気の血流から始める → どこが通りにくい・混ざるのか → そのせいで何が困るのか（チアノーゼ・心不全など）→ **だから何のために、どの手術をめざすのか**（例：単心室→最後はフォンタン手術をめざす）
2. **手術の動画（2本目以降）**：なぜ手術が必要か（1本目の「困ること」をひと言でふり返る）→ どこをどうつなぐ・ふさぐか → **術前と術後の血流のくらべ**
3. **術式が2つ以上あるときは、1術式＝1本**。例：BTシャント（姑息術）で1本、根治術で1本。ラステリ手術で1本、ジャテーン手術（動脈スイッチ）で1本
4. 病態の動画の最後に「次は手術の動画で」のひと言を入れ、手術の動画の最初に「前の動画のおさらい」を1カット入れて、シリーズとしてつなぐ

## 1本の中の積み上げ方
- **正常の血流は入れない**（2026-11-28 本人指示）。正常の血流は、先天性心疾患シリーズの中に1本だけある「正常の血流」の動画に任せる。毎回の動画には入れない（ファロー・大血管転位・フォンタンで何度もやっているため）
  - 病態の動画は、最初からその病気の絵で始める。例：単心室なら、1カット目から単心室の心臓
  - 正常との違いを言いたいときは、テロップ1行で済ませる（例：「本来は心室が2つ」）。正常の心臓のカットは作らない
- **1カット＝新しいこと1つ**。前のカットで分かったことの上に、次の1つを足す
- **4つの特徴などは、1つずつ順番に**。まとめて1枚で見せない
  - 例（ファロー四徴）：①心室中隔欠損 → ②肺動脈狭窄（右室流出路狭窄）→ ③大動脈騎乗 → ④右室肥大。それぞれ「どこが」「血の流れがどうなるか」を1カットずつ
- **「なぜ」を必ず入れる**。手術・処置には「何が困っているから、これをやるのか」を先に言う
  - 例：「卵円孔を広げる（BAS）」の前に、「左右の血が混ざらないと、酸素の多い血が全身に届かない」を見せる
- **手術の動画には、術前と術後の血流をくらべるカットを必ず入れる**（同じ向き・同じ大きさの絵で、流れの道すじだけを変える）
  - 例（ラステリ手術）：心室中隔欠損をパッチでふさいで左心室の血を大動脈へ導く／右心室と肺動脈を導管（人工血管）でつなぐ → 肺へ行く血が導管を通って肺動脈へ届く
- 最後に、その1本で分かったことを1カットでまとめる（3つまで）

## 詰め込みすぎの見分け方（台本を書いたら数える）
次のどれかに当てはまったら、2本以上に分ける。
- 病気の仕組みと手術が、両方とも2カット以上ある
- 術式の名前が2つ以上出てくる
- Tipsが4つ以上必要になる（Tipsで説明しきれないことは、Tipsではなく別の動画にする）
- 正常の血流のカットが入っている（シリーズの「正常の血流」の動画に任せて外す）
- 病態の動画に「何のために、どの手術をするのか」のつなぎがない
- 「なぜその手術をするのか」のカットがない

## 割り方の例（単心室・フォンタン）
- ① 単心室の血流（病態）：単心室の心臓から始める → 全身の血と肺の血がひとつの部屋で混ざる → チアノーゼ → 心室が2人分を送って疲れる → だから最後はフォンタン手術をめざす
- ② グレン手術：上大静脈を肺動脈へ → 術前・術後の血流
- ③ フォンタン（TCPC）手術：下大静脈も肺へ → 開窓 → 術前・術後の血流
- ④ フォンタン循環の弱点：流れがよどむ → 肝臓・たんぱく漏出・鋳型気管支炎・血栓 → 看護

## 本人への出し方
- 台本を出す前に、シリーズの分け方（何本に分けて、各回で何が分かるようになるか）を短く見せる
- 各回のタイトルは「○○の血流①　何が問題？」「○○の手術②　ラステリ手術」のように、シリーズの何本目か分かる形にする
- 1本の長さは、これまでどおり声に合わせる（声は速めない）

## してはいけないこと
- 1本に、病態・複数の術式・合併症をまとめて入れる
- 毎回の動画に、正常の血流のカットを入れる（シリーズで1本あれば十分）
- 病態を説明したまま、何のための手術につながるのかを言わずに終わる
- 「どこをどうつなぐか」をTipsの文字だけで済ませる（絵で、血の流れが動いて見えるようにする）
- 「なぜ必要か」を言わずに手術を始める
