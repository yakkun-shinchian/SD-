# 難しい言葉には必ずTips

## 対象読者（これが唯一の基準）
**看護学生3年生〜新人看護師1年目**。大学院・医学部レベルの知識は前提にしない。「国家試験に出る範囲＋臨床1年目で出会う範囲」を標準とする。

## 判断の物差し（2026-11-14 本人の指示）
「看護学生が卒業するとき、すでに知っている言葉か？」で決める。基礎看護学・成人看護学の授業や国試でくり返し出る言葉には付けない。付けすぎると、見る人が「バカにされている」と感じ、本当に難しい言葉のTipsが埋もれる。

### Tipsを付けない言葉（卒業時に知っている基礎用語の例）
ボディイメージ、セルフケア、バイタルサイン、褥瘡、誤嚥、脱水、浮腫、ADL、QOL、インフォームド・コンセント、清潔操作、体位変換、腸蠕動、尿量、排便コントロール など。
- 迷ったら「看護学生3年生が実習記録でふつうに書く言葉か」で考える。書くなら付けない
- ただし本人が「入れていい」と言った言葉は付ける（例：ストーマ。動画の主題そのものなので、入口の一枚として残す）

## 発動条件
本文に次のいずれかが出てきたら、**その場でTipsを付ける**。あとでまとめて解説しない。上の「付けない言葉」に当たるものは除く。

1. **専門用語・疾患名・術式名で、読者が初めて見る可能性があるもの**（例：播種、ひょう疽、上咽頭、血球貪食症候群、回腸導管）
2. **略語**（例：PTLD、HLH、CRBSI、PICC）— 初出時に必ず日本語の意味を添える
3. **人名のついた症候群**（例：ラムゼイ・ハント症候群、カポジ肉腫）
4. **読み方が難しい漢字**（例：播種＝はしゅ、滲出液＝しんしゅつえき）
5. **日常語と意味がずれる言葉**（例：「潜伏」「再活性化」「免疫特権」）

## 書き方の型

```
> **【Tips】語句**
> ①ひとことの言い換え（10〜20字）
> ②臨床でどう出会うか／見分けるコツ（1〜2文）
```

- 1つのTipsは**3行以内**。長くなったら本文に書くべき内容。
- **たとえ話を入れてよい**が、1つのTipsに1つまで。
- 「〜という意味よ」「〜がコツ」など、やさしい語り口で書く。

## 動画に入れるときのTipsカード（標準の見た目・2026-11-13 無気肺で決定）
PCの `pipeline\add_tips.py` で、完成動画（ラベル入りがあればそれ）に重ねる。出力は `<title>_Tips入り.mp4`。

- **書体**：極太明朝（Noto Serif JP Black、無ければHG明朝E）。
- **文字の大きさ（これが標準。大きめでスマホでも読める）**
  - 1行目【Tips】＝エメラルド（#2EE6A8）**66px**
  - 2行目 言葉の名前＝白 **60px**（長いカタカナ語もここに1行で入れる。【Tips】と同じ行にしない）
  - 説明 ①②③＝白 **52px**、3行まで、1行17字前後まで（はみ出しそうなら言い換えて短くする）
- **板**：画面いっぱいに近い幅の半透明の濃紺の角丸の板＋エメラルドの細い枠、文字は濃紺の縁取り。
- **位置**：画面の下（上端 y≈1430、1080×1920）。主役の臓器や病変にはかぶせない。同じ場面の引き出し線ラベルが下にあるときは、ラベルを上（テロップのすぐ下）へ移す。
- **出し方**：場面の頭から約0.5秒後にフェードインし、場面の終わりまで出しておく。
- **edit.json の書き方**（その場面に足す）：
  ```json
  "tips": {"word": "", "name": "インセンティブスパイロメトリー",
           "lines": ["①吸う量が見える、深呼吸の練習器具", "②ゆっくり吸って、中の玉を持ち上げる", "③術後の無気肺を防ぐために使うよ"],
           "title_size": 66, "name_size": 60, "line_size": 52, "at": 0.5, "y": 1430}
  ```
  word は空にして、言葉は name に入れる（【Tips】と言葉を別の行にして大きく見せるため）。
- **手順**：`python -X utf8 pipeline\add_tips.py <作品フォルダ> --check` で確認画像（temp\_tips_check_<場面>.jpg）を見る → 問題なければ `--check` なしで本番 → 完成動画から場面のコマを抜いて確認し、チャットに送る。

## 絶対に避けること
- **分子・遺伝子・受容体・シグナル伝達のレベルに降りない。** 「グランザイムBがICP4を切断する」ではなく「見張りの細胞が、起き上がろうとしたウイルスを押さえつける」と書く。
- 専門用語を、別の専門用語で説明しない。
- Tipsの中に新しい未説明の専門用語を持ち込まない。
- 本文の流れを止めるほど長いTipsを書かない。

## 本文側のルール
- 本文は**言い換えた言葉をメイン**に書き、専門用語はそのあとに（ ）で添えるか、Tipsに回す。
- 専門用語だけの見出し・テロップは作らない。
- 1本の動画・1つのセクションで、Tipsは**多くても6個まで**。それ以上必要なら、テーマを分割する。

## 分割の判断
情報量が多くて1本に収まらないときは、**削るのではなく、別の動画に分ける**。
「全身への影響」「がんとの関係」「潜伏と再活性化」のように、**切り口で分ける**。各本の中身は、臓器ごと・ウイルスごとに**ていねいに網羅する**。はしょって浅くしない。

## 仕上げチェック
- 初出の略語すべてに日本語の意味があるか
- 読みにくい漢字に読みがなが付いているか
- 分子・遺伝子レベルの説明が紛れ込んでいないか
- Tipsが3行以内に収まっているか
- Tipsの中に未説明の専門用語がないか
- 「看護学生3年生がこれを読んで分かるか」を声に出して確認したか
