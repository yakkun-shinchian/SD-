## 取り戻せるかもしれない場所
1. **claude.ai の 設定 → 機能（Capabilities）→ スキル**：削除・無効化したスキルが残っていないか
2. **PC の YAKUBON_STUDIO フォルダ**：スキルを作ったときの `.zip` や `SKILL.md`
3. **過去のチャット**：「スキルを更新して」と頼んだ会話には、変更前の全文が貼られていることがあります

見つかったら、`スキル/<名前>/履歴/` に `v0_日付.md` として入れておけば、原型として残ります（Claudeに「これを v0 として保管して」と渡してもらえれば整えます）。
