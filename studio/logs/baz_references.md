# 参照帳 — 伸びている動画から、原理だけを抜き出す

毎回やらなくてかまいません。**見つけたときだけ、3行。**

```
日付 | 何の動画か（一言）
効いている理由：なぜ目が止まるのか・なぜ最後まで見るのか
自分のどこに使えるか：次の1本の、どの場面に効くか
```

## 書き方の約束

- **リンクを貯めない。原理を抜き出す。** URLは消えます。原理は残ります。
  道具（ComfyUI・Seedance・Gemini）が入れ替わっても、原理は使えます。
- **医療系だけ見ない。** 美術系・自然科学系・工芸など、美しい動画も見ます。
  同じ分野で競るより、隣の分野から持ってくる方が効きます。真似だと気づかれにくく、
  真似されにくい。
- **「真似する」ではなく「効いている理由を言葉にする」。** 理由を言葉にできたものだけが、
  別の題材でも再現できます。
- 1行目は日付と一言。2行目は理由。3行目は自分への applying。それ以上は書かない。
  長く書くと、次から書かなくなります。
