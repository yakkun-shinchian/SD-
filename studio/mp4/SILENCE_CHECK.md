# ナレーション無音チェック

`build` / `subtitles` の書き出し前に実行。警告のみで、無音削除、映像・字幕の移動はしない。
`silence_report.json` と CLI の JSON に結果を保存し、警告は stderr に表示する。

既存マニフェストに以下を追加する例（audio[0] が声、audio[1] が BGM）：

```json
{
  "silence_check": {
    "enabled": true,
    "narration_tracks": [0],
    "noise_db": -40,
    "min_duration": 0.5,
    "keep": [
      {"start": 12.0, "end": 14.5, "reason": "CT断面を見せる"},
      {"start": 25.0, "end": 28.0, "reason": "3D構造を見せる"}
    ]
  }
}
```

- `narration_tracks`: audio 配列の **0始まりの番号**。指定した声だけを混合して検査する。BGMの番号は含めない。省略時は後方互換のため全audioを声として扱うので、BGMがある作品では必ず指定する。空配列は `no_narration` として検査をスキップする。
- `noise_db`: -120〜0 dB、既定 -40。実音声の小さな声を無音と判定する可能性があるため、候補を試聴して判断する。
- `min_duration`: 完成動画上の秒数、0より大きい値（最小0.001）、既定0.5。
- `keep`: 完成動画上の秒数。理由必須、映像の長さ以内。候補と重なった部分だけ警告から除外する。部分除外後の残りは短くても報告する。重複指定は二重計上しない。
- 分類は `leading`（冒頭）、`internal`（途中）、`trailing`（末尾）、`entire`（全編）。部分除外後も元の候補の分類を保持する。

```bash
python3 studio/mp4/edit.py build scene_manifest.json --output-dir edited
python3 studio/mp4/edit.py subtitles scene_manifest.json --output-dir edited
python3 -m unittest discover -s studio/mp4/tests -v
```

## 時刻とキャッシュ

書き出しと共通のフィルターで trim → atempo → volume → adelay を適用してから検査する。配置は既存レンダラーと同じミリ秒丸め。冒頭の配置待ち時間、クリップ間の空白、apad相当の末尾も含めて検出する。全チャンネルが静かな区間を対象とする。速度変更の境界はatempoの窓処理の影響があるため単純な算術換算とは数十ms異なりうる。元MP4の音声は従来の編集と同様使用しない。

BGMを含むマスターを解析しない。声と音楽が既に同一ファイルに混ざっている場合の音源分離機能はない。

設定は映像マスターのキャッシュキーから分離しており、保持指定・閾値・声トラック選択だけの変更ではマスターを再エンコードしない。検出結果は音声設定・音声ハッシュ・閾値・最小時間・全長でキャッシュする。保持区間は毎回再適用する。字幕のみモードはキャッシュが一致すれば元素材なしでも動作。閾値等を変えて再検出が必要なら元ナレーションが必要で、欠落・変更時はエラーにする。検査失敗を「無音なし」とは扱わない。

## 検証 2026-10-30

FFmpeg 6.1.1。合成音は元の2〜4秒、6〜8秒に440Hz、ほかは無音。
1〜9秒でトリム、2倍速、完成動画1秒へ配置。映像は8秒、BGMは全編220Hz。

| 検出候補 | 実測・完成動画秒 | 結果 |
|---|---|---|
| 冒頭 | 0.000〜1.488 | 警告 |
| セリフ間 | 2.506〜3.483 | 2.600〜3.400はCT保持、前後だけ警告 |
| 末尾 | 4.501〜8.000 | apad分を含め警告 |

BGMが鳴っていても上記を検出。保持を2.4〜3.6秒へ広げると途中警告だけ消える。マスターSHA-256不変。元素材削除後の字幕再出力はキャッシュで成功し、閾値変更による再検出要求は欠落エラー。最小時間2秒では末尾のみ、閾値0dBでは全編候補。複数声トラックが空白を埋める場合は警告なし。検査有効・無効の変更で完成MP4のSHA-256不変。

結果: MP4編集21件成功（既存17件＋追加4件）、既存M3/M4 21件成功、`git diff --check`成功。

実行ログ: `silence-test-results.txt`。既存のネオン、音程維持、字幕時刻換算、マスター再利用の回帰テストも含む。
