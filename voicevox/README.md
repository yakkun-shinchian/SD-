# VOICEVOXで本物のずんだもん音声をつける手順なのだ 🫛🔊

このフォルダには、各番組のナレーションを **VOICEVOX**（無料の音声合成ソフト）に
そのまま流し込めるように書き出したデータが入っているのだ。
これを使うと、アプリの自動再生を **端末の読み上げ → 本物のずんだもん音声** に差し替えられるのだ。

> ⚠️ **クレジット表記が必要なのだ**：VOICEVOXのずんだもん音声を使った成果物には
> 「**VOICEVOX:ずんだもん**」のクレジットを必ず表示するのだ（各キャラクター／VOICEVOXの利用規約に従ってほしいのだ）。

## このフォルダの中身

| ファイル | 中身 |
| --- | --- |
| `narration.txt` | 1行＝1ナレーション（全118行）。VOICEVOXに読み込ませる本文なのだ |
| `manifest.json` / `manifest.csv` | 書き出し順(seq)・番組ID・シーン番号・アプリでのファイル名(`番組ID-シーン番号.wav`)・本文の対応表なのだ |
| `export/`（自分で作る） | VOICEVOXで書き出したwavを置く場所なのだ |

## 手順（ざっくり7ステップ）

1. **VOICEVOX** を公式サイトからインストールして起動するのだ。
2. 話者を **「ずんだもん（ノーマル）」** に設定するのだ（あまあま等、好みのスタイルでもOK）。
3. メニューの **「ファイル」→「テキストを読み込む」** で `voicevox/narration.txt` を読み込むのだ。
   → 1行ずつが音声アイテムになるのだ（行の順番＝`manifest`のseqの順番）。
4. 必要なら話速・抑揚・音高をまとめて調整するのだ（ずんだもんは少し高めが可愛いのだ）。
5. **「ファイル」→「音声を書き出し」** で**一括書き出し**するのだ（連番つきのwabができるのだ）。
6. 書き出したwavを **`voicevox/export/`** フォルダに入れるのだ（名前は変えなくてOK。順番が保たれていればいいのだ）。
7. プロジェクト直下で次を実行するのだ：

   ```bash
   node tools/link-audio.mjs
   ```

   → `export/` のファイルを `manifest` の順番で `audio/番組ID-シーン番号.wav` にコピーし、
   `audio/manifest.js`（アプリが読む対応表）を自動生成するのだ。

8. ブラウザでアプリ（`index.html`）を開いて番組を再生すると、**本物のずんだもん音声**で流れるのだ！🎉

## 仕組み（なぜ自動で差し替わるのか）

- アプリは各シーンで `番組ID-シーン番号`（例：`anat01-1`）という**キー**の音声を探すのだ。
- `audio/manifest.js` の `AUDIO_FILES` にそのキーがあれば**その音声ファイル**を再生し、
  無ければ**端末の読み上げ**（または無音でスライド送り）にフォールバックするのだ。
- つまり、**作った分だけ**本物の声に置き換わって、未作成の番組は今まで通り動くのだ。

## 手動で1本ずつ用意したい場合

`export/` を使わず、自分で名前をつけて置いてもOKなのだ。

1. 音声ファイルを `audio/anat01-1.wav` のように **`番組ID-シーン番号.拡張子`** で `audio/` に置くのだ
   （対応形式：wav / mp3 / ogg / m4a）。
2. `audio/manifest.js` に対応を書くのだ：

   ```js
   const AUDIO_FILES = {
     "anat01-1": "audio/anat01-1.wav",
     "anat01-2": "audio/anat01-2.wav",
     // …必要な分だけ
   };
   ```

## 台本を直したら

`scenes.js` を編集したら、`node tools/build-voicevox.mjs` を実行すると
`narration.txt` と `manifest` が作り直されるのだ。変えたシーンだけ録り直せばいいのだ。
